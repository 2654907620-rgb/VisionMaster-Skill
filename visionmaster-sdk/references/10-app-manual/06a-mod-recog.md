# VM 模块参考：识别

识别分类下的模块可对图像进行处理，包括二维码识别、条码识别、字符识别、DL字符识别、DL读码、DL字符定位、DL单字符检测和 ML 分类模块。

## 速览

- **DL读码**：基于内置深度学习模型定位并解析一维码、二维码、堆叠码，无需自行训练模型；复杂场景读码准确率高于传统读码模块，支持码等级（质量评级）评估。
- **条码识别**：传统算法定位并识别一维条码，支持预处理条码图像，常用于物流读码、商品贴标、零件喷码及条码图像旋转和倾斜场景。
- **二维码识别**：传统算法定位并译码二维码（QR码/DataMatrix码），可高效准确识别多个二维码，但对图像要求较高。
- **DL字符定位**：深度学习定位图像中的字符区域，输出定位框与置信度；背景复杂或字符位置不固定场景仍可准确定位，可定位旋转字符、多行文本。
- **DL字符识别**：深度学习识别文本行内容，需前序模块提供字符定位信息；内置 4 个模型文件（中/英文 × 快速/高精度），兼容字符形态不一、低对比度、背景干扰等复杂场景。
- **DL单字符检测**：定位+识别一体，逐个定位并识别单个字符，适用于无法展开的弯曲字符（环形文本）、单个字符或不规则文本行。
- **字符识别**：传统字库训练 OCR（非深度学习），先训练生成字符库再识别；适合字符种类较少、字符位置较稳定且成像清晰的场景。
- **ML分类**：传统机器学习图像分类，手动标注样本训练分类器（SVM/RF），推理输入图像类别，广泛用于物体识别和分拣。
- **读码选型**：码型简单、成像好、需码等级评估之外的轻量方案 → 条码识别/二维码识别；复杂场景（反光、褶皱、低对比、混码）或需一码通吃一维+二维+堆叠码 → DL读码（内置模型免训练）。
- **字符识别 vs DL字符识别**：字符识别靠字库训练+特征分类，无需深度学习，适合字体固定、成像清晰的规则场景；DL字符识别基于深度学习模型，在字体形态变化、背景干扰、低对比度、字符轻微黏连畸变等场景更鲁棒。单字符/弯曲字符场景改用 DL单字符检测。

## 识别模块对比表（★必做）

| 模块 | 技术路线 | 核心功能 | 是否需训练模型 | 支持码制/字符集 | 典型场景 |
| --- | --- | --- | --- | --- | --- |
| DL读码 | 深度学习（内置模型） | 定位并解析一维码、二维码、堆叠码，可评码等级 | 否（内置模型，免训练） | 条码：CODE39、CODE128、库得巴、EAN8、EAN13、UPCA、UPCE、交替25、CODE93、MATRIX25、MSI、CNPOST、CODE11、IND25、ITF14；二维码：QR、DataMatrix；堆叠码：PDF417 | 复杂场景高准确率读码 |
| 条码识别 | 传统算法 | 定位并识别一维条码，支持图像预处理 | 否 | CODE39码、CODE128码等多种编码方式（CODE39/CODE128/库得巴/EAN/交替25/CODE93 开关项） | 物流读码、商品贴标、零件喷码、条码旋转倾斜 |
| 二维码识别 | 传统算法 | 定位并译码二维码，输出字符串 | 否 | QR码、DataMatrix码 | 多二维码高效识别 |
| DL字符定位 | 深度学习 | 定位字符区域，输出定位框+置信度 | 内置简易模型；可 VisionTrain/AI训练平台自训 | 不限字符集（仅定位，不识别内容） | 背景复杂、字符位置不固定、旋转/多行文本定位 |
| DL字符识别 | 深度学习 | 识别文本行字符内容 | 内置简易模型；可自训 | 内置模型支持中文/英文；字符类型过滤：数字0~9、大写字母A~Z、小写字母a~z、特殊字符、空格、自定义 | 生产日期、批号、产品编号自动识别（食药品包装、3C电子、汽车零配件、半导体、物流） |
| DL单字符检测 | 深度学习 | 定位+识别一体，逐个识别单字符 | 内置简易模型；可自训 | 同 DL字符识别的字符类型过滤 | 环形文本、无法展开的弯曲字符、不规则文本行、打印字符校验 |
| 字符识别 | 传统字库训练（自适应分割+分类器） | 字库训练+字符识别，输出第一/候选识别结果 | 需字库训练（非深度学习训练） | 字符类型过滤：全部、数字、大写字母、小写字母、特殊字符、空格、自定义 | 字符种类少、位置稳定、成像清晰 |
| ML分类 | 传统机器学习 | 图像特征+标注训练分类器，推理图像类别 | 需分类训练（手动标注样本） | 类别由用户自定义标注；分类器：SVM/RF | 物体识别和分拣 |

### DL读码

**功能**：基于深度学习模型定位和解析场景中一维码和二维码的信息，相较于传统读码模块读码准确率较高，且在复杂场景中也可保持较好的识别率。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 一般直接与图像源模块配合使用 |
| 检测区域 | ROI | 图像中需进行检测的 ROI 区域（输出中含该项） |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 该模块运行时耗费的时间 |
| 模块状态 | int | 0代表NG（红色）；1代表OK（绿色） |
| 码个数 | int | 识别到码的个数 |
| 码状态 | int | 码是否可识别；1表示识别成功，不显示表示识别失败，会显示各个码的状态 |
| 编码信息 | string | 各个码蕴含的信息 |
| 码类型 | int | 识别到码的类型 |
| PPM | float | 一维码中代表成像后最细黑条或白空的像素数，二维码中代表最小模块边长占用的像素数 |
| 码角点X/码角点Y | float | 码四个角点的X/Y坐标 |
| 码角度 | float | 码起点与终点连线后与水平方向的夹角，逆时针为正 |
| 码镜像标志 | int | 码的正反面，0为反面，1为正面 |
| 矩形框 | box | 识别到码的矩形框（含中心点X/Y、矩形宽度、矩形高度、矩形角度；矩形角度由点0和点1所连直线与水平线夹角构成，顺时针为正，逆时针为负） |
| 码行号/码列号 | int | 码在区域的第几行/第几列（配合"码行列号"参数） |
| 检测区域 | box | 检测 ROI 区域（中心点X/Y、宽度、高度、角度） |
| 码等级 | int/float 组 | 总等级质量（0(F)、1(D)、2(C)、3(B)、4(A)，数值越大码质量越好）、译码评分、符号对比度、模块均匀性、固定程度、轴向不均匀性、网格不均匀性、未使用纠错、水平/垂直打印伸缩、反射率余量、边缘确定度、最小反射率、最小边缘对比度、可译码性、缺陷度、静区及其对应分数 |
| 调试信息 | string | 算法调试信息（算法调试状态字、算法调试信息大小、算法调试信息地址） |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 条码类型 | CODE39码、CODE128码、库得巴码、EAN8码、EAN13码、UPCA码、UPCE码、交替25码、CODE93码、MATRIX25码、MSI码、CNPOST码、CODE11码、IND25码、ITF14码 | — | 需根据场景中的条码启用对应的条码类型 |
| 条码个数 | int | — | 期望查找并输出的条码最大数量，若实际查找到的个数小于该参数值，则输出实际数量的条码 |
| 二维码类型 | QR码、DataMatrix码 | — | 根据场景中的二维码，启用对应的二维码类型 |
| 二维码个数 | int | — | 期望查找并输出的二维码最大数量，不足则输出实际数量 |
| 堆叠码类型 | PDF417码 | — | 根据场景中的堆叠码，启用对应的堆叠码类型 |
| 堆叠码个数 | int | — | 期望查找并输出的堆叠码最大数量，不足则输出实际数量 |
| 超时退出时间 | ms | 1000ms | 算法运行时间超出该值则直接退出；设置为0时关闭超时退出，以实际算法运行时间为准 |
| 高性能模式 | 开/关 | — | 开启后识别效果更佳，但占用的CPU或GPU资源会增加 |
| 码行列号（行数量/列数量） | 开/关 + 行列数 | — | 开启后按行列数量将输入图像平均分割成单元格，根据码检测框外接矩形在单元格中所占比例计算码的行列信息；输出结果从0开始（如行列信息为1，1表示第二行第二列） |
| 码等级 | 开/关 | — | 开启后可评码等级；一维码等级仅支持128码和39码，二维码等级仅支持QR码和DM码 |
| 二维码等级-ISO标准 | ISO15415、ISO29158 | — | 可根据需求选择 |
| 二维码等级-评级处理类型 | 处理类型1、处理类型2 | — | 处理类型1支持HIK评级模式；处理类型2支持ISO评级模式 |
| 二维码等级-评级模式 | ISO模式、HIK模式 | — | 根据实际需求选择 |
| 二维码等级-极性 | 任意、白底黑码、黑底白码 | — | 根据所要识别码的极性进行选择 |
| 二维码等级-二维码行数/列数 | int | 默认值（建议） | 实际二维码包含的行数和列数，一般建议使用默认值；组成二维码的最小"方块"或"圆"所在行和列即为一行或一列 |
| 二维码等级-边缘类型 | 连续型、离散型 | — | —（原文为图示，文字缺失：连续/离散边缘示意） |
| 一维码等级 | 译码评分、边缘确定度、符号对比度、最小反射率、边缘对比度、模块均匀性、可译码性、缺陷度、可译码性A/B/C/D、缺陷度A/B/C/D、最小反射率A、模块均匀性A/B/C/D、对比度A/B/C/D | — | 各指标开启后计入总等级；A/B/C/D对应指标分数的计算等级区间 |

**模型相关**：
- 模型来源：模块调用内置的深度学习模型定位和解析码信息，**无需自行训练模型**。
- 码制：通过运行参数中条码类型/二维码类型/堆叠码类型开关选择，详见参数表。
- 置信度阈值：原文未给出参数表之外的置信度阈值参数；码质量通过"码等级"输出（0(F)~4(A)）。

**使用步骤**：
1. 将 DL读码模块与图像源模块配合使用（后序无指定模块，可处理该模块输出的信息即可）。
2. 在运行参数页签中，根据场景中可能出现的码制，开启对应的条码类型/二维码类型/堆叠码类型识别选项。
3. 按需设置条码/二维码/堆叠码个数、超时退出时间、高性能模式等参数。
4. 需要判断漏检时，开启"码行列号"并设置行数量与列数量，通过码的行列信息判断是否存在漏检。
5. 需要码质量评估时，开启"码等级"并按码制配置一维码等级/二维码等级相关参数。

**注意事项**：
- 码行列号输出结果从 0 开始。例如行数量设置为3、列数量设置为4，若码位于第三行第三列，则输出的码行列信息为（2，2）。
- 一般码有4个角点，按顺序分别为点0、点1、点2、点3，不同码制的顶点规则和标准有所差异，具体请以实际为准。

### 条码识别

**功能**：定位和识别指定区域内的条码，支持识别 CODE39码、CODE128码等多种编码方式，同时支持预处理条码图像，常用于物流读码、商品贴标、零件喷码及条码图像旋转和倾斜的场景。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序模块可为图像源、仿射变换、形态学处理等模块；图像处理类模块可处理待读码图像，提高读码效率 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 该模块运行时耗费的时间 |
| 模块状态 | int | 0代表NG（红色）；1代表OK（绿色） |
| 码个数 | int | 识别到码的个数 |
| 码状态 | int | 码是否可识别；1表示识别成功 |
| 编码信息 | string | 各个码蕴含的信息 |
| 码类型 | int | 识别到码的类型 |
| 码角度 | float | 码起点与终点连线后与水平方向的夹角，逆时针为正 |
| PPM | float | 成像后最细黑条或白空的像素数（一维码） |
| 矩形框 | box | 识别到码的矩形框（中心点X/Y、矩形宽度、矩形高度、矩形角度） |
| 检测区域 | box | 检测 ROI 区域（中心点X/Y、宽度、高度、角度） |
| 调试信息 | string | 算法调试信息 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| CODE39码/CODE128码/库得巴码/EAN码/交替25码/CODE93码 | 开/关 | — | 控制模块能否识别对应类型的条码；若不确定待检测条码的类型，建议开启全部项 |
| 条码个数 | int | — | 模块能够查找的最大条码数量，超出则输出前若干个条形码 |
| 降采样系数 | int | — | 每间隔k个点取1个点，图像分辨率降低为（N/k）×（M/k）；增大可提高处理效率但降低轮廓精细程度，过大时会丢弃过多图像细节导致无法识别 |
| 检测窗口大小 | int | 4 | 条码区域定位窗口大小；条码中空白间隔比较大时可设置更大（如5），但一般要保证条码高度大于窗口大小的6倍左右 |
| 静区宽度 | int | 30 | 静区指条码左右两侧空白区域宽度；稀疏时可尝试设置50 |
| 去伪过滤尺寸 | — | — | 算法支持识别的最小条码宽度和最大条码宽度 |
| 超时退出时间 | ms | — | 设置为0时不限制模块运行时间；超出设置值则识别失败，模块不输出字符信息 |

**模型相关**：不适用（传统算法，无模型）。

**使用步骤**：
1. 算法工作步骤（原理）：基于条形码纹理定位候选区并预处理图像 → 逐行扫描获取黑色条与空白条的边界位置坐标 → 组合匹配并计算条宽 → 匹配起始符和终止符获得码制 → 基于码制解析数据符内的字符信息 → 汇总每行解析结果输出最终字符信息。
2. 流程中前序搭配图像源、仿射变换、形态学处理等模块优化图像。
3. 按需开启对应码制开关，设置条码个数等运行参数。
4. 后序模块可将条码信息和位置输入至定位、通信等模块，用作后续处理。

**注意事项**：
- 完整条码通常包含两侧静区、起始符、数据符、校验位（可选）、终止符（原文为图示，文字缺失：条码组成示意图）。
- 一般码有4个角点，不同码制的顶点规则和标准有所差异，具体请以实际为准。

### 二维码识别

**功能**：识别目标图像中的二维码，将读取的二维码信息以字符串的形式输出；支持 QR码和 DataMatrix码，可高效准确识别多个二维码，但对图像要求较高。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序模块可为图像源、仿射变换、形态学处理等模块 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 该模块运行时耗费的时间 |
| 模块状态 | int | 0代表NG；1代表OK |
| 码个数 | int | 识别到码的个数 |
| 码状态 | int | 码是否可识别 |
| 编码信息 | string | 各个码蕴含的信息 |
| 码角度 | float | 码起点与终点连线后与水平方向的夹角，逆时针为正 |
| 矩形框 | box | 识别到码的矩形框（中心点X/Y、矩形宽度、矩形高度、矩形角度） |
| PPM | float | 二维码中最小模块边长占用的像素数 |
| 评估版本 | int | 101代表DM码，102代表QR码 |
| 检测区域 | box | 检测 ROI 区域 |
| 调试信息 | string | 算法调试信息 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| QR码/DataMatrix码 | 开/关 | — | 控制模块能否识别对应类型的二维码；不确定类型时建议开启全部项 |
| 二维码个数 | int | — | 期望查找并输出的二维码最大数量，不足则输出实际数量；背景纹理较复杂时可适当大于需要识别的二维码个数 |
| 极性 | 任意、白底黑码、黑底白码 | — | 可根据实际情况进行选择 |
| 边缘类型 | 连续型、离散型、兼容模式 | — | 兼容模式可兼容前两种类型（原文为图示，文字缺失：边缘类型示意图） |
| 降采样倍数 | int | — | 增大可提高处理效率，过大时会导致无法识别具体信息 |
| 码宽范围 | 像素宽度区间 | — | 二维码所占的像素宽度，包含最大最小码的像素宽度 |
| 镜像模式 | 任意、镜像、非镜像 | — | 当采集图像为从镜像时（与实际图像颠倒），可选择镜像 |
| QR畸变 | 畸变、非畸变 | — | 二维码打印在瓶体上或类似物流的软包上有褶皱时，可选择畸变 |
| 超时退出时间 | ms | — | 设置为0时不限制模块运行时间；超出设置值则识别失败，模块不输出字符信息 |
| 应用模式 | 普通模式、专家模式、极速模式 | — | 普通：一般场景；专家：二维码较难识别的场景；极速：识别效率最高但识别能力较弱，适用于单一类型的读码场景——该模式下极性、边缘类型和DM码类型等参数需设置为场景中对应类型，若设置为兼容模式，则极速模式不生效 |
| DM码类型 | 正方形、长方形、兼容模式 | — | 选择兼容模式时，模块能够识别正方形和长方形的DM码 |

**模型相关**：不适用（传统算法，无模型）。

**使用步骤**：
1. 算法工作步骤（原理）：通过二维码纹理信息定位候选区域 → 计算二维码梯度并局部旋正 → 定位二维码功能图形，获取最小模块大小、二维码版本号等信息 → 建立采样网络 → 基于采样网络提取每个最小模块的数据 → 依据二维码编码原理获取二维码所含信息。
2. 流程中前序搭配图像源、仿射变换、形态学处理等模块。
3. 开启对应码制（QR码/DataMatrix码），按场景设置极性、边缘类型、应用模式等参数。
4. 后序模块可将二维码字符和位置信息输入至定位、通信等模块。

**注意事项**：
- 二维码由固定种类的功能图案（定位图案、校正图案和参考网格）及不同数量的最小模块构成，每个最小模块用于表示1bit数据。
- 若要识别所有出现的二维码，二维码个数可设置为场景中二维码个数最大值。
- 一般码有4个角点，不同码制的顶点规则和标准有所差异，具体请以实际为准。

### DL字符定位

**功能**：通过神经网络提取输入图像中的文本位置信息，定位图像中的字符区域；在文本背景复杂或位置不固定的场景中可较准确地定位字符位置，对每个定位结果输出置信度评分。

**输入**：

| --- | --- | --- |
| 图像 | image | 前序模块可为图像源；需确保字符高度和输入图像长边的比值大于2.5%（如800×600图像，字符高度需至少为20像素） |

**输出**：

| 输出项 | 类型 | 说明 |

- 字符集：不涉及（仅定位，不识别内容）。
- 置信度阈值：通过"最小分数"参数过滤预测框；文本对比通过"最小相似度"过滤。

**使用步骤**：
1. 前序接图像源模块；确保字符高度与输入图像长边的比值大于2.5%。
2. 若占比不满足需求，可通过轮廓匹配、Blob分析、位置修正、仿射变换等模块裁剪输入图像。
3. 配置模型文件路径（内置或自训模型），按需开启方案存模型、获取模型ROI、按ROI裁图。
4. 设置最大查找个数、最小分数、最大重叠率及高级参数（目标排序、缩放系数、边缘筛选使能）。
5. 按需开启文本对比（注册模型文件或手动注册：添加图像→自动标注或手动标注→注册→调整结果文本数和最小相似度）与字符角度/宽度/高度使能过滤。
6. 后序常搭配 DL字符识别，后者订阅本模块输出的字符位置信息并识别字符内容。

**注意事项**：
- 置信度得分越高，则该定位框是文本区域的可能性越大。
- 若输入图像的字符占比不满足需求，可通过轮廓匹配、Blob分析、位置修正、仿射变换等模块裁剪输入图像。

- 字符集：内置模型支持英文（textrec_*_en.bin）与中文（textrec_*_ch.bin）；支持点阵等各类常规字体，部分字体（例如花体）可能不支持，需自行训练对应模型。
- 置信度阈值：通过"最小置信度"参数过滤。
- 训练建议：训练图像应至少使用10~20张；训练图像应包含实际检测场景中可能出现的所有字符（如大小写英文字母及0~9数字）；检查训练集标注质量；训练参数参见 VisionTrain 或 AI训练平台的用户手册。

**使用步骤**：
1. 工作流程（原理）：提取图像语义特征（卷积提取不同层级语义信息）→ 提取文字序列特征（借助LSTM层将语义特征转化为文字序列特征）→ 输出结果（将文字序列转化为字符信息）。
2. 前序模块提供字符定位信息：传统方式（轮廓匹配、Blob分析等，需确保匹配特征稳定且与字符位置关系固定）或 DL字符定位（需确保字符高度与输入图像长边的比值大于2.5%）。
3. 按语言与速度/精度需求选择模型文件（推荐一般场景使用 DL字符识别C）。
4. 设置最小置信度、最小翻转分数、最大文本行数；按需配置字符校验规则过滤易混淆字符。
5. 后序模块可为字符比较等模块，对比字符信息与标准字符信息。
6. 弯曲字符场景：可通过圆环展开等图像处理模块展开字符后调用该模块识别；若无法展开字符，建议调用 DL单字符检测分别识别每一个字符。

**注意事项**：
- 若需识别单字符，建议调用 DL单字符检测。
- 内置模型识别结果不佳时：检查 DL字符定位输出文本框是否正常（过小会导致识别字符不完整）；通过字符校验针对易混淆字符（如数字0和字母O、数字1和大写字母I、大写字母V和小写字母v）设置校验规则；检查输入图像质量（字符应清晰、完整）；检查字体（花体等需自训模型）。
- 自行训练的模型识别结果不佳时：检查训练图像数量（至少10~20张）、是否覆盖所有可能出现字符、标注质量、训练参数是否合理。
- 该类型算法模型较为轻量，一般场景中推荐使用 DL字符识别C。

| 字符过滤-设置字符类型 | 全部、数字（0~9）、大写字母（A~Z）、小写字母（a~z）、特殊字符、空格、自定义 | — | 按设置的字符类型过滤输出结果；特殊字符的覆盖范围为自定义字符类型中的特殊字符；自定义可根据需求对已有字符库中的字符选择组合形式 |
| 文本宽度使能 | 开/关 + 宽度范围 | — | 预测结果框宽度超出设置的宽度范围则舍弃 |
| 文本高度使能 | 开/关 + 高度范围 | — | 预测结果框高度超出设置的高度范围则舍弃 |

**模型相关**：
- 模型来源：内置简易模型（背景干扰少、字符对比度高的简单场景）；不满足时可使用 AI训练平台自行训练模型，通过模型文件路径加载并开启方案存模型。
- 字符集：通过"设置字符类型"过滤（数字0~9、大写字母A~Z、小写字母a~z、特殊字符、空格、自定义）。
- 置信度阈值：通过"最小置信度"参数过滤。
- 训练建议：训练前检查采集图像中文字是否容易分辨；若需裁剪输入图像和使用自行训练的模型，建议基于裁剪后的图像进行标注和模型训练。

**使用步骤**：
1. 溯源信息场景：前序搭配图像源模块，识别和保存字符。
2. 校验打印字符场景：后序调用字符比较模块接收识别的文本信息，与标准字符内容比较。
3. 在图像源模块后可调用 Blob分析、仿射变换等模块预处理输入图像（字符占比越大识别效果越好）。
4. 配置模型文件路径，设置最大查找个数、最小置信度、最大重叠率及高级参数。
5. 按需开启字符过滤（字符校验、字符类型）与文本宽度/高度使能。

**注意事项**：
- 该模块与 DL字符识别的用途基本一致，但 DL单字符检测整合定位和识别功能，适用于环形文本、文本行不规整字符的定位和识别。
- 训练模型前建议先检查采集图像中文字是否容易分辨，否则需调整成像质量。

### 字符识别

**功能**：通过字库训练达到识别图片中字符的作用（无需深度学习训练），输出第一可能识别结果和候选识别结果；常用于字符种类较少、字符位置较稳定且成像清晰的识别场景。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序模块可搭配几何变换、形态学处理等图像处理模块对字符效果优化，将字符清晰的图片输入 |

**输出**：

| 输出项 | 类型 | 说明 |

| 耗时（ms） | float | 该模块运行时耗费的时间 |
| 模块状态 | int | 0代表NG；1代表OK |
| 识别结果数量 | int | 识别的字符集合的个数 |
| 字符个数 | int | 每个文本框中检测到的字符串的字符个数 |

**使用步骤**：
1. 字库训练：① 框选目标字符区域；② 单击提取字符，出现已被红色框分割的字符（原文为图示，文字缺失：分割效果示意）；③ 单击训练字符，输入对应的字符真值，并单击添加至字符库完成训练；若识别不准确可重复训练。

**注意事项**：
- 该模块无固定搭配使用模块；前序模块可搭配几何变换、形态学处理等图像处理模块对字符效果优化。
- 自定义字符应存在于字符库中。

### ML分类

**功能**：预测输入图像的类别；基于传统机器学习方式，通过提取的图像特征和人为标注信息训练分类模型，并使用该模型推理输入图像类别，广泛用于物体识别和分拣。与 DL分类的差别在于：ML分类基于机器学习实现，DL分类基于深度学习实现。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 通常搭配图像源模块，由其传输需分类的图像 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 检测区域 | box | 检测 ROI 区域（中心点X/Y、宽度、高度、角度） |
| 模块状态 | int | 0代表NG；1代表OK |
| 预测信息个数 | int | 获取的分类个数 |
| 标签索引 | int | 获取的分类的索引（数组，长度等于预测信息个数） |
| 标签名 | string | 获取的分类的名称（数组，长度等于预测信息个数） |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 最大迭代次数 | int | — | 拟合算法的最大执行次数 |
| 最小迭代误差 | float | — | 当训练器迭代的误差小于该数值时，则停止训练 |
| 分类器类型 | SVM分类器、RF分类器 | — | SVM（支持向量机）：确定一个分类超平面分隔不同类别，适用于训练样本较少、类内差异较小、类间差距较大的场景；RF（随机森林）：集成多个决策树分类，适用于训练样本较多、类别较多的场景，相较于SVM可应用类内差异稍大一些的场景 |
| 纹理特征 | 开/关 | — | 开启后可设置图像的纹理特征；纹理特征和灰度特征需至少开启其中一种 |
| HOG | 开/关 | — | 基于图像局部区域的梯度方向直方图统计信息，对边缘和纹理敏感；适用于每一类图像具有固定几何形状或轮廓、类间形状差异明显、姿态固定的样本 |
| LBP | 开/关 | — | 描述图像局部纹理特征的算子，具有灰度不变性和旋转不变性；适用于类内有稳定纹理分布、类间纹理差异明显的场景 |
| GLCM | 开/关 | — | 灰度共生矩阵，描述两个像素灰度的联合分布；适用于类内有固定或相近纹理分布、且类内纹理不考虑姿态的场景 |
| 边缘密度 | 开/关 | — | 基于图像边缘像素点数量及其分布的特征；适用于类内纹理分布密度较稳定、类间差异明显的场景 |
| 极坐标投影 | 开/关 | — | 图像转换到极坐标后做水平和垂直投影，将一维向量作为特征；适用于类内样本水平/竖直方向纹理分布一致、类间差异显著的场景 |
| 灰度特征 | 开/关 | — | 开启后可设置图像的灰度特征；纹理特征和灰度特征需至少开启其中一种 |
| 灰度范围 | 开/关 | — | 图像像素灰度值的范围；适用于具有固定最大灰度值差异或最小灰度值界限的不同类别样本 |
| 灰度均值 | 开/关 | — | 图像像素灰度值的平均值 |
| 灰度方差 | 开/关 | — | 图像像素灰度值的方差 |
| 灰度能量 | 开/关 | — | 图像像素灰度级别的平方和，反映纹理信息整体强度和均匀程度；对纹理分布的姿态不敏感 |
| 各向异性 | 开/关 | — | 反映图像在不同方向上的灰度变化程度 |
| 水平投影 | 开/关 | — | 二维图像在水平方向上灰度值求和得到的投影 |
| 垂直投影 | 开/关 | — | 二维图像在垂直方向上灰度值求和得到的投影 |
| 灰度直方图 | 开/关 | — | 各灰度级像素出现的频率与灰度级的关系；适用于类内灰度分布相同或相近、类间灰度差异显著的场景 |
| 模型文件路径 | 模型文件 | — | 选择之前训练生成的模型文件；若已通过分类训练注册则可不加载；若既完成分类训练也设置了模型文件路径，则优先使用加载的模型文件 |
| 方案存模型 | 开/关 | — | 开启后将模型数据保存到方案文件或流程文件中，跨机加载方案时不需要再输入模型文件路径 |

**模型相关**：
- 模型来源：通过模块内**分类训练**生成模型（bin 文件，可导出/导入）；也可加载已有模型文件。若既完成分类训练也设置了模型文件路径，则优先使用加载的模型文件。
- 字符集/类别：类别由用户在分类训练中手动添加并标注（类别名称自定义）。
- 置信度阈值：原文未给出参数表。
- 训练数据要求：标记图像至少应大于4张，类别应大于2种，每种类别的图像至少有2张图像，方可进行训练；标记的图像越多越好，可提高模块检测的正确性。

**使用步骤**：
1. 在流程中添加图像源和 ML分类模块，并将 ML分类模块连接至图像源模块。
2. 双击 ML分类模块，配置相应参数。
3. 在分类训练页签单击训练 → 添加图像类别（输入类别名称，可一次性添加多个类别）。
4. 添加需标记的图像：当前图像（订阅图像）/缓存图像/导入本地图像（每次只能导入一张）/导入文件夹/按类别导入文件夹（使用时应先选中图像需标记的类别）。
5. 选中需标记类别的图像，再选中对应的类别，完成单张图像的类别标记；重复完成多张标记。
6. 可选：清空已标记的图像类别或清空已添加的图像。
7. 配置训练参数（最大迭代次数、最小迭代误差、分类器类型、纹理特征、灰度特征），单击训练生成模型。
8. 训练完成后可将生成的模型以 bin 文件形式导出，也支持导入已训练的模型。
9. 执行流程进行分类。

**注意事项**：
- 纹理特征和灰度特征需至少开启其中一种。
- 归类样本图时需准确地对具有代表性的样本图进行分类，以确保训练出的分类模型具备良好的分类性能。
