# VM 模块参考：图形生成

## 速览

| 模块 | 一句话 | 典型用途 |
|---|---|---|
| 圆拟合 | 将一组特征点（至少 3 个）拟合成一个圆，先检测有效特征点形成点集后再拟合 | 圆查找提取特征点之后；圆的测量、工件标准检测、车道检测 |
| 椭圆拟合 | 将一组特征点（至少 5 个）拟合成一个椭圆，先检测有效特征点形成点集后再拟合 | 椭圆查找提取特征点之后；椭圆的测量、工件标准检测、轨道检测 |
| 直线拟合 | 基于两个及以上的已知点拟合成一条直线，先检测顶点再拟合 | 直线查找提取特征点之后；直线的测量、宽度检测、车道检测 |
| 几何创建 | 自由创建或继承点、线、圆和矩形 | 检测或测量应用中作为基础标准配合检测；图形定位较难时自行创建图形 |

### 圆拟合

**功能**：将一组特征点拟合成一个圆，不能拟合成多个圆，往往用在圆查找提取特征点之后的阶段。使用前提是输入的特征点（至少为 3 个点）能大致组成一个圆。可用于圆的测量。

**原理**：根据初始拟合方式得到初始圆，然后根据不同的权重函数迭代进行拟合，直到拟合结果满足要求。拟合过程中会根据剔除的点数和剔除的距离舍弃偏离的点，所以具有部分抗干扰点的能力。（原文为图示，文字缺失：圆拟合示意图——紫色点为输入特征点，拟合后得到绿色圆。）

**输入**：

| 输入项 | 类型 | 说明 |
|---|---|---|
| 图像输入（输入源） | 图像 | 可选择前序模块的图像数据；该参数可不设置 |
| 拟合点 | 点集 | 选择流程中采集到的点集作为拟合来源；可通过输入方式参数选择按点或按坐标方式订阅点的数据 |

**输出**：

| 输出项 | 类型 | 说明 |
|---|---|---|
| 耗时（ms） | float | 模块运行耗费的时间 |
| 模块状态 | int | 0 代表 NG（模块呈红色）；1 代表 OK（模块呈绿色） |
| 输出圆环 | annull | 查找到的圆，记录圆心、内径和角度等信息 |
| — 输出圆环.圆心 | point | 圆心坐标（圆心X/圆心Y，float） |
| — 输出圆环.内径 | float | 圆的内径 |
| — 输出圆环.圆半径 | float | 圆的半径 |
| — 输出圆环.圆起始角度 | float | 圆起始边与水平方向的夹角 |
| — 输出圆环.圆角度范围 | float | 圆起始边与终止边跨过的角度范围 |
| 输出拟合点 | point | 每一个输出的拟合点（输出拟合点X/Y，float） |
| 拟合误差 | float | 描述拟合图形的准确性，越小越好 |
| 拟合状态 | int | 1 代表存在拟合图形，0 代表不存在 |
| 拟合点数 | int | 用于拟合的输入点数 |
| 拟合距离 | float | 拟合点与生成拟合图形之间的最近距离 |
| 匹配点 | int | 每一个输入点的匹配状态：0 不用于拟合，1 用于拟合 |
| 匹配点数 | int | 匹配点为 1 的点个数 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
|---|---|---|---|
| 输入源 | 前序模块图像数据 | （原文为图示，文字缺失） | 可不设置 |
| 拟合点 | 按点 / 按坐标 | （原文为图示，文字缺失） | 通过输入方式参数选择订阅点数据的方式 |
| 剔除点数 | （原文为图示，文字缺失） | （原文为图示，文字缺失） | 误差过大而被排除不参与拟合的最小点数量；离群点越多该值应越大，建议与剔除距离结合使用 |
| 剔除距离 | （原文为图示，文字缺失） | （原文为图示，文字缺失） | 允许离群点到拟合直线的最大像素距离，值越小排除点越多 |
| 初始化类型 | 全局法 / 局部最优 | （原文为图示，文字缺失） | 局部最优：按局部特征点拟合圆，若局部特征更准确反映圆位置则采用，否则采用全局最优；全局法：以全局特征点进行圆拟合 |
| 权重函数 | 最小二乘 / huber / tukey | （原文为图示，文字缺失） | 三种方式只是权重计算方式有差异；随离群点数量增多及离群距离增大，可逐次使用最小二乘、huber、tukey |
| 最大迭代次数 | （原文为图示，文字缺失） | （原文为图示，文字缺失） | 拟合算法的最大执行次数 |

**使用步骤**：
1. 由前序模块（如圆查找）提取特征点；
2. 通过 group 找到工件的所有顶点，并通过点集收集传给圆拟合；
3. 配置拟合点等参数后运行，对拟合圆的状态信息进行评估，检测该组特征点是否符合标准要求。

**注意事项**：
- 输入特征点至少为 3 个点，且能大致组成一个圆；
- 不能拟合成多个圆；
- 剔除点数与剔除距离建议结合使用以获取更佳效果。

### 椭圆拟合

**功能**：将一组特征点拟合成一个椭圆，不能拟合成多个椭圆，往往用在椭圆查找提取特征点之后的阶段。使用前提是输入的特征点（至少为 5 个点）能大致组成一个椭圆。可用于椭圆的测量。

**原理**：先检测有效特征点，形成点集后再拟合成椭圆。（原文为图示，文字缺失：椭圆拟合示意图——绿色和红色点为输入特征点，绿色为最终参与拟合的特征点，红色为被删除的特征点，绿色椭圆为拟合结果。）

**输入**：

| 输入项 | 类型 | 说明 |
|---|---|---|
| 拟合点 | 点集 | 选择流程中采集到的点集作为拟合来源；可通过输入方式参数选择按点或按坐标方式订阅点的数据 |

**输出**：

| 输出项 | 类型 | 说明 |
|---|---|---|
| 耗时（ms） | float | 模块运行耗费的时间 |
| 模块状态 | int | 0 代表 NG（模块呈红色）；1 代表 OK（模块呈绿色） |
| 输出椭圆 | — | 含以下子项 |
| — 输出椭圆.圆心点 | point | 椭圆圆心点（中心X/中心Y，float） |
| — 输出椭圆.椭圆长半轴 | float | 椭圆的长半轴长度 |
| — 输出椭圆.椭圆短半轴 | float | 椭圆的短半轴长度 |
| — 输出椭圆.椭圆角度 | float | 椭圆的角度 |
| 输出拟合点 | point | 每一个输出的拟合点（输出拟合点X/Y，float） |
| 拟合误差 | float | 描述拟合图形的准确性，越小越好 |
| 拟合状态 | int | 1 代表存在拟合图形，0 代表不存在 |
| 拟合点数 | int | 用于拟合的输入点数 |
| 匹配点 | int | 每一个输入点的匹配状态：0 不用于拟合，1 用于拟合 |
| 匹配点数 | int | 匹配点为 1 的点个数 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
|---|---|---|---|
| 拟合点 | 按点 / 按坐标 | （原文为图示，文字缺失） | 通过输入方式参数选择订阅点数据的方式 |
| 误差容忍度 | （原文为图示，文字缺失） | （原文为图示，文字缺失） | 拟合时计算每个参与拟合边缘点的拟合误差；该值越小，删除掉的边缘点越多，拟合结果更准确，但设置过小可能造成过拟合 |

**使用步骤**：
1. 一般与点集模块配合使用；
2. 示例：通过直线查找找到四个特征点，再通过几何创建建立中点，将五个点共同输入点集，拟合成一个椭圆；
3. 通过拟合椭圆的状态信息评估该组特征点是否符合标准要求（如判断十字中心是否符合要求）。

**注意事项**：
- 输入特征点至少为 5 个点，且能大致组成一个椭圆；
- 不能拟合成多个椭圆；
- 误差容忍度过小有可能造成过拟合。

### 直线拟合

**功能**：将一组特征点拟合成一条直线，不能拟合成多条直线，往往用在直线查找提取特征点之后的阶段。使用前提是输入的特征点（至少为 2 个点）能大致组成一条直线。可用于直线的测量。

**原理**：基于两个及以上的已知点，先检测顶点再拟合成直线。根据初始拟合方式得到初始直线，然后根据不同的权重函数迭代进行拟合，直到拟合结果满足要求。拟合过程中会根据剔除的点数和剔除的距离舍弃偏离的点，所以具有部分抗干扰点的能力。（原文为图示，文字缺失：直线拟合示意图——紫色点为输入特征点，拟合后得到绿色直线。）

**输入**：

| 输入项 | 类型 | 说明 |
|---|---|---|
| 图像输入（输入源） | 图像 | 可选择前序模块的图像数据；该参数可不设置 |
| 拟合点 | 点集 | 选择流程中采集到的点集作为拟合来源；可通过输入方式参数选择按点或按坐标方式订阅点的数据 |

**输出**：

| 输出项 | 类型 | 说明 |
|---|---|---|
| 耗时（ms） | float | 模块运行耗费的时间 |
| 模块状态 | int | 0 代表 NG（模块呈红色）；1 代表 OK（模块呈绿色） |
| 输出直线 | — | 含以下子项 |
| — 输出直线.直线起点 | point | 直线起点（直线起点X/Y，float） |
| — 输出直线.直线终点 | point | 直线终点（直线终点X/Y，float） |
| 直线角度 | float | 输出直线的角度 |
| 输出拟合点 | point | 每一个输出的拟合点（输出拟合点X/Y，float） |
| 拟合误差 | float | 描述拟合图形的准确性，越小越好 |
| 拟合状态 | int | 1 代表存在拟合图形，0 代表不存在 |
| 拟合点数 | int | 用于拟合的输入点数 |
| 拟合距离 | float | 拟合点与生成拟合图形之间的最近距离 |
| 匹配点 | int | 每一个输入点的匹配状态：0 不用于拟合，1 用于拟合 |
| 匹配点数 | int | 匹配点为 1 的点个数 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
|---|---|---|---|
| 输入源 | 前序模块图像数据 | （原文为图示，文字缺失） | 可不设置 |
| 拟合点 | 按点 / 按坐标 | （原文为图示，文字缺失） | 通过输入方式参数选择订阅点数据的方式 |
| 剔除点数 | （原文为图示，文字缺失） | （原文为图示，文字缺失） | 误差过大而被排除不参与拟合的最小点数量；离群点越多该值应越大，建议与剔除距离结合使用 |
| 剔除距离 | （原文为图示，文字缺失） | （原文为图示，文字缺失） | 允许离群点到拟合直线的最大像素距离，值越小排除点越多 |
| 初始化类型 | 全局法 / 局部最优 | （原文为图示，文字缺失） | 局部最优：按局部特征点拟合直线，若局部特征更准确反映直线位置则采用，否则采用全局最优；全局法：以查找到的全局特征点进行拟合 |
| 权重函数 | 最小二乘 / huber / tukey | （原文为图示，文字缺失） | 三种方式只是权重计算方式有差异；随离群点数量增多及离群距离增大，可逐次使用最小二乘、huber、tukey |
| 最大迭代次数 | （原文为图示，文字缺失） | （原文为图示，文字缺失） | 拟合算法的最大执行次数 |
| 角度拟合约束 | 开 / 关 | （原文为图示，文字缺失） | 开启后根据期望直线角度和直线角度容忍范围判断直线角度是否符合要求。示例：期望直线角度设为 10、直线角度容忍范围设为 20，则直线角度在 -10° ~ 30° 之间为符合要求 |

1. 由前序模块（如直线查找）提取特征点；

**注意事项**：
- 输入特征点至少为 2 个点，且能大致组成一条直线；
- 不能拟合成多条直线；
- 剔除点数与剔除距离建议结合使用以获取更佳效果。

### 几何创建

**功能**：自由创建或继承相关的点、线、圆和矩形。常应用于检测或测量应用中，作为基础标准配合检测。当有些图形定位较难时，可通过鼠标移动或修改 X、Y 坐标来改变生成图形的位置（如圆查找不好定位的白色圆轮廓可自行创建）。

**输入**：

| 输入项 | 类型 | 说明 |
|---|---|---|
| 输入源 | 图像 | 订阅前序模块输出的图像 |

**输出**：

| 输出项 | 类型 | 说明 |
|---|---|---|
| 耗时（ms） | float | 模块运行耗费的时间 |
| 模块状态 | int | 0 代表 NG（模块呈红色）；1 代表 OK（模块呈绿色） |
| 点个数 | int | 创建点的个数 |
| 直线个数 | int | 创建直线的个数 |
| 圆个数 | int | 创建圆的个数 |
| 矩形个数 | int | 创建矩形的个数 |
| 输出点 | point | 输入点旋转后得到的点（输出点X/Y，float；采用的图像坐标系为左手坐标系） |
| 输出直线 | — | 起点（起点X/Y，float，代表数组）、终点（终点X/Y，float，代表数组） |
| 直线角度 | float | 输出直线的角度 |
| 输出圆 | — | 圆心（point，圆心X/Y）、内径（float）、半径（float，代表数组）、起始角度（float，代表数组，默认为 0）、角度范围（float，代表数组，默认为 360） |
| 输出矩形 | — | 矩形中心点（中心点X/Y，float）、矩形宽度（float，最小外接矩形的宽度）、矩形高度（float，最小外接矩形的高度）、矩形角度（float，由码的点 0 和点 1 所连直线与水平线夹角构成，顺时针为正，逆时针为负） |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
|---|---|---|---|
| 输入源 | 前序模块图像 | （原文为图示，文字缺失） | 订阅前序模块输出的图像 |
| 输入类型 | 绘制 / 订阅 | （原文为图示，文字缺失） | 选择绘制图像的输入类型 |
| 输入类型=绘制：形状 | 矩形 / 点 / 直线 / 圆 | （原文为图示，文字缺失） | 选择形状图标后在预览图像中绘制：矩形——鼠标绘制后可移动或修改中心点 X/Y、宽、高和角度；点——鼠标单击生成后可移动或修改 X/Y；直线——鼠标拖动生成后可移动端点或修改端点 X/Y；圆——鼠标单击生成后可移动或修改 X/Y。均可配合位置修正使用 |
| 输入类型=订阅 | 图形类型：点 / 线 / 圆 / 矩形 | （原文为图示，文字缺失） | 订阅前序模块中的图形或参数，选择对应图形类型和输入方式并订阅 |
| 位置修正 | 开 / 关 | （原文为图示，文字缺失） | 使用时需确保前序模块中有位置修正模块，相关功能和原理参见位置修正章节 |
| 位置修正.选择方式 | 按信息 / 按点 / 按坐标 | （原文为图示，文字缺失） | 位置修正信息的获取方式；无论选择哪种方式，均需订阅相关参数 |

**使用步骤**：
1. 订阅前序模块输出的图像作为输入源；
2. 选择输入类型：绘制（选形状后在预览图中绘制）或订阅（选择图形类型和输入方式后订阅前序模块的图形或参数）；
3. 如需跟随定位，开启位置修正并设置选择方式、订阅相关参数（前序需有位置修正模块）；
4. 生成的图形作为基础标准配合检测或测量使用。

**注意事项**：
- 使用位置修正时，需确保前序模块中有位置修正模块；
- 输出点采用的图像坐标系为左手坐标系；
- 矩形角度的顶点规则：一般码有 4 个角点，按顺序分别为点 0、点 1、点 2、点 3，不同码制的顶点规则和标准有所差异，具体请以实际为准。
