# VM 应用手册：调试运行 · 工具 · 问题排查

## 速览

- 调试方案前需确认相机正常取图、检测精度满足业务需求、VM 能正常与设备通信。
- 图像显示区域展示「模块/流程输出图像」与「模块输出结果」，支持图像切换（下拉框）与图像叠加（勾选）。
- 模块图像功能：单/双画面切换、十字辅助线、本地图配置（区域①~④）。
- 结果显示区域内容随选中实体变化：模块 / 全局相机 / 数据队列；支持右键清空或保存结果。
- 综合配置窗口整合「综合参数设置 / 图像显示 / 输出结果」三区，便于统一调试。
- 运行单个方案：运行界面运行（可选「运行控制」控件），或导出程序（exe / vmCodeProject / wpf / winform）。
- 自动切换方案：设置 > 方案设置 > 方案管理，配置方案路径 + 通信字符串 + 通信切换，与工控机绑定。
- 软件通用设置：权限设置、软件设置（启动关闭/撤销重做/高级）、方案设置、运行策略、采集策略（大文件存图）。
- 标定配置引导支持 3 种类型：静态标定、动态标定、映射标定（均为步骤引导式）。
- 工具入口分两类：菜单栏「工具」选项，或 `VM安装路径\Applications\Tools` 文件夹下的 exe。
- 异常信息收集可检测系统匹配、VM 环境、SDK 引用、日志调整与日志收集。
- 版本切换工具（VersionSwitchingAssistant.exe）支持 4.2 及以上与其他版本切换（4.4.0 维护版2025.04起不再更新，推荐激活工具）。
- 加密狗写密码工具（SetDonglePassword.exe）密码 6~16 字符，加密后方案仅可在「插加密狗且密码一致」环境打开，密码无法找回。
- 存图大数据解压工具（DecompressionTool.exe）解压大文件存图生成的 .dat 文件。
- 激活工具（ActivationTool.exe）自动激活当前目录对应 VM 版本（仅 2025.04 及之后发布的 V4.4.0 维护版支持）。
- 单台工控机可装多套 VM，运行默认最近安装版本；本机加密狗仅可接入 1 个加密狗。
- 安装/启动/使用问题排查：GAC 注册异常、环境变量异常、加密狗异常、动态库加载失败等。

## 1. 方案调试与运行

### 1.1 调试方案（图像显示区域 / 查看模块图像 / 模块图像相关功能 / 查看流程图像 / 查看模块结果 / 结果显示区域 / 综合配置）

在最终向客户交付方案之前，需先在模拟环境中完成方案的试运行与初步调试，之后还需在业务现场运行并调试，直至运行效果满足业务现场的检测需求。

若方案试运行结果不理想，可调试模块基本参数、运行参数、模型配置、多流程配置、全局配置和设备配置等。可根据主界面图像显示区域和结果显示区域所显示的图像渲染和运行结果信息调试模块参数和方案设计；也可通过综合配置将各个流程的运行参数、图像数据和输出参数整合到同一个配置界面，方便调试和查看调试效果。

调试方案时需重点关注：

1. 确认相机能够正常取图，且取图质量满足业务场景需求。
2. 方案的检测精度满足业务需求。检查模块 ROI 设置、运行参数取值以及模型精度。（如需调试运行参数，可参考模块使用参考中对应模块的参数配置章节，调整参数选项或参数取值。以平行线查找模块的边缘阈值参数为例：参数值过大，可能导致模块过滤目标边缘，导致查找失败。）
3. 确保 VM 能正常与视觉系统中的设备通信。

#### 查看模块图像

模块图像指流程中某个模块输入或输出的图像，支持在主界面的图像显示区域查看。前提：已完成流程配置（模块排布连接和各模块参数配置）。

操作步骤：

1. 在主界面快捷工具条区域，单击运行相关图标（或对应按钮）；也可在主界面流程栏单击对应图标执行流程。
2. 在主界面流程编辑区，单击目标模块。执行成功的模块，可在右侧图像显示区域查看该模块输出的图像。

图像显示区域支持图像切换和图像叠加：

- **图像切换**：图像显示区域可切换图像数据类型，在图像显示区域左上角下拉框中可选择目标图像数据类型进行切换。选中某个模块后，可切换的图像类型包括「当前选中模块所输出的图像」和「所有前序模块输出的图像」（如下图所示，原文为图示）。
- **图像叠加**：不同图像数据类型可叠加显示，在图像切换下拉框中勾选目标图像数据类型前的复选框，即可叠加显示当前勾选的图像数据。

在图像显示区域还可对图像进行单/双画面切换、添加十字辅助线、本地图配置等操作。图像显示区域如下图所示（原文为图示）。

上图各区域功能如下表：

| 区域序号 | 说明 |
| --- | --- |
| ① | 单击选择在区域③（预览窗口）显示的图像数据。单画面显示模式下，可选择当前模块所有输入和输出的图像，并可多选进行叠加显示；双画面显示模式下，左侧预览窗口仅可选择当前模块输入源订阅的图像数据，右侧预览窗口与单画面模式下支持显示的功能一致。 |
| ② | 可对预览窗口进行预览相关操作，从左至右的图标依次表示「切换画面数量」（切换单/双画面模式）、「十字辅助线配置」、「放大」、「缩小」、「自适应」和「全屏显示」。 |

**十字辅助线配置**：单击区域②中的十字辅助线配置图标打开十字辅助线窗口，可在该窗口开启并设置两个互不干涉的十字辅助线（如下图所示，原文为图示）。各参数说明：

- 十字辅助线1/2：启用后，图像预览窗口显示对应的十字辅助线。
- 坐标X/Y：十字辅助线交叉点在图像中对应的 x 轴和 y 轴坐标。
- 粗细：设置十字辅助线的粗细程度，数值越大越粗。
- 颜色：设置十字辅助线的颜色。
- 显示：单击「居中」可将十字辅助线的交叉点移动至图像的中心点。
- 锁定：开启后，将无法直接在预览画面上拖动十字辅助线。（若未开启锁定，可单击交叉点激活拖动功能后直接拖动调整位置，拖动过程中坐标 X/Y 数值同步更新，详见动图，原文为图示。）

**本地图像配置**：当在图像源模块中选择本地图作为图像源时，区域④显示。各界面功能：

- 添加本机或局域网内共享的图像；
- 添加本地文件夹或局域网内共享文件夹内的所有图像；
- 将已添加的图像全部删除；
- 显示已添加图像中的第一张图像；
- **自动切换**：一般与运行全部/运行选中配合使用。
  - 开启自动切换且开启运行全部，单击快捷工具条连续执行流程时，可自动切换所有已添加本地图并连续执行流程；
  - 开启自动切换且开启运行选中，连续执行时仅自动切换选中的本地图；
  - 关闭自动切换，单击连续执行时仅对单张本地图连续执行流程。
- 运行全部/运行选中：说明同上。

#### 查看流程图像

流程图像指多流程模式下，某个流程被成功执行后最终输出的图像。前提：已完成流程配置。

操作步骤：

1. 在主界面流程栏单击对应按钮进入所有流程页面。
2. 配置流程图像：
   1. 在所有流程页面，单击目标流程小窗口上的设置图标（流程设置，原文为图示）。
   2. 在流程窗口，单击「显示设置」。
   3. 在显示设置页签的「参数名称」列，选择「输出图像 >」（如需同时显示模块图像和数据，参数名称选择多选，批量勾选目标图像和数据，原文为图示）。
   4. 在「关联关系」列，单击关联图标（订阅关联关系，原文为图示）。
   5. 在订阅列表中，双击选择流程最终输出的图像。
   6. 在流程窗口右下角，单击「确定」。
3. 在所有流程页面，单击目标流程小窗口上的运行图标，在图像显示区域即可查看流程图像（如下图所示，原文为图示）。还可进行添加十字辅助线、缩放、全屏显示等操作。

#### 查看模块结果

图像显示区域的「模块结果」页签显示所选模块或所选流程的输出数据。

- 选中模块某个输出参数后，下方显示 SDK 中与该输出参数对应的信息（`VmSolution.Instance` 表示方案实例，如 `BlobNum` 即 blob 个数）。可单击复制图标复制该信息，用于二次开发结果获取（原文为图示）。
- 可单击变量管理列的关联图标，选择全局/局部变量，将其与对应的结果数据绑定。

#### 结果显示区域

结果显示区域呈现流程中模块对输入数据的处理结果，还附带：配置全局相机常用参数、查看所选模块帮助信息、一键清空或保存结果信息。该区域显示内容根据流程编辑区选中实体类型有所区别：

**选中某个模块时**

- 选中采集或逻辑工具模块时：执行流程时显示模块数据处理的历史结果（采集类模块当前结果即输出图像已在预览窗口实时展示，逻辑工具类输出为流程走向/判断结果，均不在此处实时展示）。历史结果含执行序号、执行时间和模块数据（原文为图示）。
- 选中其他模块时：显示模块数据处理的当前结果和历史结果（以 Blob 分析模块为例，原文为图示）。

**选中全局相机时**：可在结果显示区配置全局相机的常用参数（原文为图示）。

**选中某个数据队列时**：可查看数据队列接收到的各队列数据（原文为图示）。

**帮助信息**：选中模块、全局相机或数据队列，均可查看对应简要帮助信息（Blob 分析 / 全局相机 / 数据队列，原文为图示）。

**快捷操作**：结果显示区域支持一键清空或保存所有结果信息。右键单击该区域任意位置并选择清空或保存。

#### 综合配置

综合配置窗口将各个流程的运行参数、图像数据和输出参数整合到一起，便于快速查看关键参数调整后的效果。单击快捷工具条的综合配置图标，屏幕显示综合配置窗口，分为综合参数设置、图像显示和输出结果三个区域（原文为图示）。

| 区域 | 功能说明 |
| --- | --- |
| 综合参数设置 | 统一查看方案中各流程设置的运行参数并修改，修改实时生效。仅显示已设置的自定义流程运行参数；若未设置，则该区域不显示内容。需先完成至少一个流程的自定义运行参数设置。 |
| 图像显示 | 左上角下拉选择图像源数据，切换查看不同图像源数据显示效果。在综合参数设置区选中某运行参数时，该区域可显示对应参数所在模块的图像。 |
| 输出结果 | 实时查看方案各流程设置的输出参数；可自定义显示一个/多个输出结果参数，单击图标可自定义勾选流程耗时参数或各流程输出参数。 |

### 1.2 运行单个方案

单个方案的正式运行分两种方式：直接在运行界面运行、导出程序运行。可在菜单栏「设置 > 运行策略」中设置 CPU、GPU、内存和网络使用率资源安排。

**在运行界面运行**（按是否已添加运行控制控件区分）：

- 已添加「运行控制」控件：单击主界面右上角运行模式切换至运行界面，单击运行控制运行方案。
- 未添加「运行控制」控件：在主界面单击连续运行方案图标，再单击主界面右上角运行模式切换至运行界面，方案在运行界面连续运行。

**导出运行界面并运行**：运行界面设计支持导出 C# 开发语言的程序，可直接运行或二次开发自定义，降低对计算机资源利用率。若已在「设置 > 权限设置」配置项中启用加密，需以管理员角色登录 VM，否则无法导出。

操作步骤：

1. 单击运行界面设计窗口右上角的「导出」。
2. 名称处输入自定义程序名称。
3. 图标处设置导出程序图标（仅支持 ico 格式，默认本公司软件 logo）。
4. 选择类型：可选 `exe`、`vmCodeProject`、`exe+vmCodeProject` 三种。
   - `exe`：仅导出生成程序；
   - `vmCodeProject`：仅导出工程文件和对应代码文件；
   - `exe+vmCodeProject`：以上程序和文件均导出。
5. 选择工程类型：可选 `wpf` 或 `winform`。
6. 存储路径处选择自定义路径。
7. 单击「导出」生成程序（整体耗时较长，请耐心等待）。

以名称 test、类型 exe+vmCodeProject、工程类型 wpf 导出后，文件夹下各文件含义如下（原文为图示）：可通过 `test.sln` 对运行界面二次开发，生成后的 exe 在 `public_release` 文件夹下，双击运行即可。

### 1.3 自动切换方案并运行

除手动运行，VM 支持自动切换并运行方案，适用于「通过通信设备自动控制方案运行」的业务场景。前提：已添加并配置通信设备。

操作步骤：

1. 进入方案自动切换配置界面：
   - 选项1：主界面菜单栏「设置 > 方案设置」；
   - 选项2：运行界面设计窗口单击右上角对应图标，选择「方案管理」（原文为图示）。
2. 配置方案切换数据：
   1. 单击方案路径输入框右侧图标选择需加载的方案文件。（若方案设密码，在方案密码输入框输入正确密码；未设则无需填写。）
   2. 在通信字符串输入框输入可触发方案切换的字符串内容。
      - 注意：字符串支持阿拉伯数字、字母和汉字，不支持符号；务必确保不同方案字符串内容不一致。
   3. 开启「通信切换」；若不开启，配置不生效（VM 收到字符串无法自动切换）。
3. （可选）单击图标添加更多方案配置数据，重复步骤 2。

VM 收到通信设备指定字符串后，在运行界面自动切换方案。

注意：该方案切换配置与工控机绑定，工控机 A 中设置的策略仅在 A 生效，不随方案在工控机 B 生效；更换工控机运行需重新配置。

## 2. 软件通用设置

通过菜单栏「设置」选项，调整 VM 软件全局生效的通用设置，包括权限、方案和运行策略等。

### 2.1 权限设置

权限设置可导入/导出权限信息（txt 格式），设置不同角色（管理员、技术员、操作员）的权限及密码。

- **权限导入导出**：以 txt 格式文档导入或导出当前权限设置模块配置。
- **启用加密**：打开后需设置管理员密码，启用管理员角色权限管理，软件以管理员角色登录并操作。点击「修改密码」处修改，输入旧密码和新密码即可完成。设置密码时数字或字母任意组合，长度 3~15 位（技术员、管理员密码均遵循此原则）。软件以管理员角色运行时可对所有功能设置，并可设置技术员和操作员权限。

**技术员权限设置**（仅管理员可设置）：技术员可配置管理员指定模块参数、编辑前端运行界面。

- 技术员权限：开启后可设置技术员密码和权限分配，软件以技术员角色登录。
- 技术员密码：原则与管理员密码一致。
- 权限分配：点击「配置」对技术员支持操作的工具模块自定义分配；勾选「开放所有工具」则所有工具模块均可配置（原文为图示）。

**操作员权限设置**（管理员和技术员均可设置）：操作员只能对前端运行界面按钮点击操作。

- 操作员权限：开启后可设置操作员密码和权限分配，软件以技术员角色登录并操作。
- 操作员密码：原则与管理员密码一致。
- 操作员使能：启用并以操作员身份登录运行界面时，控件可正常操作；否则只可查看不能操作。

**软件登录角色切换**：完成各角色设置后，软件右上角显示当前登录角色，点击当前角色选择「切换角色」并输入对应密码登录（原文为图示）。

### 2.2 软件设置

包括启动关闭设置、撤销重做设置、模块自动连线间距设置、高级设置。

**启动关闭设置**

| 设置项 | 说明 |
| --- | --- |
| 开机软件自启动 | 启用后，PC 开机时软件延时自动开启，在「延时启动」参数填写延时时间。 |
| 关闭软件密码 | 启用后，关闭软件需输入密码，弹窗中设置密码并单击确定保存。 |
| 隐藏欢迎页 | 启用后打开软件跳过欢迎页直接进入主界面（欢迎页勾选不再显示亦可开启）。 |
| 启动时最大化 | 启用后软件启动默认最大化。 |
| 启动时全屏 | 启用后软件启动默认全屏。 |
| 默认启动运行界面 | 启用后软件启动默认不显示主界面，直接打开运行界面。 |
| 运行界面独立启动时最大化 | 启用后最大化显示运行界面（仅在开启默认启动运行界面后生效）。 |
| 自动加载指定方案 | 启用后打开软件自动加载方案。需设：载入路径（选方案路径）、方案密码（加密方案需输入）、启动状态（非连续执行/连续执行）、选择身份（管理员/技术员/操作员，仅开启权限设置时可见）。 |
| 自动加载最近打开方案 | 启用后自动加载最近打开方案列表第一个方案，需设启动状态（非连续执行/连续执行）。 |

说明：自动加载指定方案 与 自动加载最近打开方案 功能互斥，不可同时使用。

- **非连续执行 + 开启高级设置静默执行**：默认加载方案后静默执行一次；未开启则不执行。
- **连续执行**：加载方案后连续运行。

**撤销重做设置**：缓存步数设置——设置撤销/重做功能最多缓存步数，上限 15 步。

**模块自动连线间距设置**：模块间距——设置模块间自动连线长度，上限 80 px。在某模块下方添加算法模块时，软件按长度自动提示连线位置。

**高级设置**

| 设置项 | 说明 |
| --- | --- |
| 模块最大数量 | 设置方案中允许拖入模块最大数量（需重启软件生效）。 |
| 静默执行 | 开启后设置手动加载方案运行是否启运一次静默执行（需重启生效）。 |
| 静默执行模块选择 | 开启静默执行后选择：深度学习和脚本模块 / 所有模块 / 深度学习模块 / 脚本模块。 |
| 修改参数自执行 | 开启后修改 ROI 或运行参数时自动展示模块图像效果（订阅参数不支持）。 |
| 修改模型自执行 | 开启后模型参数配置界面修改参数立即生效。 |
| 流程延时 | 设置流程执行完一次延时多久执行下一次。 |
| 图像高质量渲染 | 开启后关闭图像下采样，视觉更好但增加渲染耗时和 CPU 占用。 |
| 图形数量上限 | 设置单个渲染控件单次渲染图形数量上限，防止图形过多导致卡顿。 |
| 深度学习库预加载 | 开启可降低深度学习模块首次执行耗时。 |
| GPU锁频开启 | 稳定 GPU 耗时波动并一定程度降低运行耗时；可用 GPU锁频频率 设固定工作频率（100% 锁定最高频率，80% 锁定最高频率的 80%）。注意：仅适用于英伟达显卡；百分比越高效率越高但功耗越大，长时间最高频率可能降低显卡寿命。 |
| ROI图层是否偏移 | 设置是否将绘制 ROI 的图层整体偏移 0.5 像素点，默认开启。 |
| 看门狗 | 针对特殊场景，一般无需开启。 |
| 执行前清空缓存 | 开启后每个流程执行前清空一次历史结果数据。 |

### 2.3 方案设置

包括方案自动切换、回调设置、自动保存设置。

**方案自动切换**：配置参数指定软件收到特定字符串后自动切换方案（点击图标可设置多个方案策略）。注意：仅在当前电脑生效（电脑 A 设置只在 A 生效，换电脑需重配）。

| 参数 | 说明 |
| --- | --- |
| 方案路径 | 点击图标选择需自动切换的方案。 |
| 方案密码 | 所选方案有密码需输入正确，否则切换时无法加载。 |
| 通信字符串 | 软件收到指定字符串后自动切换方案。 |
| 通信切换 | 开启后通信设备发送指定字符串时方案自动切换（需确保通信管理处已完成通信设备添加设置）。 |

**回调设置**：单击「全部打开」并在弹窗点击确定，可通过回调获取整个方案各模块结果信息。注意：该功能开启后，选中单个模块时该功能自动关闭（仅能获取选中模块结果），需再次开启获取全部模块结果。

**自动保存设置**：启用后软件每 5 分钟检查模块运行参数是否更新，有改动则保存在方案文件同级目录。

**自动保存设置（全量保存）**：启用后根据设置的自动保存间隔时间自动保存方案。

### 2.4 运行策略

设置软件运行时 CPU、GPU、内存和网络使用率资源安排。

| 参数 | 选项 | 说明 |
| --- | --- | --- |
| 运行模式 | 普通模式 | CPU/GPU/内存/网络任一过高不告警。 |
| 运行模式 | 诊断模式 | 任一过高则告警提示。 |
| 策略模式 | 默认 | 所有流程集中调度，线程数量与 CPU 核数自动分配。 |
| 策略模式 | 自定义 | 针对各流程进行线程配置及 CPU 配置（流程耗时波动大或 CPU 占用高时使用；CPU 配置可用全选框批量选中/取消）。 |
| 策略模式 | 耗时稳定 | 每个流程任务在同一线程以串行方式执行。 |

### 2.5 采集策略

通过采集策略统一管理多个输出图像模块的存图操作，避免高频存图导致磁盘使用率过高引起存图失败。

**存图设置**：多个输出图像模块高频存图可能导致磁盘使用率过高引起存图失败，建议开启「大文件存图」功能统一管理。开启后，当输出图像模块输出图像达到固定数量时，软件自动将待存储图像统一压缩成 `.dat` 文件存到本地，降低写入频率优化效率。该功能需配套解压工具（DecompressionTool.exe，即存图大数据解压工具）查看；`.dat` 文件需通过该工具查看，普通图像文件可直接打开。

**大文件存图**：点击右侧按钮开启/关闭，开启后配置「大文件路径」（设置 `.dat` 文件本地保存路径）。注意：①确保所选路径存储空间足够，磁盘空间不足将导致后续图像无法存储；②开启后图像全部存到该功能路径下，各输出图像模块设置的存图路径不生效。

## 3. 工具介绍

VM 集成多种辅助工具，部分通过主界面菜单栏「工具」选项访问，部分需前往 VM 安装路径下 `\Applications\Tools` 文件夹访问。

### 3.1 标定配置引导

通过菜单栏「工具」打开标定配置引导，以步骤引导方式快速完成一键标定的复杂流程。选择标定类型后点击「创建」进入引导配置流程。支持 3 种标定类型：

| 标定类型 | 说明 |
| --- | --- |
| 静态标定 | 通过静止单相机和标定板确定图像坐标系和物理坐标系之间的转换关系。 |
| 动态标定 | 通过特征点移动确定图像坐标系和物理坐标系之间的转换关系以及旋转中心。 |
| 映射标定 | 通过特征点确定两个相机之间图像坐标系的转换关系。 |

#### 静态标定

主要通过「标定板标定」模块实现。通过标定配置引导选择静态标定并创建进入引导界面。

1. **通信配置**：点击设备管理处「配置」打开通信管理添加配置外部设备（开始前需在通信管理启用所选设备）；设备选择处选需关联的通信设备（仅支持 TCP 或 UDP 类型）；触发信号处配置控制流程执行的字符串信息；按需使用结束符（可选 `\r` 回车、`\n` 换行、`\r\n` 回车换行）。
2. **图像来源**：点击相机管理处「配置」打开相机管理添加配置全局相机；点击「图像源配置」对图像源模块配置。
3. **标定方式**：选择标定方式（当前仅支持标定板标定），点击「标定板标定」对标定板标定模块配置。
4. 点击图标查看该标定流程的模块搭建及配置情况。
5. **结果查看**：勾选「开始标定」，通过外部设备发送特定触发信号开始标定并显示信号内容和结果状态（需确保通信管理设备列表已启用并通讯正常），点击「生成标定文件」另存为标定文件，标定矩阵处显示具体信息（原文为图示）。

完成后将生成的标定文件在标定等相关模块中加载使用。

#### 动态标定

主要通过「N 图像标定」或「N 点标定」模块实现。通过标定配置引导选择动态标定并创建进入引导界面。

1. **通信配置**：设备选择（仅 TCP/UDP）；通信信号处分别配置开始信号、标定信号、结束信号和示教信号输入（标定信号 X/Y/R 为物理坐标点横/纵/角度；OK 输出/NG 输出呈现各信号输出给外部设备信号）；按需使用结束符。
2. **图像来源**：相机管理添加配置全局相机；图像源配置对图像源模块配置。
3. **标定方式**：可选「标定板标定」或「特征点标定」。选标定板标定时点击 N 图标定对 N 图像标定模块配置；选特征点标定时，点击模块配置的图标选择特征点由哪些模块提供（可添加多个），再点击「N 点标定」对 N 点标定模块配置。
4. 点击图标查看模块搭建及配置情况（点击右上角图标可返回引导配置模式）。
5. **结果查看**：勾选开始标定，发送触发信号开始标定，点击「生成标定文件」另存为标定文件。

#### 映射标定

主要通过「映射标定」模块实现。通过标定配置引导选择映射标定并创建进入引导界面。

1. **通信配置**：设备选择（仅 TCP/UDP）；通信信号处配置主相机触发信号、从相机触发信号和示教信号；按需使用结束符。
2. **图像来源**：相机管理添加配置全局相机；分别配置主相机图像源配置和从相机图像源配置。
3. **标定方式**：当前仅支持映射标定，点击「映射标定」对映射标定模块配置。
4. 点击图标查看模块搭建及配置情况（点击右上角图标返回引导配置模式）。
5. **结果查看**：勾选开始标定，发送触发信号开始标定，点击「生成标定文件」另存为标定文件。

### 3.2 标定板生成

**用途**：生成标定板轮廓图纸文件（.dxf / .bmp），后续手动填充棋盘格颜色并加工标定板。
**入口路径**：菜单栏「工具 > 标定板生成」。
**操作步骤**：

1. 选择标定板类型并回车（海康 I 型 / II 型区别见标定板生成模块介绍；常规型与扩展型支持行列数不同：常规型最大 255，扩展型最大 1000 行和列）。
2. 按界面提示依次输入标定板相关参数（标定板需覆盖相机视野；参数受项目精度、加工精度、材质、相机视野等多因素影响）。
3. 配置完成后回车，生成预览图像（.bmp，仅行列数都在 50 以下时生成，仅供预览不可打印）和轮廓图纸（.dxf）（原文为图示）。
4. 前往 VM 安装路径获取生成文件：相对路径 `.\Applications\Tools\CalibrationBoardGenerationTool`。

**注意**：该文件无法直接用于加工，需向棋盘格填充颜色后使用。填充时根据光源、标定板材料等选合适颜色；加工时确保缩放比例不变、单位正确且未栅格化，建议加工后测量标定板数据。

| 功能 | 说明 |

| 日志调整 | 设置日志收集等级。 |

### 3.4 参数查找工具

**用途**：查看方案中各模块输入/输出/运行参数的名称、对应算子参数名称及当前值。
**注意**：该功能仅型号中带 6210 或 7120 的加密狗支持。
**入口路径**：菜单栏「工具 > 参数查找工具」。
**操作步骤**：左上角选择流程 → 左侧显示该流程当前使用模块 → 选择模块后右侧查看输入参数、输出参数和运行参数。

- 模块参数名称：软件二次开发中的参数名称；
- 算子参数名称：对应算子包 SDK 中的参数名称；
- 当前值：当前参数数值（仅部分模块参数有对应算子参数）。

选中具体参数，工具下方显示该参数在软件和算子参数二次开发中对应信息，二次开发可复制代码获取参数值（原文为图示）。

- 软件调用路径：`VmSolution.Instance`（方案实例）、`IMVSBlobFindModuCs`（命名空间）、`IMVSBlobFindModuTool`（类名称）、`ModuParams`（所属类）、`Polarity`（参数名称）。
- 算子参数调用路径：`AlgorithmTool`（算法工具实例）、`GetRunParam`（获取参数方法）、`CircleFindMode`（参数名称，对应 Polarity）、`ref`（输出标记）、`paramValue`（输出参数值）。

### 3.5 自定义模块生成

**用途**：通过配置自定义生成新模块的 xml、dll 等文件。
**入口路径**：`.\Applications\Tools\AlgorithmXMLGenerator\AlgorithmXMLGenerator.exe`（双击打开）。
**操作步骤**：

1. VM 版本处下拉选择版本（V3.X 对应 V3.0.0~V3.4.0；VM4.X 对应 V4.0.0~V4.3.0；VM431 对应 V4.3.1 及之后）。
2. 基本输入处填写模块名称（只能英文），按需勾选支持输入图像源/位置修正信息。
3. 基本输出处按需勾选模块状态/输出图像。
4. 自定义输入输出处点击「添加」，在表格设置：参数名称（底层名，英文）、显示名称、参数类型（float/int/string/POINT/LINE/ROIBOX）、输入/输出（Input 对应基本参数，Output 对应模块结果）。支持删除/插入/上移/下移/导出（iofml 格式）/导入（原文为图示）。
5. 结果显示处点击「更新自定义输出」，Output 参数自动显示在结果显示各 Tab 页。
6. 在当前结果/历史结果/文本显示 Tab 页分别设置需显示参数（三模块互相独立）。
7. 点击「下一步」进入第二步（算法模块界面 XML 配置）。
8. 基本参数处勾选需要的 ROI 类型和屏蔽区（输入图像源/位置修正/文本显示已第一步设置，此处不可改，需改点「上一步」）。
9. 自定义运行参数处点击「添加」，设置：参数类型（float/int/enumeration/string/bool/floatBetween/intBetween）、参数名称（英文）、显示名称、编辑（float/int 设最大最小默认；enumeration 设显示名和枚举值；string 设最大长度和默认；bool 设 True/False；floatBetween/intBetween 设上限下限参数名、显示名、最小最大默认），编辑状态显示 Yes/No（生成前必须全部为 Yes）（原文为图示）。
10. 按需勾选「模板配置」并点击「单击编辑」配置（参数配置同自定义运行参数）。
11. 点击「生成XML / 生成C++工程 / 生成C#工程」选择路径保存：
    - 生成 XML：以自定义模块名命名的文件夹（xml 配置）；
    - 生成 C++ 工程：以 `Proj_模块名称` 命名（C++ 工程文件）；
    - 生成 C# 工程：以 `CsProj_模块名称` 命名（C# 工程文件）。
    - 推荐 xml 和工程文件放同一路径，编译后 dll 和 xml 同路径。
12. 编译 C++/C# 工程生成相应 dll 文件。
13. 将 dll、xml、png 整合到一个文件夹，放置到 `软件安装路径\Module(sp)\x64` 对应类别下（原文为图示）。

**注意**：单个视觉模块需由 10~11 个文件组成，其中 `CalculatorModuleControl.dll` 对应模板配置功能（不需要模板配置可缺，其他文件不可缺）。重新打开软件，对应类别下新增自定义模块（原文为图示）。

### 3.6 版本切换工具

**用途**：支持 4.2 及以上版本与其他版本间切换，PC 同时安装多版本时切换当前可用版本。
**注意**：自 VM V4.4.0 维护版本（2025.04）起不再更新，推荐使用激活工具切换。

**操作步骤**：

1. 确保已关闭 VM 和 Visual Studio 所有相关进程。启动后工具根据注册表自动获取已安装版本，左上角显示当前版本号（原文为图示）。右上角按钮：清除当前/清除所有（清除配置信息）、环境检测（弹出环境检测工具）、默认勾选「附带算法切换」（切换版本时同步切换算法）。
2. 点击对应版本切换，等待完成（原文为图示）。

**注意**：若切换后运行方案不成功，可通过「算子包安装程序」手动安装对应版本算子包：`.\Drivers\MVDAlgorithmSDK_STD.exe`；如需深度学习功能，双击该路径下 `MVDAlgorithmSDK_Patch.exe` 安装深度学习算子。

### 3.7 加密狗写密码工具

**用途**：授权方式为本机加密狗或远程加密狗时，为加密狗设密码，对「方案相关成果物文件」私有化加密保护知识产权。
**入口路径**：`.\Applications\Tools\SetDonglePassword\SetDonglePassword.exe`（需已插入加密狗）。
**操作步骤**：

1. 双击打开工具（原文为图示）。
2. 设置密码处输入并确认密码。**密码需包含 6~16 字符，仅可包含大小写字母和数字**。注意：设置后 VM 保存方案、导出流程及导出 Group 文件默认用该密码加密，密码无法找回，务必牢记。
3. （可选）修改密码（输入旧密码、新密码）；取消密码（单击左下角「恢复出厂设置」并输入当前密码）。

**说明**：「方案相关成果物文件」包括方案、流程、Group 及各模块模型（不含深度学习模块加载的模型文件）。设密码后上述文件仅可在「工控机插入加密狗且密码与设置一致」环境打开/加载。

**注意**：使用已设密码加密狗保存方案时，谨慎是否设方案密码。一旦设方案密码，打开方案需同时满足：①插入加密狗密码一致；②输入方案密码正确。建议设方案密码前备份原始方案。

### 3.8 读取加密狗序列号工具

**用途**：读取加密狗序列号（SN）。
**入口路径**：`..\VisionMaster4.4.3\Applications\Tools\ReadDongleSerialNumber\ReadDongleSerialNumber.exe`。
**操作步骤**：确保 PC 已连接加密狗，双击打开即可获取序列号。
**参数/输出**：加密狗分 4.0 和 5.0 版本，工具识别版本并在对应版本处显示 SN；序列号为 9 位字母和数字组合（原文为图示）。

### 3.9 存图大数据解压工具

**用途**：解压大文件存图存储的 `.dat` 文件，得到输出图像模块存储的图像。

## 4. 问题排查

软件安装、启动及使用过程中遇到问题，可参考本章节。

### 4.1 安装问题排查

#### 安装过程中提示文件在 GAC 目录下不存在

- **现象**：软件提示「文件在 GAC 目录下不存在」（原文为图示）。
- **原因**：GAC 用于储存多个应用使用的公共程序集。该问题因二次开发程序占用对应路径，导致安装时 GAC 注册异常。
- **解决步骤**：
  1. 打开 `VersionSwitchingAssistant.exe`（安装路径 `/Applications/Tools/VersionSwitchAssistant`）。
  2. 单击「清除当前」，清除当前版本环境配置。
  3. 清除后，在工具中单击当前安装的版本重新注册。
- **注意事项**：需在清除 GAC 环境后重新注册对应版本。

#### 安装过程中提示环境变量配置异常

- **现象**：软件提示「环境变量配置异常」（原文为图示）。
- **原因**：环境变量未正确配置（路径与安装时选择的安装路径相关）。
- **解决步骤**：
  1. 右击计算机图标 → 属性。
  2. 依次选择 高级系统设置 > 高级 > 环境变量。
  3. 单击系统变量 Path → 编辑。
  4. 单击新建，手动配置（以安装在 D 盘 Program Files 为例）：
     - `D:\Program Files\VisionMaster4.4.3\Applications\PublicFile\x64`
     - `D:\Program Files\VisionMaster4.4.3\Applications\PublicFile\x86`
  5. 单击确定并继续安装。
- **注意事项**：配置路径与安装 VM 时选择的安装路径相关，需分别配置 x64 和 x86 两个路径。

#### 双击安装包或补丁包无反应，且无进程状态显示

- **现象**：双击运行安装包或补丁包时，任务管理器未显示安装相关进程。相关进程：4.3.0 以下为 `VmModuleProxy.exe`、主进程服务 exe（名称带 Server）、主进程 exe；4.3.0 及以上为主进程 exe。
- **原因**：可能由工控机系统安全等级过高引起。
- **解决步骤**：
  1. 右键安装包/补丁包 → 属性。
  2. 常规中单击安全处「解除锁定」，取消勾选。
  3. 单击确定或应用。
  4. 再次安装。
- **注意事项**：其他安装包若存在同样问题，用以上方式处理（原文为图示）。

#### 安装过程中提示 MVS 正在运行中

- **现象**：软件提示 `MVS正在运行`（原文为图示）。
- **原因**：MVS 软件正在运行，与 VM 安装冲突。
- **解决步骤**：关闭 MVS 软件，并继续安装即可。
- **注意事项**：安装前建议先关闭 MVS。

### 4.2 启动问题排查

#### 启动软件时提示找不到方法

- **现象**：软件提示 `找不到方法`（原文为图示）。
- **原因**：软件依赖库安装不完整。
- **解决步骤**：
  1. 关闭防火墙及其他杀毒软件后，重新安装软件。
  2. （若安装过其他版本）运行 `ClearGAC.exe` 清除当前 GAC 环境（相对路径 `.\Development\V4.x\ComControls\Assembly\Tool`），再双击同路径 `GAC.bat` 重新注册 GAC。
- **注意事项**：ClearGAC.exe 与 GAC.bat 同路径，需先清除再注册。

#### 启动软件时提示加密狗未检测到或检测异常

- **现象**：软件安装时选择本机加密狗授权，提示加密狗异常（原文为图示）。
- **原因**：加密狗硬件/驱动/识别异常等多种原因导致。
- **解决步骤**：
  - **检查加密狗指示灯**：旧型号红色，新型号蓝色，确认是否正常亮起。
  - **检查加密狗接入数量**：环境中是否存在其他加密硬件（如向含加密信息工控机接入硬件加密狗可能导致冲突），需拔掉硬件加密狗。
  - **检查加密狗硬件识别**：打开设备管理器，插拔加密狗，若设备管理器刷新则可识别；否则更换接口重试。若不同接口/工控机插拔均未刷新，硬件可能损坏，联系技术人员。
  - **检查驱动**：设备管理器中右键加密狗设备 → 属性 → 设备状态查看；若错误可重装驱动。新型号（iMVS-VM-7200(pro)、iMVS-VM-6200(pro)）驱动相对路径 `.\Drivers\SenseShield`（仅支持 4.x.0 及以上）；旧版（iMVS-VM-*1**）驱动相对路径 `.\Drivers\EliteIV`（原文为图示）。
- **注意事项**：iMVS-VM-7200(pro)、iMVS-VM-6200(pro) 仅支持 4.x.0 及以上软件。

#### 软件安装后启动异常

- **现象**：软件安装后启动异常。
- **原因**：多种原因（安装环境、环境变量、版本匹配、运行库等）。
- **解决步骤**：
  1. 检查防火墙、白名单、软件限制及系统权限。
  2. 右键计算机 → 属性 → 高级系统设置 → 环境变量 → 系统变量 → Path，检查 VM 环境变量是否正确写入并置顶（确保在相机和算子环境变量上方）（原文为图示）。
  3. 检查是否有名为 `PYTHONHOME` 的环境变量，需删除（否则影响启动）。
  4. 多版本 VM 时检查版本与算子是否匹配；不匹配用版本切换工具（`.\Applications\Tools\VersionSwitchAssistant`）切换。
  5. 安装过 VM 3D 或二次开发环境，需用 `ClearGAC.exe`（`.\Development\V4.x\ComControls\Assembly\Tool\ClearGAC.exe`）清除 GAC 后执行 `GAC.bat`。
  6. 检查运行时库是否正常，异常时手动执行 VM 安装路径下名称以 `vcredist` 开头的 4 个库（相对路径 `.\Drivers`）（原文为图示）。
  7. 确认是否在管理员权限下安装；若否，需重新安装 VM。
- **注意事项**：逐项排查，环境变量、PYTHONHOME、版本匹配是常见原因。

### 4.3 使用问题排查

#### 全局相机硬触发时无法触发其他流程

- **现象**：多个流程绑定同一全局相机，通过相机硬触发执行流程时，仅能触发单个流程。
- **原因**：硬触发可触发图像源模块绑定该全局相机的流程；多个流程同时绑定同一相机时，软件按流程顺序优先将图像传递给可用流程。相机固定速率出图时，若流程 1 能在出图间隔内运行完，图像不会输入至流程 2（原文为图示）。
- **解决步骤**：若需同时触发若干流程，将单个相机绑定单个流程，并通过标志信息控制图像输入哪一个流程。
- **注意事项**：图像优先传递至最靠前的可用流程。

#### 添加全局相机时提示动态库加载失败

- **现象**：相机管理中添加全局相机时，报错提示 `动态库加载失败`。
- **原因**：相机 SDK 安装失败，或当前相机 SDK 版本与 VM 安装路径下 `MVS_SDK_Setup.exe` 版本不一致。
- **解决步骤**：重新安装 `MVS_SDK_Setup.exe`（相对路径 `.\Drivers\MVS_SDK_Setup.exe`）。
- **注意事项**：确保相机 SDK 版本与 VM 自带版本一致。

#### 拖拽模块提示动态加载库失败

- **现象**：运行 VM 后，从模块箱拖拽某一模块到流程区时，报错提示「动态库加载失败。」
- **原因**：①安装时算子开发包安装失败；②环境变量未生效。
- **解决步骤**：
  - 重新安装算子开发包（`.\Drivers\MVDAlgorithmSDK_STD.exe`）；
  - 若重装后仍报错，可能环境变量未生效，重启工控机。
- **注意事项**：先重装算子包，无效再重启使环境变量生效。

## 5. 常见问题

| 问题 | 回答 |
| --- | --- |
| 单台工控机可否安装多套 VM？ | 可以。运行默认最近安装版本；需用其他版本时通过版本切换工具（4.2 及以上）切换。 |
| 是否支持加密方案？ | 支持。保存方案时单击「加密」设方案密码，重新打开需先输入密码。注意密码无法找回。 |

| 能否在单台工控机使用多个加密狗？ | 不可以。选本机加密狗时仅可接入 1 个，多接入会引起加密狗冲突。 |
| 能否在单台工控机使用多套授权码？ | 可以。激活工具可输多套授权码，能力集有差别时支持全部能力集。 |
| 是否对相机出图有分辨率限制？ | 没有限制，图像源模块对相机出图尺寸无限制。 |
| 如何获取 SDK 和算子开发包？ | SDK：`.\Development`；算子开发包：`C:\Program Files (x86)\MVDAlgorithmSDK`。另含软件 `.\Applications`、驱动 `.\Drivers`。 |
| 软件都需要哪些驱动？ | 见下表。 |

**驱动说明**：

| 驱动 | 文件名/路径 | 作用 |
| --- | --- | --- |
| 加密狗硬件驱动 | 新版本蓝色指示灯：`.\SenseShield\install.bat`；旧版本红色指示灯：`.\EliteIV\install.bat` | 接入工控机指示灯未亮时重装。 |
| 相机驱动 | `MVS_SDK_Setup.exe` | 相机调用/加载等问题时手动运行安装。 |
| 算子包驱动 | 名称以 `MVDAlgorithmSDK` 的 exe | 算子版本不匹配 VM 时手动运行安装适配版本。 |
