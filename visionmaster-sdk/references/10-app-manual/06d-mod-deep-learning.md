# VM 模块参考：深度学习

## 速览
- **深度学习通用**：模块均分 C/G 两型，原理与参数基本一致，仅运行环境不同；后缀 C 基于 CPU（推荐 i7-8 代及以上），后缀 G 基于独立显卡 GPU（显存 6 GB 及以上）。模型训练用深度学习训练工具（VisionTrain）或 AI 训练平台。
- **DL快速图像分割**：检测并分割表面缺陷（划痕/脏污/裂纹等），可输出类别图；效率显著高于 DL图像分割，但**不支持输出概率图**；**仅可在含独立显卡的工控机上使用**。
- **DL图像分割**：检测表面缺陷，可输出缺陷概率图或类别图；CPU/GPU 版本都有；效率低于 DL快速图像分割。
- **DL实例分割**：为每个物体实例生成独立掩膜和 ID，整合目标检测算法；适用于目标重叠场景（上下层目标）、高精度定位与计数。
- **DL目标检测**：输出目标定位框 + 类别 + 置信度；单/双阶段算法，实际多用单阶段；自带 2 个模型文件 DetectDefault.bin（默认）与 DetectFast.bin（快速）；单个待检测目标应占输入图像像素面积 1.31% 以上。
- **DL分类**：整图分类，输出类别与置信度；适用于类间差异大、分类标准明确的场景；图像需 ≥16×16（建议 >256×256）；类别固定，若需新增类别建议改用 DL图像检索。
- **DL图像检索**：基于"注册 + 检索"（Gallery 数据库）判类；内置通用模型可直接注册图像使用；支持随时扩展新类别；检索时输入图像必须为 RGB24 格式（注册图像无此限制，可用 MONO8）。
- **DL无监督分类**：只用正常样本训练，检出与正常样本不一致的异常；训练分普通模式（缺陷判断）与逻辑模式（缺失/有无/数量检测）；**仅可在含独立显卡的工控机上使用**。
- **DL无监督分割**：只用 OK 样本训练，通过原图与重建图相似度推理缺陷区域，输出概率图；无需标注缺陷样本；复杂纹理场景建议改用 DL快速图像分割有监督训练；**仅可在含独立显卡的工控机上使用**。
- **评价指标**：分类 → 混淆矩阵/Precision/Recall/PR曲线/F1_Score；图像分割 → Recall/Precision/M_IoU；实例分割 → Recall/Precision/PR曲线；目标检测 → Recall/Precision/M_IoU/PR曲线/F1_Score/mAP/AP@0.5:0.95。

| DL无监督分割 | 无监督异常分割 | 仅 OK 样本；无需标注缺陷样本；训练集不得含缺陷图 | 仅 GPU（独立显卡工控机） | 概率图、检测区域 |

### DL快速图像分割
**功能**：检测和分割表面缺陷（划痕、脏污、裂纹等），可分类多种缺陷，输出类别图（不支持概率图），常用于缺陷检测、区域定位。适用于目标提取、缺陷检测、场景分割，在小目标、特征不明显场景有一定优势。

**限制**：仅可在含独立显卡的工控机上使用（独立显卡性能要求参见推荐硬件）。

**模块原理**：基于神经网络提取图像中待测目标掩膜并判断其类别，将相同像素值分配给同一类别的像素。与 DL图像分割的差异：①在基本保证检测精度的前提下检测效率显著提升；②不支持输出概率图。

**输入**：原文未给出独立输入表；前序模块通常为图像源（建议检测目标大于 3×3 像素）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 模块运行耗费时间 |
| 模块状态 | int | 0=NG（红色），1=OK（绿色） |
| 类别信息 | image | 类别图信息（类别名称 string，保存在模型中，导入模型时从模型文件获取；灰度值 int，每个类别的灰度值） |
| 最小分数 | int | 类别图上属于缺陷的最小概率 |
| 类别图 | image | 类别图 / 类别图宽度 / 类别图高度 / 类别图像素格式（均 int） |
| 检测区域 | box | 检测 ROI（中心点X/Y float、宽度/高度 float、角度 float：顺时针为正、逆时针为负，正准位姿为 0 度） |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 模型文件路径 | 模型文件（.bin） | 原文未给出 | 选择该模块运行时使用的模型文件 |
| 方案存模型 | 开/关 | 原文未给出 | 开启后保存方案时，将当前模型文件保存到方案或流程文件 |
| 按ROI裁图 | 开/关 | 原文未给出 | 开启：仅预测 ROI 内图像，忽略 ROI 外信息；关闭：识别整张图，但根据 ROI 等设置筛选过滤结果 |
| 批处理使能 | 开/关（仅 GPU 模块可配置） | 原文未给出 | 并行处理多 ROI 区域；开启后配置批处理等级，值越大并行能力越强、效率越高、占用性能越多 |
| 小目标模式 | 开/关 | 原文未给出 | 针对大图小目标场景（目标占输入图像尺寸低于 0.5%）优化训练过程；开启后无法配置按ROI裁图 |
| 横向滑窗数 / 纵向滑窗数 | 整数 | 原文未给出 | 小目标模式下分别设置横向和纵向的图片切割个数 |
| 滑窗重叠率 | 比率（0=相邻滑窗独立） | 原文未给出 | 图片切割时相邻图片的重叠比率（重叠部分面积 / 单个滑窗面积） |
| 最小分数 | 数值 | 原文未给出 | 预测结果的最小可信度（某像素属于某类别的最小概率），低于则舍弃；减小时分割的类别区域更小 |

**模型/训练相关**：使用 VisionTrain 或 AI 训练平台自行训练模型；模型文件后缀 .bin；通过"模型文件路径"加载，开启"方案存模型"保存至方案。如需分类缺陷，训练时需采用多种标签标注（单标签模型仅检出缺陷，多标签模型检出并输出类别）。原文未给出具体训练参数。

**使用步骤**：
1. 使用 VisionTrain 或 AI 训练平台训练模型（需分类缺陷时采用多种标签标注）。
2. 在模块中通过模型文件路径加载模型（.bin），开启方案存模型。
3. 识别缺陷（单标签模型）：前序接图像源，后序搭配 Blob 分析渲染缺陷位置。
4. 识别并分类缺陷（多标签模型）：后序搭配 Blob 标签分析，渲染缺陷位置并输出缺陷类别。
5. 可通过图像显示将输出配置为缺陷概率图或类别图（类别图中不同颜色区分类别，如蓝=裂纹、绿=青斑、红=黑斑、黄=不饱满）。

**注意事项**：
- 建议检测目标大于 3×3 像素。
- 性能调优：输出较差时检查模型在训练集上的表现（查准率/查全率）、训练集与测试集数据分布是否近似、训练集是否包含全部需分割的标注类型和数据；调整后需重新训练。
- 误检多：训练时添加误检场景数据；适当提高最小分数参数值。
- 漏检多：检查目标像素面积占比是否过小（过小则开启小目标模式）；尝试调低最小分数（若可检出，建议增大训练集数据量）；添加漏检场景训练数据。
- 掩膜质量差：检查训练集标注区域，多边形标注应紧贴物体轮廓。

### DL图像分割
**功能**：检测表面缺陷（划痕、脏污、裂纹等），可分类多种缺陷，输出缺陷概率图或类别图，常用于缺陷检测、区域定位。适用于目标提取、缺陷检测、场景分割，在小目标、特征不明显场景有一定优势。

**与快速版关系**：DL快速图像分割效率更高，但仅支持在含独立显卡的工控机上运行；本模块有 C（CPU）/G（GPU）两种版本。

**输入**：原文未给出独立输入表；前序模块通常为图像源。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 模块运行耗费时间 |
| 模块状态 | int | 0=NG（红色），1=OK（绿色） |
| 概率直方图 | int | 将频数除以总样本数，得到每个区间内数据的概率 |
| 最小分数 | int | 类别图上属于缺陷的最小概率 |
| 类别图信息 | image | 类别图（图像数据/宽度/高度/像素格式）+ 类别信息（类别名称 string、灰度值 int） |
| 缺陷概率图 | image | 每个缺陷概率图的图像数据 / 图像宽度 / 图像高度 / 图像像素格式 |
| 缺陷\*概率图（\*代表1-8） | image | 每个缺陷概率图的图像 / 宽度 / 高度 / 像素格式 |
| 检测区域 | box | 检测 ROI（中心点X/Y、宽度、高度、角度，同 DL快速图像分割） |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 模型文件路径 | 模型文件（.bin） | 原文未给出 | 选择该模块运行时使用的模型文件 |
| 方案存模型 | 开/关 | 原文未给出 | 开启后保存方案时保存当前模型文件到方案或流程文件 |
| 获取模型ROI | 开/关 | 原文未给出 | 开启后自动获取模型文件中的 ROI 信息，无需配置基本参数中的 ROI 区域 |
| 按ROI裁图 | 开/关 | 原文未给出 | 同 DL快速图像分割 |
| 批处理使能 | 开/关（仅 GPU 模块可配置） | 原文未给出 | 同 DL快速图像分割 |
| 小目标模式 | 开/关 | 原文未给出 | 大图小目标（<0.5%）场景优化；开启后无法配置按ROI裁图 |
| 横向滑窗数 / 纵向滑窗数 / 滑窗重叠率 | 整数 / 整数 / 比率 | 原文未给出 | 同 DL快速图像分割小目标模式子参数 |

注意：本模块原文未列出"最小分数"等算法参数（算法参数原文未给出参数表）。

**模型/训练相关**：需使用 VisionTrain 或 AI 训练平台自行训练模型；模型文件后缀 .bin；加载后开启方案存模型。如需分类缺陷，训练时需采用多种标签标注。原文未给出具体训练参数。

**使用步骤**：
1. 训练模型（多标签标注以支持缺陷分类），加载模型并开启方案存模型。
2. 识别缺陷（单标签模型）：前序图像源，后序搭配 Blob 分析渲染缺陷位置。
3. 识别并分类缺陷（多标签模型）：后序搭配 Blob 标签分析输出缺陷类别。

**注意事项**：
- 性能调优：检查模型训练集表现、训练/测试集数据分布近似、训练集覆盖全部标注类型；调整后重新训练。
- 误检多：训练时添加误检场景训练数据。
- 漏检多：目标像素占比过小时开启小目标模式；添加漏检场景训练数据。
- 掩膜质量差：检查多边形标注，应紧贴物体轮廓。

### DL实例分割
**功能**：标记输入图像中的每个物体实例，为相同类别的不同物体生成 ID；常用于检测精度要求较高的定位、计数场景，特别适用于识别目标重叠场景中的上下层目标。

**模块原理**：整合目标检测算法，额外提取每个检测框内的特征图以预测对应目标掩膜，输出每个目标的独立掩膜。流程：①检测目标（预测定位框）→ ②提取 ROI 内特征并采样至统一大小 → ③预测掩膜和类别 → ④输出结果。

**输入**：原文未给出独立输入表；前序模块通常为图像源。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 模块运行耗费时间 |
| 模块状态 | int | 0=NG，1=OK |
| 目标个数 | int | 检测区域内检测到的定位框个数 |
| 目标类别 | int | 目标实例的种类序号（需预先训练好模型并标记序号） |
| 目标置信度 | float | 每个定位框的置信度 |
| 目标像素值 | int | 每个实例分割检测目标的灰度值，用于区分不同的目标 |
| 目标面积 | int | 每个检测目标的面积大小 |
| 目标状态 | int | 1=定位框正常，0=异常 |
| 类别名称 | string | 类别名称，保存在模型中，导入模型时从模型文件获取 |
| 目标信息矩形 | — | 中心X/Y（float）、矩形宽度/高度（float）、矩形角度（float，范围[-90,90]，顺时针为正） |
| 输出掩膜图 | image | 完成掩膜后输出的图像 / 宽度 / 高度 / 像素格式（如 17301505 代表黑白图片） |
| 输出渲染图 | image | 完成渲染后输出的图像 / 宽度 / 高度 / 像素格式 |
| 检测区域 | box | 检测 ROI（中心点X/Y、宽度、高度、角度） |
| 边缘点个数 | int | 输出边缘点的个数 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 模型文件路径 | 模型文件（.bin） | 原文未给出 | 选择运行时使用的模型文件 |
| 方案存模型 | 开/关 | 原文未给出 | 保存方案时保存当前模型文件 |
| 按ROI裁图 | 开/关 | 原文未给出 | 同 DL快速图像分割 |
| 最大查找个数 | 整数 | 原文未给出 | 最大目标数量，超出舍弃；不确定目标数量时建议调大 |
| 目标框置信度 | 数值 | 原文未给出 | 预测框最小置信度；漏检时降低、错检时提高 |
| 目标框重叠率 | 比率 | 原文未给出 | 预测目标框允许被遮挡的最大比例，超过则舍弃 |
| 掩膜置信度 | 数值 | 原文未给出 | 掩膜得分最小值，低于则不输出该掩膜区域 |
| 掩膜重叠率 | 比率 | 原文未给出 | 两掩膜区域重叠程度最大值，超过则过滤置信度较低的掩膜 |
| 边缘筛选使能 | 开/关 | 原文未给出 | 开启后筛选超出 ROI 边界的预测结果，需配置最小边缘分数（预测框在 ROI 内的面积比例，低于则舍弃） |
| 渲染输出图像 | 开/关 | 原文未给出 | 开启后运行后图像中检测到的目标以掩膜方式呈现 |
| 不同类别过滤 | 开/关 | 原文未给出 | 开启后可过滤不同类别的目标；不开启则只按同类别过滤 |

**模型/训练相关**：使用 VisionTrain 或 AI 训练平台自行训练模型；模型文件后缀 .bin；训练具体步骤参见对应训练工具用户手册（原文未给出具体训练参数）。

**使用步骤**：
1. 训练并导出模型，在模块中通过模型文件路径加载，开启方案存模型。
2. 前序接图像源提供图像输入；后序无指定模块，可处理模块输出结果即可。

**注意事项**：
- 调整训练图像/标注/训练参数后需重新训练，训练结束后需导出并在该模块中加载模型。
- 误检多：向训练集添加易被误检的正常图像。
- 漏检多：目标像素占比过小则增大输入图像分辨率；尝试调低目标框置信度和掩膜置信度（若可检出需补数据重新训练）；仍严重则检查训练集和检测方案合理性。
- 掩膜质量差：检查多边形标注（紧贴物体轮廓）；大目标问题调整标注框形状，小目标尝试增大目标在图像中的占比。

### DL目标检测
**功能**：检测图像中的目标并确定类别和位置信息，常用于定位、计数和缺陷检测场景，可实时定位和识别多个目标。

**模块原理**：利用神经网络提取图像特征，根据特征分布给出类别信息（类别 + 置信度）。流程：提取特征 → 池化降采样 → 激活 → 重复提取多层特征 → 全连接层和分类器预测各类别概率。

**注意事项**：

- 检查训练集图像中待检测目标是否对齐、是否存在复杂纹理变化；若纹理变化较多，建议使用 DL快速图像分割进行有监督训练。
