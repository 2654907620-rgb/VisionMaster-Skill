# VM 模块参考：缺陷检测

## 速览

1. 缺陷检测类模块用于识别图像中零部件的特征缺陷，共 13 个模块，分为通用图像类、边缘模型类、直线圆弧类、组合与趋势类四组。
2. **表面缺陷滤波**：无纹理背景表面的点/线/块状缺陷（划伤、破损、异物），输出滤波响应图，需搭配后序 Blob 分析筛选缺陷 blob。
3. **字符缺陷检测**：字符脏污、缺失、差异，基于 OK 样本建模比对，适用于芯片雕刻字符、包装印刷字符。
4. **异常检测**：基于边缘特征或灰度特征，用 OK 样本注册建模，按匹配分数阈值判定 NG/OK，无需粗定位（内含模板匹配）。
5. **边缘模型类**（边缘模型缺陷检测 / 边缘对模型缺陷检测）：手动绘制（或自动生成）轨迹建模，与实时提取边缘比对，检测位置偏移、断裂、阶梯（边缘对另支持宽度、气泡缺陷）；边缘对模型适合边缘呈曲线等不规则分布的场景。
6. **直线圆弧类**（直线边缘 / 直线对 / 圆弧对 / 圆弧边缘缺陷检测）：基于卡尺工具沿直线/圆弧采样边缘点（对），与基准直线/圆弧比较检测断裂、偏移、宽度异常，无需建模、画 ROI 即可检测。
7. "边缘检测"与"缺陷判定"分工：边缘模型类先建基准模型再比对；直线圆弧类基准可外部传入（直线查找/圆查找）或内部自行查找。
8. **组合类**（边缘组合 / 边缘对组合缺陷检测）：将直线+圆弧（对）缺陷检测合并于一个模块，参数与两个独立模块一致。
9. **趋势类**（边缘位置趋势分析 / 边缘对位置趋势分析）：卡尺系工具，输出边缘点（对）到 ROI 边的距离信息（最大/最小/平均）及对应点，用于筛选点位、分析边缘走势，属分析工具而非直接判定缺陷。
10. 缺陷类型编码（多数模块输出共用）：6=边缘位置偏移，8=边缘断裂，9=边缘阶梯差。
11. 表面缺陷滤波/异常检测/字符缺陷检测属于"建模比对/滤波"路线；直线圆弧与组合类属于"卡尺采样+基准比较"路线；趋势类属于"距离统计"路线。
12. 通用输出约定：各模块均输出 耗时（ms）与模块状态（0=NG 红色，1=OK 绿色）。

## 通用（表面缺陷滤波 / 字符缺陷检测 / 异常检测）

### 表面缺陷滤波
**功能**：适用于简单、无纹理背景的表面缺陷检测场景，可检测工件表面点状、线状、块状等不同形状的缺陷（划伤、破损、异物等），且不受材料表面亮度变化影响。

原理：缺陷区域呈现与背景不同的灰度特征，导致表面灰度分布突变。算法将缺陷抽象为"异常灰度像素值在一定空间范围内构成的区域"，结合缺陷的空间与灰度分布特征生成图像空域滤波器（按缺陷信号波形近似高斯函数构造卷积核，并旋转得到多方向卷积核），对各方向滤波结果综合得到缺陷滤波响应图。工作流程：1) 生成不同方向的卷积核；2) 分别用各卷积核对图像滤波；3) 综合各方向结果生成缺陷滤波响应图；4) 根据滤波响应值判断缺陷是否存在，若存在同时输出缺陷严重程度。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序模块为图像源，提供图像输入 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 模块运行耗费的时间 |
| 模块状态 | int | 0=NG（红色），1=OK（绿色） |
| 输出图像数据/宽度/高度/像素格式 | binary/int | 输出图像数据；像素格式 17301505 对应 Mono8，35127316 对应 RGB24 |
| 检测区域（中心点X/Y、宽度、高度、角度） | box/point/float | 图像中需进行检测的 ROI 区域；角度顺时针为正，正准位姿为 0 度 |
| 屏蔽区多边形（多边形点数、点集点X/Y） | polygo/point/int | 需屏蔽的 ROI 区域（不进行检测） |
| 多边形字符串 | string | 以字符串输出多边形信息，数值为各顶点 X/Y 坐标，英文逗号隔开 |
| 屏蔽区字符串 | string | 屏蔽区位置字符串信息，用于后序模块继承屏蔽区 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 滤波模式 | 快速 / 高精度 | — | 快速：耗时低，但对指定方向缺陷的滤波响应抑制效果不精确；高精度：耗时较高，可通过设置权重精确抑制或增强指定方向缺陷的滤波响应 |
| 卷积核宽度/高度 | — | — | 卷积核尺寸，决定视野大小；需大于所要检测最大缺陷的宽度或高度的最小值。尺寸越大滤波效果越好但耗时显著增加，可对图像缩放以降低耗时（需保证缺陷信息无明显损失） |
| 核的数量 | — | — | 卷积核分析的角度颗粒度，在 0 到 180 度之间均匀分布卷积核方向。个数增多滤波效果提升不明显但耗时增加，一般设为 6 即可满足大部分需求 |

| 0/30/60/90/120/150度权重 | -10 ~ +10 | — | 6 个方向的滤波响应权重；卷积核个数不等于 6 时其他方向权重由这 6 个方向自适应计算；值越大该方向在结果融合中作用越强 |

**使用步骤**：
1. 前序接图像源模块；后序接 Blob 分析，处理滤波响应图并筛选符合条件的缺陷 blob。
2. 配置基本参数与上述运行参数。
3. 配置结果显示，执行或连续执行模块查看输出。

### 字符缺陷检测
**功能**：准确识别字符缺陷，包括字符脏污、缺失、差异等，适用于各类部件的字符缺陷，如半导体芯片上雕刻字符缺陷和包装行业印刷字符缺陷。

原理：将目标图像与标准图像比对，分建模（仅注册 OK 样本，保存有效字符特征信息：输入图像→设定定位基准粗定位→字符分割得到文本行/单词/字符区域→字符区域建模→模型训练保存特征）与检测（输入图像与模型→模板匹配→结合匹配结果、建模基准位置及检测区域位置修正→字符匹配→特征比对计算精确缺陷位置）两个流程。

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序模块为图像源，提供图像输入 |
| 特征模板 | — | 前序高精度匹配模块提供可继承的特征模板（可选） |

| 输出项 | 类型 | 说明 |

| 模块状态 | int | 0=NG（红色），1=OK（绿色） |

| 字符状态 | int | 每个文本行中单个字符的状态，1=检测到字符，0=未检测到 |

字符模型相关（建模窗口）参数——模型参数（直接创建时设置）：尺度模式（自动/手动）、速度尺度（取值 1~20，越大图像金字塔顶层图像越小、边缘点越稀疏、匹配越快，过大可能漏检）、特征尺度（图像金字塔底层大小，越大抗形变能力越强、匹配越快，过大可能误检且定位精度下降；取值不能大于速度尺度）、阈值模式（自动/手动）、对比度阈值（手动时生效，查找的最低对比度数值）。搜索参数（直接创建和继承均需设置）：绘制ROI（默认全屏，启用后仅对 ROI 内粗定位）、最小匹配分数（默认 0.5）、角度范围（默认 -180°~180°）、匹配极性。字符分割参数：最小字符面积、最小字符宽度、二值化尺度（数值越低提取的二值化点越少但越可靠）、二值化窗口大小（二值化点领域大小）、二值化阈值、显示二值图（开关）、字符极性（黑底白字/白底黑字）、字符分割方式（文本行分割/单词分割/字符分割）。精定位参数：缩放模式（手动/自动，推荐自动）、精度金字塔尺度（取 1 时精细程度最大、边缘点最多、精度最高）、速度金字塔尺度（1~20，越大匹配越快）、阈值模式（自动/手动）、模型低阈值（手动时生效）。训练参数：最小匹配分数、角度范围（默认 -180°~180°）、阈值类型（自动阈值/模型阈值/手动阈值）、边缘阈值（手动阈值时设置）、位置纠正、宽度方向容忍、高度方向容忍。

**使用步骤**：
1. 执行一次流程，使模块获取图像源输入的图像。
2. 打开模块配置窗口，进入"字符模型"页签，单击模型训练打开字符训练模型窗口。
3. 设置基准、创建定位模型：选项 1 直接创建——用掩膜绘制工具在图像上绘制待检测字符轮廓，生成粗定位模型；选项 2 继承——从模型选择下拉列表选择高精度匹配模块生成的模型。
4. 设置模型参数与搜索参数，单击下一步。
5. 设定检测目标：绘制检测区域，设置字符分割相关参数（最小字符面积、最小字符宽度、二值化尺度、二值化窗口大小、二值化阈值、字符极性、字符分割方式等）。
6. 单击下一步设置精定位：字符提取不理想时重新绘制区域并设置精定位参数；再设置训练参数并单击训练模型。
7. 单击下一步设置检测区域掩膜（无需识别的区域），启用掩膜绘制并在检测区域内拖动光标绘制。
8. 单击下一步批量训练：加载多张建模图像统计训练，合格图像标记"统计当前图像"，不合格图像标记"不统计当前图像"。
9. 单击完成；配置运行参数（字符检测/字符精定位/字符粗定位）与结果显示，单击执行查看结果。

**注意事项**：无额外原文注意事项（建模仅注册 OK 样本）。

### 异常检测
**功能**：通过边缘特征或灰度特征检测物料异常情况，并输出异常缺陷的位置信息。

原理：工作流分注册阶段（基于合格样本提取图像特征获取特征向量，构造描述 OK 图像特征分布的检测模型）和分类阶段（按注册相同方式提取候选特征，与模型特征比对输出相似度得分；存在得分低于阈值区域则判定为缺陷区域、标 NG 输出，否则标 OK 输出）。因算法内含模板匹配，无需粗定位。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序模块一般为图像源；无需粗定位 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 模块运行耗费的时间 |
| 模块状态 | int | 0=NG（红色），1=OK（绿色） |
| 对比状态 | int | 算法分数与设定阈值比较，大于阈值输出 1（无缺陷），小于输出 0（有缺陷） |
| 标签 | string | 大于阈值输出 OK，小于阈值输出 NG |
| 分数 | float | 匹配到图像的得分，1 表示与模板图像完全相同 |
| 检测区域个数；检测区域（中心点X/Y、宽度、高度、角度） | float/box | 检测区域个数及区域信息 |
| 匹配状态 | int | 1=匹配成功，0=匹配失败 |
| 匹配框（中心X/Y、宽度、高度、角度） | box | 将匹配对象框选起来的最小矩形框 |

**参数**：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 分数阈值 | — | — | 低于评分阈值的目标将被判定为 NG。缺陷模型选择继承时，运行参数只有该参数 |
| 最小匹配分数 | 最大 1 | — | 缺陷模型与图像中目标的相似程度阈值，达到才被搜索到，1 表示与模型完全一致 |
| 匹配极性 | 考虑极性 / 不考虑极性 | — | 目标边缘极性与模型不一致仍要查到时设为不考虑极性，否则考虑极性可缩短查找时间 |
| 角度范围 | -180 ~ 180 | — | 待匹配目标相对于已创建模型的角度变化范围 |
| 尺度范围类型 | 尺度范围 / 尺度范围XY | — | 尺度范围：整体设置缩放尺度范围，取值 0.1~1；尺度范围XY：分别在 X 尺度范围、Y 尺度范围设置，取值 0.1~10 |
| 阈值类型 | 自动阈值 / 模板阈值 / 手动阈值 | — | 边缘阈值即边缘对比度阈值（轮廓点与背景灰度差阈值），仅大于该阈值的轮廓点可被提取；自动：自适应；模板：模板边缘阈值内部转换后使用；手动：手动设定 |
| 延拓阈值 | — | — | 特征在图像边缘显示不全时，缺失部分相对于完整特征的比例；目标被图像边缘截断时设置可保证目标被找到 |

批量训练相关（缺陷模型窗口）：尺寸模式（自动/手动；手动时设最小缺陷尺寸——需检测缺陷的最小宽度，单位 pixel，取值越小精度越高耗时越长）、背景噪声抑制类型（自动/手动；手动时设背景噪声抑制阈值，越高对背景波动异常抑制越强；自动时绘制背景噪声抑制区域，算法自动计算阈值）、下采样率（值为 k 时原图每行每列每隔 k 个点取一点，值越大轮廓越稀疏、越不精细，不宜过大）、特征类型（全部/边缘特征/灰度特征）。

**使用步骤**：
1. 执行一次流程获取图像；配置基本参数。
2. 缺陷模型页签选择直接创建或继承：
   - 直接创建：单击+新建模型打开异常检测窗口 →（可选）设计基准建立定位模型（绘制掩膜、生成模板、橡皮擦擦除多余轮廓点；模型参数尺度模式/速度尺度/特征尺度/阈值模式/边缘阈值参见轮廓匹配模块特征模板）→ 单击下一步设定检测区域 → 单击下一步批量训练（至少一张 OK 图像建模，一般选 3~5 张；可选设置尺寸模式和特征类型；OK/NG 图像分别标记后单击训练；可在模型验证处滑动滑块调整 OK 标准，导入验证图像单击模型验证获取统计结果）→ 单击完成。
   - 继承：选择继承并新建模型 → 设置继承方式（按区域：从前序模块订阅区域；按图像：从前序模块选择掩膜图像）→ 加载多张建模图像（至少一张 OK，一般 3~5 张）→ 可选设置尺寸模式和特征类型 → 标记 OK/NG → 单击训练 → （可选）调整 OK 标准 → 完成。
3. 配置运行参数（继承模型时仅分数阈值）与结果显示，执行查看输出。

**注意事项**：
- 建立定位模型可避免因位置偏差导致的误检。
- 至少需要一张 OK 图像进行建模，一般选择 3~5 张建模图像。

## 边缘模型类（边缘模型缺陷检测 / 边缘对模型缺陷检测）

### 边缘模型缺陷检测
**功能**：将目标物体边缘与基准模型进行对比，输出边缘缺陷信息，如边缘偏移和断裂。边缘检测基于卡尺工具。算法含位置偏移缺陷检测（边缘点与模型边缘距离超过位置偏移阈值为偏移缺陷点，连续缺陷点长度大于缺陷长度阈值构成缺陷区域）、断裂缺陷检测（查找边缘点失败即为断裂点，连续断裂点长度满足缺陷长度阈值判定为断裂缺陷区域）、阶梯缺陷检测（相邻点垂直方向偏离大于阶梯偏离高度为阶梯点，相邻阶梯点尺寸大于最小阶梯长度为阶梯缺陷区域）。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序一般含图像源；目标存在位姿变化时搭配位置修正和模板匹配做粗定位（前序含位置修正时，位置修正基准点必须在一张图像上创建），无位姿变化时可仅搭配图像源 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms）；模块状态 | float/int | 运行耗时；0=NG（红色），1=OK（绿色） |
| 缺陷个数；缺陷框（中心X/Y、宽度、高度、角度） | int/box | 检测到的缺陷个数及缺陷框 |
| 卡尺框（中心X/Y、宽度、高度、角度） | box | 定位目标所使用的卡尺框 |
| 缺陷卡尺起始索引/终止索引 | int | 缺陷在所有卡尺中的起始/终止位置索引 |
| 缺陷类型 | int | 6=边缘位置偏移，8=边缘断裂缺陷，9=边缘阶梯差缺陷 |
| 缺陷长度 | float | 沿轨迹方向的缺陷长度，即所占卡尺数量 |
| 边缘点（X/Y）；轮廓点状态；边缘点个数 | point/int | 检测到的边缘点及各轮廓是否被检测出（0=未检测到，1=检测到） |
| 理想卡尺点（X/Y） | float | 理想中检测到边缘点的坐标 |

**参数**——运行参数（检测参数与边缘模型中的训练参数相同）：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 缺陷长度阈值 | — | — | 连续位置偏移缺陷点构成的轮廓长度大于该值时，判定存在位置偏移缺陷 |
| 位置缺陷使能 | 开/关 | — | 开启后可检测位置偏移缺陷 |
| 位置偏移阈值 | — | — | 目标图像边缘点与建模图像标准边缘点的距离大于该阈值时，判定为位置偏移缺陷待选点（位置缺陷使能的子参数） |
| 断裂缺陷使能 | 开/关 | — | 开启后可检测断裂缺陷 |
| 阶梯缺陷使能 | 开/关 | — | 开启并配置子参数后可检测锯齿类缺陷（尺寸和面积较小、偏离幅度较低） |
| 阶梯偏离高度 | — | — | 相邻两个边缘点高度偏差大于该阈值时判定为阶梯缺陷候选点 |
| 最小阶梯长度 | — | — | 阶梯缺陷候选点相邻个数超过该值则判定为阶梯缺陷 |

| 追踪容忍 | — | — | 距离阈值，用于边缘点修正去除干扰点；为 0 不修正，大于 0 时在该阈值内寻找更符合边缘趋势的边缘点 |

边缘模型训练参数（模板配置窗口）：边缘类型（最强/第一条/最后一条——查找方向上梯度大于边缘阈值且变化幅度最大/第一条/最后一条的边缘）、边缘极性（任意极性/从黑到白/从白到黑）、边缘强度（即梯度阈值，取值 0~255，数值越大抗噪越强、边缘越少）、卡尺高度（边缘查找不准确时适当增大）、卡尺宽度（增大可获取更稳定边缘点，噪点多时建议较大值，耗时增大）、卡尺间距（间距越小边缘点越多、耗时越大）、边缘精细检测（开启后用实际查到的边缘点修正手动绘制轨迹并再次提取，降低手绘轨迹不准引入的风险）、滤波尺寸。

**使用步骤**：
1. 配置基本参数。
2. 配置边缘模型：边缘模型页签打开模板配置窗口 → 在图像上绘制待提取为模型的轮廓轨迹（单击绘制节点，拖动画线段，双击结束；可删除/插入轨迹节点、闭合轨迹、调整节点位置、清空基准等）→ 生成模型 → 可用橡皮擦擦除不必要轮廓点 → 按需调整训练参数重新生成模型 → 可保存模板至本地 → 确定。
3. 配置运行参数与结果显示。
4. 执行或连续执行模块，查看输出结果。

**注意事项**：
- 前序模块包含位置修正时，创建位置修正基准点必须在一张图像上进行：先运行一次流程，双击位置修正模块手动点击创建基准点。
- 对后序模块无特殊要求。

### 边缘对模型缺陷检测
**功能**：将实际提取到的边缘对与预先建立的边缘对模型比较，分析边缘对的存在性、位置、宽度等信息，判断是否存在边缘断裂等边缘对缺陷。常用于待检边缘区域呈不规则分布的情况，例如呈曲线分布。算法包括宽度缺陷检测（边缘对过窄/过宽）、位置缺陷检测（理想边缘对中心与实际中心差值超过位置偏移阈值）、断裂缺陷检测、阶梯缺陷检测、气泡缺陷检测（模型边缘对平均灰度与实际平均灰度差值超阈值，平均灰度指边缘点对连线上所有点的灰度均值，双线性插值）。边缘检测基于卡尺工具。

**输入**：

## 直线圆弧类（直线边缘缺陷检测 / 直线对缺陷检测 / 圆弧对缺陷检测 / 圆弧边缘缺陷检测）

### 直线边缘缺陷检测
**功能**：通过分析图像中的直线边缘特征，精确定位并标记缺陷，输出缺陷的位置和大小等信息。常用于待检边缘区域呈明显直线状分布的场景。缺陷类型：断裂（按与基准边缘直线位置关系分左断裂/右断裂）、位置偏移（分左缺陷/右缺陷）。

原理：1) 获取基准边缘直线（方式 1：外部生成基准直线边缘直接传入，对应前序已获取该边缘、图集待检区域无法有效提取稳定边缘、基准已知三种场景；方式 2：模块内部通过直线查找自行查找）；2) 在基准直线与检测 ROI 框的相交线段上均等分布 N 个卡尺，每个卡尺提取一个边缘点组成点集（卡尺查找失败时用卡尺中心点作为该边缘点）；3) 分析点集（判定边缘点自身状态→断裂/OK；与基准直线比较→偏移/OK）；4) 连续断裂/缺陷点聚类成区域，计算面积和尺寸特征，输出满足面积或尺寸要求的缺陷区域。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 前序一般将图像源作为前序模块，提供图像输入；前序还可包括直线查找，以实现更精确的目标定位 |
| 基准直线 | line | 外部生成基准直线边缘时直接传入（输入直线类型需相应配置） |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms）；模块状态 | float/int | 运行耗时；0=NG（红色），1=OK（绿色） |
| 缺陷个数；ROI缺陷个数 | int | 检测到的缺陷个数；数组形式，每个 ROI 检测到的缺陷个数 |
| 缺陷框（中心X/Y、宽度、高度、角度）；缺陷框索引 | box/int | 缺陷框及索引（顺序递增数组，长度与缺陷框数据长度相同） |
| 缺陷尺寸；缺陷面积 | float | 沿轨迹方向的缺陷长度；缺陷框的面积 |
| 卡尺起始值；卡尺终止值 | int | 根据卡尺宽度和卡尺间距从直线起始点顺序放置序号点的起始/终止序号点 |
| 缺陷类型 | int | 6=边缘位置偏移，8=边缘断裂缺陷，9=边缘阶梯差缺陷 |
| 检测区域（中心点X/Y、宽度、高度、角度） | box | 图像中需进行检测的 ROI 区域 |
| 边缘点（轮廓点X/Y）；轮廓点状态；边缘点个数；ROI边缘点个数 | point/int | 检测到的边缘点及状态（0=未检测到，1=检测到）；数组形式的每个 ROI 边缘点个数 |
| 卡尺框（中心X/Y、宽度、高度、角度） | box | 定位目标所使用的卡尺框 |
| 理想卡尺点状态；理想卡尺点数量；ROI理想卡尺点数量 | int | 理想中直线边缘点的创建状态（1=创建成功）；数量；每个 ROI 的数量 |
| 标准直线（起点X/Y、终点X/Y）；标准直线角度 | line/float | 标准直线及相对 X 轴正方向顺时针偏移的角度 |
| 屏蔽区多边形；屏蔽区字符串 | polygo/string | 需屏蔽的 ROI 区域；用于后序模块继承屏蔽区 |

**参数**——基本参数（前序包含直线查找时需配置）：

### 边缘位置趋势分析

原理：1) 根据预设运行参数在 ROI 区域内获取符合要求的卡尺区域集合；2) 在每个卡尺区域获取一个边缘点，并获取所有边缘点到 ROI 某边的距离信息（最大值、最小值、平均值等）；3) 根据设置的距离阈值提取满足要求的点集，得到点集距离的最大/最小/平均距离，并分别输出一个最大距离和最小距离对应的点。

## 缺陷检测选型对比表（缺陷形态 → 选哪个模块）

| 缺陷形态 / 场景 | 推荐模块 | 要点 |
| --- | --- | --- |
| 无纹理表面上的点/线/块状缺陷（划伤、破损、异物），不受表面亮度变化影响 | 表面缺陷滤波 | 输出滤波响应图，需后序 Blob 分析筛选缺陷 blob |
| 字符脏污、缺失、差异（雕刻/印刷字符） | 字符缺陷检测 | 仅注册 OK 样本建模比对；基准可继承高精度匹配 |
| 物料整体结构/灰度异常（OK/NG 判定） | 异常检测 | OK 样本注册建模，按分数阈值判 NG；内含模板匹配无需粗定位 |
| 边缘偏移、断裂、阶梯（单条边缘，任意/曲线轨迹） | 边缘模型缺陷检测 | 绘制轨迹建模；检测参数与训练参数相同；基于卡尺 |
| 边缘对宽度/位置/断裂/阶梯/气泡缺陷（边缘呈曲线等不规则分布） | 边缘对模型缺陷检测 | 轨迹可手绘或按起始范围自动生成；支持宽度合格比例、灰度合格阈值 |
| 明显直线状分布边缘的断裂、位置偏移 | 直线边缘缺陷检测 | 基准直线可外部传入（直线查找）或内部查找；支持缺陷极性（轨迹左/右/两侧） |
| 一对直线之间的形变、断裂（矩形工件边缘形变缺损、毛刺、污垢） | 直线对缺陷检测 | 运行参数与圆弧对缺陷检测类似；可搭配直线查找精定位 |
| 圆环状分布、有一定径向宽度的边缘区域（凹凸、断裂、宽度异常） | 圆弧对缺陷检测 | 前序用两个圆查找取内外径差判定宽度合格范围；不判定缺陷极性 |
| 弧边缘断裂、凹陷、凸点、磨损 | 圆弧边缘缺陷检测 | 卡尺在圆弧上环形分布；圆轮廓模糊时建议开启标准输入 |
| 工件上同时存在直线边缘与圆弧边缘缺陷 | 边缘组合缺陷检测 | 直线+圆弧二合一，参数同两个独立模块 |
| 工件上同时存在直线对与圆弧对缺陷 | 边缘对组合缺陷检测 | 直线对+圆弧对二合一，增加中心点使能 |
| 需要边缘点距 ROI 边的距离统计（最大/最小/平均）与走势分析、筛选点位 | 边缘位置趋势分析 | 卡尺系分析工具，不直接判定缺陷；后序接点集 |
| 需要边缘对距离统计与走势分析、筛选点位 | 边缘对位置趋势分析 | 8 种边缘对查找类型；支持理想边缘宽度与中心点使能 |
