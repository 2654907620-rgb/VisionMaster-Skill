# VM 模块参考：定位

## 速览

1. **模板匹配怎么选**：优先用**轮廓匹配**（效率与精度兼得的新一代模板匹配）；对精度要求极高用**高精度匹配**（金字塔多层搜索）；目标有形变、只需有无/方向/计数用**快速匹配**（粗糙轮廓、仅金字塔顶层搜索）；目标无明显稳定轮廓但灰度分布稳定（低对比度、噪声干扰、光源/曝光变化）用**灰度匹配**（NCC）。
2. **图形定位**：针对回字形（矩形 Mark 点）/十字形 Mark 点专用粗定位，输出中心/角度/尺度，后接位置修正 + 圆查找/直线查找/卡尺工具做精定位。
3. **位置修正**：根据模板匹配结果实时修正后序模块 ROI，是几乎所有"匹配 → 精定位"流程的中间枢纽；前序为轮廓匹配/高精度匹配时自动订阅尺度，可修正不同大小目标。
4. **Blob 类分工**：**Blob 分析**在二值图上提取连通域（数量/位置/形状/方向），适合高对比度、无旋转缩放场景；**Blob 标签分析**直接在灰度图上按灰度值区分 Blob 类别标签，典型搭配 DL 图像分割做缺陷分类。
5. **圆查找/椭圆查找**：基于"环形 ROI + 卡尺取边缘点 + 拟合"，单模块一次只查一个圆/椭圆；多圆有规律排列用**阵列圆查找**，无规律多圆配合 Group 循环。
6. **直线类分工**：单条直线用**直线查找**；不连续（断裂）边缘用**直线查找组合**；一区域内多条线用**多直线查找**（半导体硅片/引脚间距）；两条边的"边对"用**平行线查找/矩形检测**（边对式边缘类型：最宽/最窄/最强/最弱/第一对/最后一对/最接近/最不接近）。
7. **平行线计算/中线查找/垂线查找/角平分线查找**是纯几何计算模块，无边缘提取运行参数，输入来自直线查找等前序模块。
8. **卡尺工具**是边缘检测的底层通用工具（投影→差分滤波→极值点→插值→评分→输出亚像素边缘），支持单边缘/边缘对与多种评分方式；**边缘查找**（简化版单边缘）、**顶点检测**（加扫描宽度）均基于它。
9. **边缘交点/四边形查找**本质是"多次直线查找 + 几何解算"（交点坐标/顶点/对角线交点/中点线交点等）。
10. **路径提取**沿绘制路径（轨迹/扇圆）等间隔取点或查边缘点，用于点胶胶路检测。
11. **目标跟踪**利用位置+速度预测轨迹做跟踪计数，前序为 DL 目标检测或定位类模块。
12. 拟合方式（最小二乘/huber/tukey）随离群点增多逐次选用；剔除点数与剔除距离建议结合使用。
13. 边缘阈值（梯度阈值，0~255）越大抗噪越强但可能丢目标边缘；滤波尺寸在边缘贴近时过大会丢边缘。
14. 匹配类模块通病提醒：目标有缩放/旋转时必须改尺度范围/角度范围，否则匹配失败。

## 模板类定位（轮廓匹配 / 高精度匹配 / 快速匹配 / 灰度匹配 / 图形定位）

### 轮廓匹配
**功能**：提取 ROI 中的边缘点特征创建模板，在图像中搜索与模板相似的目标，实现定位、计数和判断有无。新一代模板匹配，兼具匹配效率与定位精度，建议优先使用。

**原理**：基于边缘点的模板匹配算法公式涉及参数：x=模板在x轴的平移量、y=模板在y轴的平移量、θ=模板的旋转角度、scaleX/scaleY=模板在x/y轴的伸缩尺度（公式原文为图示）。Fm 为模板图像中的显著边缘轮廓点，Fs 为匹配图像对应区域的显著边缘轮廓点，S=(Fm,Fs) 度量模板特征点经拉伸、旋转、平移后与目标图像边缘轮廓点相匹配的比例，比例越高得分越高。算法遍历 (x,y,θ,scaleX,scaleY) 所有取值，选取满足相似度得分阈值且得分最高的 n 个结果输出（n 即最大匹配个数）。

**匹配加速机制**：1. 对待匹配图像建立图像金字塔；2. 在图像金字塔中自顶向下逐层进行目标搜索，直至找到满足条件的目标（示例：在含 R 和 P 的图像中搜索 R——顶层先找到候选 R 和 P，下一层进一步判定并调整位姿，删除错误候选 P，底层对 R 做最终位姿调整并输出）。速度尺度定义金字塔顶层大小（调节匹配搜索速率），特征尺度定义金字塔底层大小（调节抗形变能力）。

**输入**：
| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 待匹配图像，通常来自图像源模块 |

**输出**（模块结果）：
| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 模块运行耗时 |
| 模块状态 | int | 0=NG（红色），1=OK（绿色） |
| 匹配状态 | int | 1=匹配成功，0=匹配失败 |
| 匹配个数 | int | 与模板相同或相似对象的个数 |
| 匹配模板编号 / 匹配模板名称 | int / string | 所匹配模板的编号/名称 |
| 匹配框（中心点/中心X/Y/宽度/高度/角度） | box | 匹配对象最小矩形框；角度=较长边旋转至水平轴的角度，顺时针为正 |
| 匹配点（X/Y） | point/float | 每个匹配点坐标 |
| 尺度 / 尺度X / 尺度Y | float | 相对模板的等比例/X 轴/Y 轴缩放倍数 |
| 分数 | float | 匹配得分，1 表示与模板完全相同 |
| 横切值 | float | 匹配对象 Y 轴向 X 轴的旋转角度 |
| 检测区域（中心点/宽度/高度/角度） | box | 检测 ROI 区域 |
| 匹配轮廓信息 / 匹配轮廓点个数 | pointset / int | 轮廓点集信息（不显示）/轮廓点个数 |
| 轮廓点集（轮廓点X/Y）/ 轮廓点序号 | float / int | 各轮廓点坐标及编号 |
| 屏蔽区多边形（多边形点数/点集） | polygo | 屏蔽区多边形 |

| 输出掩膜（图像/宽度/高度/像素格式） | image | 检测区+屏蔽区算出的二值掩膜图，像素格式一般 17301505（Mono8） |

**参数**：

模板配置参数（特征模板页签 → 创建，最多支持创建 36 个特征模板）：
| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 尺度模式 | 自动 / 手动 | 自动 | 速度尺度的配置模式；自动不满足时切换手动调整速度尺度 |
| 速度尺度 | 1~20 | — | 值越大金字塔顶层图像越小、边缘点越稀疏，匹配越快，过大可能漏检 |
| 特征尺度 | 整数，不能大于速度尺度 | — | 金字塔底层大小，值越大抗形变能力越强、速度越快，过大可能误检、精度下降；取值 1 时最精细 |
| 阈值模式 | 自动 / 手动 | 自动 | 边缘阈值的调整模式 |
| 边缘阈值 | 1~255 | — | 边缘特征点与背景的灰度值差距，越大被淘汰的特征点越多 |
| 链长模式 | 自动 / 手动 | — | 最小链长的调整模式 |
| 最小链长 | — | — | 特征链的最小长度，链长超过该值才被保留 |
| 建模类型 | 原图建模 / 掩膜图建模 | — | 模板创建类型 |

掩膜列表操作：隐藏/显示掩膜、屏蔽掩膜、增强匹配（**仅高精度匹配支持**，开启后对相似度要求更高、匹配精度更高）、删除掩膜。
特征模板页签操作：模板排序（未开全部搜索模式时优先采用排序靠前的模板，找到符合最小匹配分数的目标即停止）、勾选模板、编辑模板、清空模板、载入模板。

运行参数：
| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 全部搜索模式 | 开/关 | 关闭 | 逐个使用所有勾选模板匹配，输出最优结果；开启后需设置多模板重叠率 |
| 多模板重叠率 | — | — | 不同模板检测目标重叠时：重叠率低于该值均输出，高于则仅输出分数高的目标。重叠率=重叠部分面积/两目标总面积 |
| 最小匹配分数 | 最大 1 | 0.5 | 相似度阈值，达到才判定为有效匹配 |

| 横切角度范围 | -45~45 | 0~0 | 目标相对模板沿横坐标轴的旋转角度范围（仅尺度范围XY类型） |

| 排序类型 | 按分数降序排序/按角度降序排序/按X由小到大排序/按Y由小到大排序/X由小到大，Y由小到大/Y由小到大，X由小到大 | — | 多目标时的排序依据 |
| 阈值类型 | 自动阈值 / 模板阈值 / 手动阈值 | — | 匹配阶段边缘对比度阈值来源 |
| 是否考虑噪点 | 开/关 | 关闭 | 考虑不在边缘链上的特征点，特征有毛刺则评分降低 |
| 延拓阈值 | — | — | 目标特征被图像边缘截断时，缺失特征相对完整特征的比例上限，可保证截断目标被找到 |

**使用步骤**：
1. 双击模块打开配置窗口，选择"特征模板"页签，单击"创建"打开模板配置窗口（默认显示当前图像源采集图像，可"选择其他图像"）。
2. 在图像上特征明显的区域绘制掩膜（支持绘制多个不同形状的掩膜），算法在掩膜区域内提取图像特征。
3. 可选：选择/锁定匹配中心、刷 ROI、擦除不必要轮廓点（橡皮擦大小可调）。
4. 调整模板配置参数（尺度模式/速度尺度/特征尺度/阈值模式/边缘阈值/链长模式/最小链长/建模类型），单击生成模板，直至效果满足需求。
5. 单击保存图标将模板保存至本地路径（模板存图默认开启，关闭则不保存模板图像），单击"确定"完成模板配置。
6. 在运行参数页签按业务需求配置匹配参数（分数/个数/极性/角度范围/尺度范围等）。

**注意事项**：
- 通常与位置修正、条件检测、脚本、测量类模块搭配；可与 N点标定配合实现 12 点标定（9 次平移 3 次旋转）实现工件定位。
- 匹配加速机制：建立图像金字塔，自顶层向下逐层搜索（速度尺度定顶层、特征尺度定底层）。
- 延拓阈值示例：大于 40 即可保证被图像边缘截断的目标被查找到。

### 高精度匹配
**功能**：提取物体的精细轮廓创建模板，定位精度较高但匹配效率较低；使用图像金字塔多层图像搜索目标（快速匹配仅顶层搜索）。适用于定位目标、识别方向、检测偏移角度等高精度场景。

**输入**：
| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 待匹配图像 |

**输出**：与轮廓匹配模块结果基本一致（耗时、模块状态、匹配状态、匹配个数、匹配模板编号/名称、匹配框及中心/宽/高/角度、匹配点、尺度/尺度X/尺度Y、分数、检测区域、匹配轮廓信息/点个数、屏蔽区多边形、多边形字符串、屏蔽区字符串、输出掩膜等）。

**参数**：模板配置过程与参数与轮廓匹配一致（掩膜额外支持"增强匹配"选项，为本模块独有）。运行参数与轮廓匹配基本相同，差异如下：
| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 尺度范围类型 | 尺度范围 / 尺度范围XY | — | 尺度范围XY 仅需设置 X 尺度范围、Y 尺度范围（无横切角度范围） |
| 是否输出轮廓 | — | — | 原文该模块参数未列出此项 |

其余参数（全部搜索模式/多模板重叠率/最小匹配分数/最大匹配个数/匹配极性/角度范围/尺度范围/最大重叠率/排序类型/阈值类型/是否考虑噪点/延拓阈值/超时控制/是否获取轮廓）定义与轮廓匹配同名参数相同，取值与默认值一致。

**使用步骤**：
1. 特征模板设置过程与轮廓匹配一致（创建模板、绘制掩膜、生成模板、保存）。
2. 若对特定掩膜内匹配精度要求高，可在掩膜列表开启"增强匹配"。
3. 配置运行参数后运行。

**注意事项**：
- 典型用法：高精度匹配 → 位置修正 → 二维码识别，保证 ROI 随部件位置变化。
- 通常与位置修正、N点标定、测量相关模块配合使用。

### 快速匹配
**功能**：提取物体的粗糙轮廓，匹配速度快，对存在形变的目标匹配效果更好，但精度低于高精度匹配；仅使用图像金字塔顶层搜索目标。适用于有无判断、方向判断、产品计数等对精度要求不高的场景。

**输入**：
| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 待匹配图像 |

**输出**：与高精度匹配基本一致，但尺度仅输出"尺度"（等比例缩放倍数），无尺度X/尺度Y；另有"多边形字符串"。

**参数**：模板配置过程和参数定义均可参考轮廓匹配。运行参数：
| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 全部搜索模式 / 多模板重叠率 | 同轮廓匹配 | 关闭 | 定义同轮廓匹配 |
| 最小匹配分数 | 最大 1 | 0.5 | 同轮廓匹配 |
| 最大匹配个数 | 1~1000 | 1 | 同轮廓匹配 |
| 匹配极性 | 考虑极性 / 不考虑极性 | — | 同轮廓匹配 |
| 角度范围 | -180~180 | -45~45 | 同轮廓匹配 |
| 尺度范围 | 0.1~10.0 | 1.00~1.00 | 无"尺度范围类型"，仅整体尺度范围；目标有缩放时必须调整 |
| 最大重叠率 | 0~100 | 50 | 同轮廓匹配 |
| 排序类型 | 6 种（同轮廓匹配） | — | 同轮廓匹配 |
| 阈值类型 | 自动阈值/模板阈值/手动阈值 | — | 同轮廓匹配 |
| 是否考虑噪点 | 开/关 | 关闭 | 同轮廓匹配 |
| 延拓阈值 | — | — | 同轮廓匹配 |
| 超时控制 | 0~10000（ms） | — | 同轮廓匹配 |
| 是否获取轮廓 | 开/关 | — | 同轮廓匹配 |

**使用步骤**：特征模板配置过程和轮廓匹配一致；运行参数按需配置。

**注意事项**：
- 缺针检测示例流程：快速匹配（匹配针脚特征）→ 位置修正 → 亮度测量 → 条件检测 → 格式化 → 发送数据。
- 通常与位置修正、条件检测、脚本、测量相关模块配合。

### 灰度匹配
**功能**：基于物体灰度值分布（归一化互相关性 NCC）做模板匹配，不依赖边缘点；适用于目标无明显且稳定轮廓、对比度较低、受随机噪声干扰的场景。光源变化或相机曝光时间变化时仍可匹配到目标。

**原理**：以模板图像和待匹配图像的灰度值分布作为特征，使用归一化互相关性（Normalized Cross Correlation，NCC）评价两者灰度值分布的相似性（公式原文为图示）。NCC=1 表示两灰度分布线性正相关（趋势相同，仅整体数值偏移或比例关系），0 表示线性无关，-1 表示线性负相关。算法计算模板图像所有可能的旋转平移结果与待匹配图像的相似性，取相似度分数达到阈值且最高的 n 个结果作为输出。匹配加速使用图像金字塔：金字塔层数相当于轮廓匹配的速度尺度，匹配结束层相当于特征尺度。

**输入**：
| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 | image | 待匹配图像 |

**输出**：匹配状态、匹配个数、匹配模板编号/名称、匹配框（中心/宽/高/角度）、匹配点、分数、检测区域、屏蔽区多边形、输出掩膜等（无尺度类输出）。

**参数**：

灰度模板配置参数：

## Blob 类（Blob分析 / Blob标签分析）

### Blob分析
**功能**：在二值图像中定位或分析目标物体（连通域），输出目标的存在性、数量、位置、形状、方向以及 Blob 间拓扑关系等信息。适用：仅需二维特征、对比度高、判断有无、缩放固定且无旋转；不适用：对比度低、两个灰度级不能反映对象属性。

**原理**：Blob = 图像上由互相连通的像素点构成的区域；连通分 4连通（上下左右相邻）和 8连通（加上对角线相邻）。分析流程：图像二值化（按预设像素阈值转为纯黑 0/纯白 255）→ 孔洞填充（填充被 Blob 包围且与 Blob 颜色相反的部分，由填充面积阈值决定）→ Blob 提取（按 4/8 连通特性提取，由连通性配置）→ Blob 筛选（由各项"使能"参数决定）→ Blob 排序（由排序特征和排序方式决定）→ Blob 输出（二值化图像、Blob 图像、符合筛选条件的 Blob 数量及各 Blob 特征信息与特征加权得分）。

**输入**：
| 输入项 | 类型 | 说明 |
| --- | --- | --- |

### 卡尺工具
**功能**：测量物体的宽度、边缘特征的位置以及图像中边缘对的位置和间距，在 ROI 内快速精确检测和定位。算法流程：ROI → 沿一个方向投影得一维数据 → 一维差分滤波 → 极值点查找 → 极值点插值（亚像素） → 极值点评分 → 边缘输出。

**原理**：卡尺工具将图像区域数据沿一个方向投影得到一维数据，对该数据做一维差分滤波（滤波核越大抑制噪声越强，但极值点位置精度可能越差），按边缘极性选取极值点查找目标（白到黑→极小值/谷值；黑到白→极大值/峰值；任意极性→两者），对极值点插值得到亚像素精度的边缘位置，再按预设评分方式计算得分，最终输出符合得分要求的亚像素极值点。评分方法分三大类：位置评分（绝对位置/相对位置/归一化位置/归一化相对位置）、间距评分（间距差/相对间距差/间距）、对比度评分（对比度/灰度）；单边计分函数分递增/递减（由 x0、x1、xc 调节曲线走势），双边计分函数为左右两个单边函数合并，共四种组合；多种计分方式联合使用时按公式合并为总计分（公式原文为图示，文字缺失）。

**输入**：
| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像 + ROI | image / ROI | 与图像源、轮廓匹配、位置修正组合调用（粗定位 + 本模块精定位） |

**输出**：
| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms）/ 模块状态 | float / int | — |
| 边缘状态 / 边缘个数 / 分数 | int / float | 是否位于边缘；查找到的边缘个数；得分（1 为满分） |
| 边缘\*极性（\*代表0-1） | int | 1=从黑到白，2=从白到黑，3=任意极性 |
| 边缘\*位置（\*代表0-1） | float | 边缘点所在位置 |
| 边缘点\*（\*代表0-1，X/Y） | point | 边缘点坐标 |
| 测量宽度 | float | 两个边缘点在投影法线方向的宽度 |
| 直线\*起点/终点/角度（\*代表0-1） | point / float | 边缘直线信息 |
| 圆弧\*（\*代表0-1：中心点X/Y、半径、起始角度、角度范围） | — | 扇环 ROI 时的圆弧信息 |
| 检测区域 | box | 常规区域输出 |

**参数**：
| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 边缘模式 | 单边缘 / 边缘对 | — | 单边缘=检测边缘位置（定位/计数/有无）；边缘对=检测边缘间距（如工件尺寸测量） |
| 滤波尺寸 | ≥1 | — | 增强边缘抑制噪声；边缘贴近时影响精度甚至丢边缘 |
| 边缘阈值 | 0~255 | — | 梯度阈值，越大抗噪越强、边缘越少 |
| 边缘0/1极性 | 从黑到白 / 从白到黑 / 任意极性 | — | 边缘模式为边缘对时才有边缘1极性 |
| 边缘对宽度 | — | — | 期望输出的边缘对像素间距尺寸；仅当位置归一化/相对位置归一化/间距/间距差/相对间距差计分中一个或多个开启时有意义，作为计分因子的缩放因子 |
| 最大结果数 | — | — | 期望输出的边缘对最大数量，超出按分数由高到低输出 |
| 排序方式 | 分数升序 / 分数降序 / 方向正向 / 方向逆向 | — | 边缘点在结果页签的显示排序 |
| 对比度/边缘对对比度 | 开/关（评分项） | — | 单边缘时为对比度、边缘对时为边缘对对比度；按对比度均值计分；曲线类型（递增/递减）+起点/X中点/终点/Y计分（对应 x0、x1、xc、y0~y1） |
| 灰度 | 开/关（评分项） | — | 按边缘灰度或边缘对灰度均值计分 |
| 位置 | 开/关（评分项） | — | 按边缘或边缘对中心相对投影区域中心的绝对位置之差评分 |
| 相对位置 | 开/关（评分项） | — | 按位置差（可正可负）评分 |
| 归一位置 | 开/关（评分项，仅边缘对） | — | 按绝对归一化距离评分，归一化分母为边线对宽度 |
| 归一相对位置 | 开/关（评分项，仅边缘对） | — | 按归一化位置差（可正可负）评分，归一化分母为边缘对宽度 |
| 间距 | 开/关（评分项，仅边缘对） | — | 按边对距离/边缘对宽度，单边计分方式评分，理想接近 1 |
| 间距差 | 开/关（评分项，仅边缘对） | — | 按\|(边缘对距离-边缘对宽度)/边缘对宽度\|，单边计分，理想接近 0 |
| 相对间距差 | 开/关（评分项，仅边缘对） | — | 按(边缘对距离-边缘对宽度)/边缘对宽度，双边计分方式评分（唯一双边计分函数） |
| 投影方向 | 纵向投影或径向投影 / 横向投影或环向投影 | — | 矩形 ROI：投向矩形宽（纵向）或矩形高（横向）；扇环 ROI：投向扇环形圆弧（径向，边缘点按圆环方向排列）或扇环形半径（环向，按半径方向排列） |
| 模糊边缘 | 开/关 | — | 增强候选边缘点集提取能力，适用于干扰点多或边缘模糊的图像，但耗时明显增加 |

评分原理补充：单边计分函数分递增/递减两种（可由 x0、x1、xc 调节曲线走势）；双边计分函数为左右两个单边函数合并，共四种组合；多种计分方式联合使用时按公式合并为总计分（公式原文为图示，文字缺失）。

**使用步骤**：
1. 与图像源、轮廓匹配、位置修正组合调用，ROI 上箭头表示边缘查找方向。
2. 选择边缘模式（单边缘/边缘对）。
3. 设置滤波尺寸、边缘阈值、极性。
4. 边缘对模式时设置边缘对宽度并按需开启位置/间距类计分。
5. 设置投影方向、排序方式、最大结果数。

**注意事项**：
- 极值点查找目标与极性对应：白到黑→极小值（谷值）；黑到白→极大值（峰值）；任意极性→两者。
- 投影区域可能超出图像边界，超出部分填充其他灰度值；投影区域形状目前支持任意角度的矩形，通过插值获取采样。
- 滤波核越大抑制噪声越强，但极值点位置精度可能越差。

### 目标跟踪
**功能**：对目标物体进行跟踪和计数。原理：利用目标的位置和速度信息，通过数学模型预测目标运动轨迹。核心元素：ROI（感兴趣区域）、计数线（ROI 在跟踪方向上的中线）、有效计数目标（进入 ROI 且越过计数线）、跟踪框（算法生成的可跟踪矩形框）、X/Y方向速度（跟踪框跟踪速度）。

**原理**：在 ROI 区域发现目标时获取目标初始状态信息（位置、速度、大小），结合 X/Y 方向速度建立数学模型预测目标轨迹实现跟踪。跟踪过程中算法不断更新目标状态信息并进行轨迹预测，将当前检测结果与之前被跟踪目标关联以确定是否为同一目标；目标离开视野或被遮挡时重新寻找目标并获取新初始状态，实现连续跟踪和计数。

**输入**（基本参数）：
| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 图像输入 | image | 图像源采集的连续帧图像，必须按采集的时间序列排序 |
| BOX输入 | box | 前序模块输出目标信息矩形，可订阅目标信息矩形或检测区域；前序一般为 DL 目标检测和定位类模块（如轮廓匹配和 Blob 分析） |
| 检测区域 | box | 跟踪和计数区域，根据目标进入和离开该区域的状态计数 |

**输出**：
| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms）/ 模块状态 | float / int | — |
| 目标数 | int | 当前帧检测区域内跟踪到的目标总数 |
| 计数总数 | int | 过去所有帧跨过检测线的所有目标数累计和 |
| 单帧计数 | int | 当前帧目标在检测线上的个数 |
| 多边形轮廓点（轮廓点X/Y） | float | 目标轮廓顶点坐标 |
| 目标Id位置（X坐标/Y坐标）/ 目标Id | float / int | 目标 id 编号位置及编号 |
| 边缘点个数 | int | 输出的边缘点个数 |
| 检测区域（中心点/宽/高/角度） | — | — |
| X方向速度 / Y方向速度 | float | 运行参数中设置的值 |
| 检测线（起点X/Y、终点X/Y）/ 直线角度 | line / float | 计数线信息 |

**参数**：
| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| X方向速度 | — | 1.0 | 跟踪框对横向移动（从左至右）物体的跟踪速度；跟踪框比目标慢时逐次增大（1.1、1.2、1.3……），快时逐次减小（0.9、0.8、0.7……），直至基本一致 |
| Y方向速度 | — | 1.0 | 纵向移动（从上至下）物体的跟踪速度，调整方式同上 |
| 允许缺帧数 | — | — | 目标检测模块未检测到目标、输入 Box 接收不到数据定义为丢帧；未超过允许缺帧数不影响计数，超过则认为前后是同一个目标，不进行计数 |
| 轨迹重叠率 | 1~100 | 30 | 两个目标框之间重叠率超过该值则认为是同一个目标 |

**使用步骤**：
1. 基本参数页签配置图像输入、Box输入和检测区域。
2. 单击执行或连续执行查看运行结果。
3. 根据实际需求配置运行参数（跟踪状态不理想时调节 X/Y 方向速度）。
4. （可选）单击清空计数清除当前计数，重新从 0 开始计数。

**注意事项**：
- 检测区域应尽量位于图像中央：区域宽度尽量与图像宽度相同；区域高度按目标尺寸设置，包含 3~5 个目标高度为最佳。
- 目标离开视野或被遮挡时，算法重新寻找目标并获取新的初始状态信息，实现连续跟踪和计数。

### 输出项类型通用说明

定位类模块结果中反复出现的公共输出项，类型含义如下（各模块具体条目见对应章节）：

- **耗时（ms）**：float 型，模块运行耗费时间。
- **模块状态**：int 型，0=NG（模块红色）、1=OK（模块绿色）。
- **检测区域**：box 型，图像中需进行检测的 ROI 区域，含中心点（X/Y）、宽度、高度、角度（相对水平方向/正准位姿的旋转角度，顺时针为正，正准位姿为 0 度）。
- **ROI圆弧**：annull 型，含检测圆弧中心点（X/Y）、内径、外径、起始角度、角度范围。
- **屏蔽区多边形**：polygo 型，绘制的屏蔽区多边形（不进行检测的区域），含多边形点数（int）、多边形点集（point 型，多边形点X/Y）。
- **屏蔽区字符串**：string 型，屏蔽区位置字符串信息，主要用于后序模块继承屏蔽区。
- **多边形字符串**：string 型，ROI 各顶点 X/Y 坐标以英文逗号隔开的字符串。
- **输出掩膜**：image 型，根据检测区域和屏蔽区域计算出的掩膜图像（二值图输出），含宽度、高度、像素格式；像素格式一般为 17301505，表示 Mono8 格式。
- **轮廓点状态**：int 型，0=未检测到轮廓点，1=检测到轮廓点。
