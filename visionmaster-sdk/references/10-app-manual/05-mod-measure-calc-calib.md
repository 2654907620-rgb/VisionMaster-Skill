# VM 模块参考：测量 · 标定 · 运算 · 颜色处理

> 本文件为「模块使用参考」分片的蒸馏版，聚焦**参数含义与配置方法**（SDK 文档未覆盖的一层）。覆盖测量(10)、标定(10)、运算(11)、颜色处理(6) 共 41 个模块。图片语法已删除，仅保留图注与"如下图所示"语义。

## 速览

1. **标定是 VM 工业落地的命门**：解决「像素→毫米」「上下相机对位」「旋转中心求解」三大问题，产物为**标定文件**（N点/N图像/映射标定生成 **xml**；单位转换支持 **iwcal/txt/xml**；旋转标定支持 **xml/iwcal**；标定加载仅 **xml**）。
2. **四种标定适用场景对比**（详见 §2.9）：
   - **N点标定**：输入"图像像素点 ↔ 运动机构物理点"一一对应，建立图像系↔机构物理系转换。**需机构配合走位**（N≥4，常见 9 点/12 点），最通用。
   - **N图像标定**：用途与 N点相同，但用**海康自研标定板**自动确定像素点，**精度更高**，需 ≥4 张标定板图像，**无需机构走位**。
   - **标定板标定**：用标定板（棋盘格/圆/海康 4 型）建立图像系↔物理系，用于"测像素距离换算物理距离""多相机统一到同一物理系"，**结果仅对与标定板同一平面有效**。
   - **映射标定 / 相机映射**：建立**两个图像坐标系之间**的映射（上下相机对位）。相机映射订阅前序特征提取模块的点集；映射标定用海康自研标定板图像或对应文件。
3. **单点抓取 vs 单点纠偏 vs 单点对位**（详见 §三）：
   - **单点抓取**：单相机拍物料的**抓取**场景；输入像素点+示教物理点(+示教拍照物理点)+标定文件；输出**相对偏移量 + 绝对抓取坐标(X/Y/R)**；配平移旋转标定。末端夹具与旋转轴**不共轴时必须填示教拍照物理点**。
   - **单点纠偏**：单相机拍物料的**纠偏**场景；参数与单点抓取**基本一致（除示教拍照物理点相关参数）**；输出**相对偏移量 + 绝对纠偏坐标(X/Y/R)**；用于修正物料姿态。
   - **单点对位**：计算**对象点对位到目标点所需偏移量**（x/y/theta）；**输入为目标点与对象点的物理坐标**，**必须配合标定转换模块**；Δθ 归一化至 **-π~π**；无绝对抓取坐标概念。
4. **标定误差允许范围**：相机标定允许误差范围 **0.1~0.5**（标定板标定、畸变标定明确给出）。
5. **自由度**（多数标定模块通用）：①缩放、旋转、纵横比、倾斜、平移及透射（**透视变换**）；②缩放、旋转、纵横比、倾斜及平移（**仿射变换**）；③缩放、旋转及平移（**相似性变换**）。自由度逐步降低，**推荐默认（透视变换）**。例：正方形经透视→梯形，仿射→矩形，相似性→大小变化的方形。
6. **权重函数**：最小二乘 / Huber / Tukey；选 Huber 或 Tukey 需设**权重系数**（对应函数的**削波因子**，推荐默认值）。
7. **旋转中心**：N点标定中"旋转轴与图像中心不共轴"时需设**旋转次数（一般 3，且旋转在第 5 个点进行）**；常见 9 点（共轴，9 次平移）/ 12 点（不共轴，9 平移+3 旋转）。
8. 测量类模块多支持**坐标系选择**（图像坐标系 / 特定坐标系）：选特定坐标系时结合"坐标系矩阵"中选择的标定矩阵计算，输出**实际物理距离**。
9. **角度符号约定**：图像坐标系为**左手系**（原点左上、x 向右、y 向下）；顺时针为正、逆时针为负（不同模块基准不同，见各条）。
10. **颜色空间**：RGB / HSV / HSI（颜色抽取、颜色测量、颜色分割、颜色转换支持）；颜色转换额外支持转 **YUV** 与**灰度**。颜色处理模块均需**彩色（RGB）输入**。
11. **标定板类型**：棋盘格、圆、海康I型、海康II型、海康扩展I型、海康扩展II型。海康板在棋盘格基础上用带位置信息的码替代部分格子（I 型 1 码占 4 格；II 型码放白格中）。海康**常规板行列最大 255**，**扩展板行列最大 1000**；海康板**码建议占据 ~100 像素**才易解译。
12. **海康板自带物理坐标系**：因码记录了角点物理坐标与方向信息，无论板如何放置都有相同默认物理坐标系；棋盘格/圆板则以**左上角第一个角点为原点、轴与格边平行**（列数>行数时坐标系位置与方向变化，特征点多的方向为 X 轴）。
13. **畸变标定**三种畸变类型：**径向畸变**（以畸变中心沿径向，离中心越远越大）、**透视畸变**（近大远小，被测物与相机倾斜导致边缘夹角变化）、**径向透视畸变**；需再配合**畸变校正**模块才实际生效。
14. **标定转换正/逆公式**：图像→物理 `Pw=H·PI`；物理→图像 `PI=H⁻¹·Pw`。输出中的**单像素精度**为 H 中的尺度，**平移X/Y、旋转、尺度、斜切、宽高比**为 H⁻¹ 的分量。
15. **单位转换仅近似运算**：物理距离 = 像素间距 × 单像素精度 × 像素当量修正；精确计算建议用"标定转换 + 点点测量"。
16. **旋转计算**把点/线绕旋转中心旋转（**正=顺时针，负=逆时针**，左手图像系）；**坐标转换**配合划片拆分把划片内点映射回原图坐标（坐标转换使能默认**开**，关则输入=输出）。
17. **变量计算**是"计算器"+订阅替换：支持 int/float/**POINT** 输出类型与大量数学函数，POINT 仅支持点±、点×常数，不支持初始化。
18. **标定加载**只支持加载 **N点标定 / N图像标定 / 映射标定** 生成的 **xml** 文件，用于排查标定问题或输出标定矩阵给运算模块；"方案存矩阵"启用后可把标定数据存入方案。
19. **通用输出字段**：几乎所有模块结果含**耗时(ms)**（float）与**模块状态**（int，0=NG 红、1=OK 绿）。通用输出结构：**检测区域(box)、ROI圆弧(annull)、输出掩膜(image)**。
20. **像素格式码**：**17301505 = Mono8**；**35127316 = RGB24**；直方图类输出为长度 **256** 的 int 数组，累积直方图为 **256 定长**数组。

## 一、测量模块

> 测量分类用于距离测量、像素统计等。显示结果中各模块结构大同小异（均有耗时、模块状态）。

### 线圆测量

**功能**：过"被查找圆的圆心"向"被测量直线"作垂线，返回直线与圆的垂直距离及相交点坐标。多用于工件圆孔与某边距离的合格性判断。一般与圆查找、直线查找配合（前序定位圆与直线并输出坐标）。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 输入源 | 图像 | 前序模块图像（图像源或图像处理输出）；来源选择=订阅时可不设置，=绘制时必须设置 |
| 来源选择 | 订阅 / 绘制 | — |
| 线输入（订阅时） | 按线 / 按点 / 按坐标 | 三种方式订阅直线 |
| 圆输入（订阅时） | 按圆 / 按参数 | 两种方式订阅圆 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 | float | 模块运行耗时（ms） |
| 模块状态 | int | 0=NG（红），1=OK（绿） |
| 测量直线 | line | 输入直线 |
| 测量直线起点/终点 X、Y | float | 输入直线起点/终点的 X/Y 坐标 |
| 测量直线角度 | float | 相对水平线旋转角；顺正逆负 |
| 测量圆环 | annull | 输入或查找到的测量圆环 |
| 圆心点X / 圆心点Y | float | 圆心坐标 |
| 圆内径 | float | 默认 **0** |
| 圆半径 | float | — |
| 圆起始角度 | float | 默认 **0 度** |
| 圆角度范围 | float | 默认 **360 度** |
| 交点1 / 交点2 X、Y | point | 测量直线与测量圆的交点 |
| 垂足点X / 垂足点Y | point | 圆心垂直于测量直线的交点 |
| 角度 | float | 最小外接矩形的较长边基于水平线旋转的角度；顺正逆负 |
| 距离 | float | 圆心垂直于测量直线的距离 |
| 卡尺检测区1/2 | box | 中心点X/Y、宽度、高度、角度 |

**参数**：

| 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 坐标系选择 | 图像坐标系 / 特定坐标系 | — | 特定坐标系时结合标定矩阵输出物理距离 |
| 输出角度范围 | -90°~90° / -180°~180° | — | 角度=垂点到圆心向量与 x 轴正半轴夹角；向量指向 y 正为正值、y 负为负值 |
| 选择类型 | 直线1 / 圆2 | — | 不同类型需配不同参数 |
| 边缘类型 | 最强 / 第一条 / 最后一条 / 接近中线 | — | 最强=梯度最大；第一条/最后一条=满足条件的第一/最后一条；**接近中线仅选择类型=直线1 可选** |
| 边缘极性 | 从黑到白 / 从白到黑 / 任意极性 | — | 黑→白=低灰度到高灰度边缘 |
| 边缘阈值 | 0~255 | — | 梯度阈值；越大抗噪越强、边缘越少，甚至可能筛除目标边缘 |
| 滤波尺寸 | 最小值 1 | 1 | 越小边缘越清晰过渡带小；过大且边缘间距小于该值时影响精度甚至丢失边缘 |
| 剔除点数 | int | — | 误差过大被排除不参与拟合的最小点数量（离群点越多应设越大） |
| 初定位 | 关 / 开 | 关 | **仅选择类型=圆2 可设**；含下采样系数（上限 **8**）、定位敏感度（不宜过大） |
| 剔除距离 | px | — | 离群点到直线的最大像素距离，越小排除越多 |
| 初始拟合 | 全局 / 局部 | — | 全局用查找得到的全局特征点拟合 |
| 拟合方式 | 最小二乘 / huber / tukey | — | 离群点增多/距离增大时逐次升级使用 |

**使用步骤**：1) 添加圆查找、直线查找为前序，定位圆与直线；2) 线圆测量"来源选择=订阅"，分别按线/按点/按坐标订阅直线、按圆/按参数订阅圆；3) 配坐标系选择（要物理距离选特定坐标系并选标定矩阵）；4) 设边缘阈值/滤波尺寸/拟合方式；5) 运行查看"距离""垂足点"。

**注意事项**：角度正负取决于垂点到圆心向量方向（指向 y 正=正，y 负=负）。

### 圆圆测量

**功能**：测量两圆圆心连线长度（两圆距离）。多用于工件两孔间距的合格性判断。与圆查找配合。

**输入**：输入源（图像）；来源选择（订阅 / 绘制）；圆输入（按圆 / 按参数，直接订阅 **2 个圆**）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 测量圆环1/2 | annull | 圆1/2圆心X、圆心Y、内径（默认0）、半径、起始角度（默认0度）、角度范围（默认360度） |
| 交点1 / 交点2 X、Y | point | 两测量圆交点 |
| 角度 | float | 最小外接矩形的较长边基于水平线旋转的角度；顺正逆负 |
| 距离 | float | 测量圆的圆心垂直于测量直线的距离 |
| 位置关系 | string | Inside=内含，Inscribe=内切，Intersect=相交，Circumscribe=外切，Outside=外离 |
| 卡尺检测区1/2 | box | 中心点X/Y、宽度、高度、角度 |

**参数**：与线圆测量基本一致（坐标系选择、输出角度范围 -90°~90°/-180°~180°、边缘类型[最强/第一条/最后一条]、边缘极性、边缘阈值、滤波尺寸[最小1]、剔除点数、初定位[下采样系数上限8、定位敏感度]、剔除距离、初始拟合[全局/局部]、拟合方式[最小二乘/huber/tukey]）。**差异**：无"选择类型"，改为**选择圆**（圆1 / 圆2）；边缘类型无"接近中线"；圆查找时前序若为位置修正，建议**关闭初定位**。第一条=与圆心距离最小、最后一条=与圆心距离最大。

**使用步骤**：同线圆测量，订阅两个圆即可。

**注意事项**：角度=两圆心连线与水平线夹角，**默认取输入圆2上左侧的角**；连线在水平线下方为负、上方为正。

### 点圆测量

**功能**：测量"点到圆心连线长度"实现点到圆距离；中心距离 + 圆上的最近/最远距离。用于齿轮齿到轮芯圆、柱状钢材内外径等。与圆查找、顶点检测、匹配等配合。

**输入**：输入源（图像）；**点输入**（按点 / 按坐标）；**圆输入**（按圆 / 按参数）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 测量点X / 测量点Y | point | 输入点坐标 |
| 测量圆环 | annull | 圆心点X/Y、圆内径（默认0）、圆半径、圆起始角度（默认0度）、圆角度范围（默认360度） |
| 角度 | float | 最小外接矩形的较长边基于水平线旋转的角度；顺正逆负 |
| 中心距离 | float | 测量点到测量圆圆心的距离 |
| 最近距离 | float | 测量点到测量圆上最近的距离 |
| 最远距离 | float | 测量点到测量圆上最远的距离 |

**参数**：坐标系选择（图像 / 特定）；输出角度范围（-90°~90° / -180°~180°）（角度=点与圆心连线与水平线夹角，连线在水平线下方为负、上方为正）。（**原文未给出点圆测量的细分边缘/拟合参数表**。）

**使用步骤**：1) 前序定位圆与点；2) 分别订阅圆和点；3) 选坐标系（特定坐标系得物理距离）；4) 读中心距离/最近/最远距离。

### 点线测量

**功能**：过"被查找点"向"被测量直线"作垂线，得点到线距离。用于角点到单边、孔点到某边距离。与直线查找、顶点检测、匹配、边缘交点等配合。

**输入**：输入源（图像）；**点输入**（按点 / 按坐标）；**线输入**（按线 / 按点 / 按坐标）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 测量点X / 测量点Y | point | 输入点坐标 |
| 测量直线起点X/Y、终点X/Y | float | 输入直线起点、终点坐标 |
| 测量直线角度 | float | 相对水平线旋转角；顺正逆负 |
| 垂足点X / 垂足点Y | point | 测量圆圆心点垂直于测量直线的交点 |
| 垂线角度 | float | 输入测量点垂直于输入测量直线的角 |
| 垂直距离 | float | 输入测量点到垂足点的距离 |
| 最近距离 / 最远距离 | float | 输入测量点到输入测量圆上最近/最远的距离 |

**参数**：坐标系选择（图像 / 特定）；输出角度范围（-90°~90° / -180°~180°）（角度=点与垂足连线与水平线夹角，连线在水平线下方为负、上方为正）。（**原文未给出点线测量的细分边缘/拟合参数表**。）

**使用步骤**：1) 前序定位点、线；2) 分别订阅；3) 选坐标系；4) 读垂直距离。

### 线线测量

**功能**：对两条线各自边缘点向对面线作垂线求均值，得线线平均距离、交点、夹角。用于两边间距/夹角合格性。与直线查找、直线查找组合、多直线查找配合。

**输入**：输入源（图像）；来源选择（订阅 / 绘制）；线输入（按线 / 按点 / 按坐标，**直接订阅 2 条线**）；绘制时可分别使用**直线卡尺1/直线卡尺2**，并可选是否开启位置修正。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 测量直线1/2起点X/Y、终点X/Y | float | 用于查找中线的输入直线起点、终点 |
| 测量直线1/2角度 | float | 相对水平轴的旋转角；顺正逆负 |
| 交点X / 交点Y | point | 两测量直线的交点 |
| 夹角 | float | 直线1与直线2相交的**锐角**大小 |
| 绝对距离 | float | 两条直线的起点和终点（**共 4 个点**）到对应另一线垂直距离的平均值 |
| 角度标识点1~5 | point | 点1/2=直线向量1起点/终点；点3=两直线向量交点；点4/5=直线向量2起点/终点 |
| 卡尺检测区1/2 | box | 中心点X/Y、宽度、高度、角度 |

**参数**：

| 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 坐标系选择 | 图像坐标系 / 特定坐标系 | — | 特定坐标系结合标定矩阵输出物理距离 |

## 二、标定模块 ★重点

> 标定分类下的模块用于生成两个坐标系之间的转换关系（标定文件）并应用。
>
> - N点标定：输入多个一一对应的图像像素点与运动机构物理点，建立图像坐标系和运动机构物理坐标系之间的转换关系。
> - 平移旋转标定：基于 N点标定实现"小视野+大角度"类型的旋转标定，自动计算手性一致性和旋转一致性。（图像坐标系均为左手系；若机构为左手系手性一致性为 1，右手系为 -1。）
> - 旋转标定：平移旋转标定模块中旋转部分的标定。
> - N图像标定：使用海康自研标定板建立图像系和机构物理系转换关系。
> - 标定板标定：使用标定板建立图像系和物理系转换关系。
> - 相机映射：通过前序模块输出的点集建立两个图像坐标系之间的转换关系。
> - 映射标定：通过海康自研标定板建立两个图像坐标系之间的转换关系。
> - 畸变标定：对带畸变的标定板图像生成畸变校正文件，供畸变校正模块校正。
> - 坐标系：在图像坐标系中自定义创建一个坐标系，并通过坐标矩阵建立图像系与自定义系之间的关系。
> - 标定加载：加载部分模块生成的标定文件并输出相关信息。

### 2.1 标定基本概念

- **目的**：生成两个坐标系之间的转换关系（标定文件），用于像素↔物理换算、上下相机对位、旋转中心求解。
- **平移转换公式**：`Pw=HPI`（PI 像素坐标，Pw 物理坐标，H 转换关系）；反向 `PI=H⁻¹Pw`。实际标定一般会有一个**基准量**，物理坐标与像素坐标均减去该基准量，故 H 与 H⁻¹ 代表的是**像素坐标变化量与世界坐标变化量**之间的转换关系。
- **旋转**：需使用 N点标定进行旋转标定，确定旋转轴中心位置并计算旋转变换关系，旋转前后公式（原文为图示，文字缺失），其中 ΔPw 表示旋转前后的变化量、T 是旋转前点的位置、R 是旋转的变换矩阵；T 的公式（原文为图示，文字缺失），Protw 为旋转中心。
- **像素精度 / 单像素精度**：float，代表**单个像素对应物理坐标系下的尺寸**。
- **尺度**：float，代表世界坐标系中单位长度对应图像坐标系中的**像素数**。
- **x偏移 / y偏移**：float，图像坐标系原点到机构物理坐标系原点的偏移值 X/Y，**单位为像素**。
- **旋转**：float，机构物理坐标系相对于图像坐标系的旋转角度，**单位为弧度**。θ 为正时机构物理系 X 轴沿**逆时针**旋转 θ 后其 X 轴与图像系 X 轴方向一致；θ 为负时沿逆时针旋转 -θ。
- **斜切**：float，世界坐标系的 Y 轴旋转角度与 X 轴旋转角度之差（弧度）。
- **宽高比**：float，世界坐标系的 Y 轴缩放量与 X 轴缩放量的比例。
- **角度旋转一致性**：int，机构物理坐标系角度的变化与像素坐标系角度的变化一致（角度同增或同减）。
- **坐标系左右手一致性**：int，1=机构物理坐标系和像素坐标系手性一致，-1=不一致（像素坐标系手性为左手系）。
- **标定误差**：float，标定测量值与真实值间的差异；**相机标定允许误差范围在 0.1~0.5 之间**。
- **标定板类型**：棋盘格标定板、圆标定板、海康I型标定板、海康II型标定板、海康扩展I型标定板、海康扩展II型标定板。海康板原理：在棋盘格基础上，部分棋盘格用带位置信息的**码**替代；**I型 1 个码占据 4 个棋盘格位置**，**II型码均放置在标定板的白格中**。海康**常规板行/列数最大 255**，**扩展板行/列数最大 1000**，其余无差别。海康板可用 VM 自带**标定板生成工具**生成（生成可编辑文件后需按实际光源填充标定板颜色）。
- **图像坐标系**（四种板通用）：图像左上角为原点，水平向右为 X 轴，垂直向下为 Y 轴。
- **物理坐标系差异**：棋盘格/圆板→以**左上角第一个角点**为原点、坐标轴与棋盘格边平行（**提取到的角点列数大于行数时坐标系位置和方向会变化，特征点数量较多的方向为 X 轴**）；海康板→码记录角点物理坐标与方向信息，无论板如何放置都有**相同的默认物理坐标系**。
- **标定板选型**：仅用一个相机→推荐棋盘格/圆标定板（无需关注物理系原点）；多相机需转换到同一物理坐标系→推荐海康标定板（每相机视野不同，拍摄棋盘格区域不同）。使用海康板需保证码足够大且清晰（**推荐码占据 100 个像素左右**），否则可能标定失败。
- **自由度**（多数标定模块通用，详见速览第 5 条）。
- **标定类模块共有参数**：标定文件路径、更新文件、生成标定文件。

### 2.2 N点标定

**功能**：计算相机的图像坐标系和运动机构的物理坐标系之间的转换关系。输入多个一一对应的图像像素点与运动机构物理点，得出标定文件。广泛用于视觉引导机构抓取、纠偏、对位。

> **说明**：需确保 **N≥4**。较常见的是 **9 点标定**与 **12 点标定**。机构共轴运动→9 次平移（9 点）；机构不共轴→9 次平移后还需 3 次旋转（12 点）。

**输入**：

| 旋转次数 | int | 旋转轴与图像中心不共轴时设置，**一般设置为 3，且旋转在第 5 个点进行** |
| 点编辑 | 自定义 / 导入(txt) / 导出 / 清空标定点 | 手动输入时通过"编辑标定点"页签自定义或导入 |

| 标定图像点（图像坐标X/Y） | point | 标定时特征点像素坐标 X/Y |
| 标定物理点（转换坐标X/Y） | point | 标定时机构物理坐标 X/Y |

### 2.3 N图像标定

### 2.4 标定板标定

### 2.5 相机映射 / 映射标定

#### 相机映射

**功能**：通过输入一系列一一对应的点，计算两个图像坐标系的**仿射变换矩阵**（标定文件）。用于多相机定位引导类场景。模块原理与映射标定相同。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 输入方式 | 按点 / 按坐标 | 按点=订阅数据为点坐标；按坐标=订阅数据为点 X 和点 Y 组成坐标 |
| 示教点\*-运行点\* | 点映射 | **至少需设置两组映射关系**，可通过"+"增加映射关系 |
| 标定文件路径 / 更新文件 / 生成标定文件 | — | 标定类模块共有参数 |

> **说明**：设置映射时，需确保每组参数**左侧订阅的点属于同一个图像坐标系**，右侧订阅的点也遵循该原则；但**左右两侧的点应属于不同的图像坐标系**。

| 旋转 | float | 机构物理系相对图像系的旋转角（弧度） |
| 尺度 | float | 世界坐标系中单位长度对应图像坐标系中的像素数 |
| 斜切 | float | 世界坐标系 Y 轴旋转角与 X 轴旋转角之差（弧度） |
| 宽高比 | float | 世界坐标系 Y 轴缩放量与 X 轴缩放量的比例 |

**使用步骤**：配合特征提取类模块使用（如边缘交点模块，上相机的边缘交点1/2/3/4 分别与下相机的边缘交点5/6/7/8 映射），本模块订阅前序两个图像坐标系下一一对应的点计算仿射变换矩阵。

#### 映射标定

**功能**：作用与用途同相机映射。不同之处在于获取点集的方式：相机映射订阅前序特征提取类模块输出的点集，**映射标定通过海康自研标定板的图像或对应的文件**。

**原理**：坐标系 I1、I2 不是同一坐标系（假设为图像坐标系），坐标系 W 是物理坐标系，可分别计算出从 I 坐标系映射到 W 坐标系的关系 H1、H2（原文为图示，文字缺失）；由于两物理坐标相同，对 I2 中每一点先映射到 W 再映射到 I1，即可实现从 I2 到 I1 的映射，公式为 H1⁻¹H2（原文为图示，文字缺失）。**映射标定最终需计算映射矩阵 H1⁻¹H2**。

**输入**：需前序有 **2 个图像源模块**，分别获取两个相机采集的海康自研标定板图像。

| 输入方式 | 子项 | 说明 |
| --- | --- | --- |

| 图像输入 | 物理点输入 | 按点 / 按坐标 |
| 图像输入 | 物理点 / 物理坐标X/Y / 物理角度 | 机构坐标点的位置及角度，每个图像点对应一个机构物理点 |
| 图像输入 | 示教 | 外部输入字符（如 TRIGGER STRING）、外部触发字符（一致则为示教信号） |
| 文件输入 | 标定文件1/2 | 选择海康自研标定板图像对应的标定文件 |
| 文件输入 | 刷新信号 | 0/空值=仅第一次运行加载，后续不更新；非 0 非空=每次运行重新加载 |
| 共有 | 标定文件路径 / 更新文件 / 生成标定文件 | 标定类共有参数 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |

### 2.6 畸变标定

**功能**：对带畸变的标定板图像进行标定，生成畸变校正文件，供畸变校正模块校正。畸变主要来源为相机成像时的**径向和透视畸变**。

> **说明**：实际使用时，通过该模块生成校正文件后，**还需使用畸变校正模块对图像进行校正**，方可降低畸变所引入的偏差。

**畸变类型（原文为图示）**：

| 畸变类型 | 说明 |
| --- | --- |
| 径向畸变 | 以畸变中心（一般为图像中心）为中心点沿径向方向产生的畸变；离中心点距离越远畸变越大。校正目标=使校正后图像中原本扭曲的直线恢复笔直 |
| 透视畸变 | 即近大远小；被测物与相机之间存在倾斜导致图像边缘夹角与实际相比变化；典型现象为棋盘格格子宽度近大远小。校正后格子大小完全相同，所有格子宽度以**设置的校正点附近格子宽度为基准长度**校正；校正目标=使校正后被测物夹角与实际保持一致 |
| 径向透视畸变 | 既存在径向畸变，又存在透视畸变；会同时得出径向校正系数与透视校正系数 |

**输入**：输入源（前序图像源输出的带畸变的标定板图像）；形状（全屏 / 矩形 ROI）。标定板可以是棋盘格标定板、圆型标定板或海康自研标定板（**海康板作为普通棋盘格使用时无需译码**，查找棋盘格角点即可）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 标定误差 | float | 标定测量值与真实值的差异；相机标定允许误差范围 **0.1~0.5** |
| 标定点数 | int | 所提取标定板上的特征点数量 |
| 标定点（标定点X/Y） | point | 标定板角点像素坐标 |
| 标定点状态 | float 数组 | 由"评估误差阈值"与"标定点评估误差"大小决定：误差>阈值取 **0**（红），≤阈值取 **1**（绿） |
| 评估误差 | float | 总体评估误差；需提前开启矫正评估功能 |
| 标定点评估误差 | float | 标定点的评估误差；需提前开启矫正评估功能 |
| 检测区域 | box | 中心点X/Y、宽度、高度、角度 |
| 矫正后的图像 | image | 矫正后的图像数据、宽度、高度、像素格式；需开启矫正评估后输出 |

**参数**：

| 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 校正点输入 | 按点 / 按坐标 | — | — |
| 校正中心X/Y（校正中心点） | px | — | 设置畸变校正的中心点；**畸变类型含径向时需设到图像中心，此时校正效果最好** |
| 畸变类型 | 透视畸变 / 径向畸变 / 径向透视畸变 | — | 按实际情况选择 |
| 矫正评估使能 | 关 / 开 | — | 开启后模块会矫正标定图像并额外输出一张矫正后的图像 |
| 矫正后标定点 | 关 / 开 | — | 需查看矫正后图像每个标定点的位置和误差系数时开启 |
| 评估误差阈值 | float | — | 每个标定点对应一个评估误差，超过该值显示红色，不超过显示绿色（可通过"评估误差字号"设置图上显示字号） |
| 标定板类型 | 棋盘格 / 圆 / 海康I型 / 海康II型 / 海康扩展I型 / 海康扩展II型 | — | 按实际情况选择 |
| 自由度 | 透视 / 仿射 / 相似性 | 默认 | 见 §2.1 |
| 中值滤波状态 | 执行滤波 / 无滤波 | 默认 | 提取角点前是否执行中值滤波 |
| 权重函数 | 最小二乘 / Huber / Tukey | 默认 | 选 Huber/Tukey 需设权重系数 |
| 权重系数 | 削波因子 | 默认 | 推荐默认值 |

**使用步骤**：1) 图像源拍带畸变标定板（**建议占满视野**，此时标定效果最好）；2) 设畸变类型、校正中心点；3) 设标定板类型、中值滤波；4) 开矫正评估使能查误差；5) 生成标定文件→接畸变校正模块。

**调试建议**：畸变类型含径向畸变→校正中心点设到图像中心；含透视畸变→若提取到的特征点**行数大于列数会对图像进行旋转**，若不希望旋转，拍摄前保证特征点行数小于列数。

### 2.7 平移旋转标定 / 旋转标定

#### 平移旋转标定

### 2.8 坐标系 / 标定加载

#### 坐标系

**功能**：在图像坐标系中自定义创建一个坐标系，并通过坐标矩阵建立图像坐标系和自定义坐标系之间的关系（例：点 P 在图像系 XY 下坐标为 (x,y)，可得到在自定义系 X'Y' 下的坐标 (m,n)）。

| 坐标系矩阵 | float | 相对于图像坐标系的坐标系矩阵 |

| **坐标系** | 图像内自定义坐标系 | — | 绘制 或 订阅标定矩阵 | 坐标系矩阵 | 自由度固定为平移/旋转/缩放 |
| **标定加载** | 加载/排查标定文件、输出矩阵给运算 | 已有 xml（**仅 N点/N图像/映射标定**生成） | 标定文件路径（xml） | 标定矩阵、旋转中心、误差、像素精度 | 不重新标定，仅读取 |

## 三、运算模块 ★重点（定位引导项目核心）

### 单点对位

**功能**：根据输入的目标点坐标和角度、以及对象点的坐标和角度，计算由对象点对位至目标点所需的偏移量（X/Y 方向位移 + 角度）。

**输入**：输入方式（按点 / 按坐标）；**示教点0-运行点0**（点 / 点X/Y / 角度），可自定义或订阅前序模块数据（一般订阅）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| x偏移 | float | 示教点到运行点 X 方向的位置移动量 |
| y偏移 | float | 示教点到运行点 Y 方向的位置移动量 |
| theta偏移 | float | 示教点到运行点的角度偏移量，**顺时针为正** |

**前提约束**：输入的为**目标点和对象点的物理坐标**，**需配合标定转换模块使用**；模块中的**示教点即目标点，运行点即对象点**。Δθ 公式中的角度会被**归一化至 -π~π 范围内**。

**原理**：每个物理坐标点由 x、y、θ 组成。设 P1(x1,y1,θ1) 为示教点、P2(x2,y2,θ2) 为运行点，将 P2 对位至 P1 需先旋转 Δθ，再按 (Δx, Δy) 平移。

**使用步骤**：1) 图像源获取图像；2) 定位类模块获取图像系特征点及角度；3) 标定转换将图像坐标点转为物理坐标点；4) 单点对位在物理坐标系中计算运行点到示教点的偏移量。

### 单点抓取

**功能**：单相机拍物料的**抓取**场景使用，得到基准位移动到运行位的**相对偏移量和绝对抓取坐标**。需与平移旋转标定模块配合（相机与机构通过标定得到标定矩阵 M）。

**原理**：
- 末端夹具与旋转轴**共轴**时无需考虑角度偏移：将机构在示教拍照位 P1 拍摄的特征点像素坐标定义为 p1，机构移动至示教物理位 P2 使夹具对准特征点中心；生产时机构运动至示教拍照位 P1 拍摄的特征点像素坐标为 p2。先将 p1、p2 从图像系转换到机构物理系，再算差值（相对偏移量）；**相对偏移量与示教物理位之和即绝对抓取坐标**。
- 末端夹具与旋转轴**不共轴**时，目标物料发生角度偏移、机构同步旋转会导致夹具 X/Y 坐标偏移；为补偿需引入示教拍照位和示教物理位，计算不共轴长度与旋转偏差。**标定类型选平移旋转标定时，示教拍照位必须填写**，模块输出的偏差包含平移偏差和不共轴旋转产生的偏差（使用到的旋转计算公式原文为图示，文字缺失）。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 标定类型 | 平移标定 / 平移旋转标定 | 按实际需求选择 |
| 输入方式 | 按点 / 按坐标 | — |
| 像素点 | 点（或坐标X/Y）+ 角度 | 设置图像的基准点和运行点；完成订阅后点"执行"再点"创建基准"，提示"基准点创建成功"即完成；后续订阅的像素点均为图像运行点 |
| 示教物理点 | 点（或坐标X/Y）+ 角度 | 物料在基准位置时机构抓取物料的绝对物理坐标及角度 |
| 示教拍照物理点 | 点（或坐标X/Y）+ 角度 | 物料在基准位置时机构携带相机拍照的绝对物理坐标及角度，**一般为第 5 个点拍照位的物理坐标**；生产时若相机相对标定时角度有变化，还需**开启旋转拍照使能并设置旋转相对角度**；**标定类型=平移旋转标定时必须设置**，否则可不设 |
| 标定文件 | 加载方式（标定矩阵 / 加载标定文件）+ 刷新信号 | 加载标定文件可点图标选择；刷新信号 0/空值=仅第一次运行加载，非 0 非空=每次重新加载 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 基准点（基准点X/Y）/ 基准点R | point / float | 图像提取到的特征点坐标与角度 |
| 相对坐标X / Y / R | float | 机械臂抓取物料相对基准位置变化的偏移量与角度偏移量 |
| 绝对坐标X / Y / R | float | 机构抓取的绝对物理位置与角度 |

**使用步骤**：1) 前序图像源→定位类模块获取图像特征点；2) 像素点订阅后点"执行"→"创建基准"；3) 设示教物理点、示教拍照物理点（按需）；4) 加载标定文件；5) 读绝对抓取坐标引导机构。

### 单点映射对位

**功能**：主要用于**上相机拍目标、下相机拍对象**的对位贴合场景。通过下相机拍物料、上相机拍料盘，根据对象点与目标点的位置和角度，计算对象点对位贴合到目标点需要的移动量（位置移动量 + 角度移动量）。需与**平移旋转标定模块和映射标定模块**配合。

**原理**：静止下相机和运动机构通过标定得到下相机图像坐标系和机构物理坐标系的转换关系（标定矩阵 M）；上下两相机通过映射标定得到两个图像坐标系之间的转换关系。运动机构携带基准物料到静止下相机的示教物理点 P1，下相机拍摄特征点像素坐标 p1 和对位直线角度；上相机回到拍照位 P2 拍摄需要贴合的对象，提取对象点及对位直线的起点和终点。将上相机对象点及直线起点、终点通过映射标定文件映射到下相机的图像坐标系内，再通过下相机和机构的平移旋转标定矩阵转换到机构坐标系下，从而计算出对位偏差。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 输入方式 | 按点 / 按坐标 | — |
| 对象像素点 | 点（或坐标X/Y）+ 角度 | 对象位（一般指**下相机拍照位**）的图像像素点及角度 |
| 目标像素点 | 点（或坐标X/Y） | 目标位（一般指**上相机拍照位**）的图像像素点 |
| 目标像素直线起点 / 终点 | 点（或坐标X/Y） | 目标位对位直线的起点/终点；用于映射到下相机坐标系确保角度统一 |
| 示教物理点 | 点（或坐标X/Y）+ 角度 | 做上下相机映射标定时机构抓取标定板的绝对物理坐标 |
| 标定文件 | 加载方式（N点标定矩阵 / 映射标定矩阵 或 N点标定文件 / 映射标定文件）+ 刷新信号 | 刷新信号 0/空值=首次加载；非 0 非空=每次重载 |

**输出**：耗时、模块状态（通用）；相对坐标X / Y / R；绝对坐标X / Y / R（含义同单点抓取）。

**前提约束**：需**同时持有 N点（平移旋转）标定矩阵 与 映射标定矩阵**（下相机机构物理系 + 上/下相机图像系映射）。

### 单点纠偏

**功能**：适用于单相机拍物料的**纠偏**场景。相机拍物料，根据运行点位置和角度、基准点位置和角度，计算运行点移动回基准点需要的移动量。需与平移旋转标定模块配合。

**原理**：机构携带基准物料到示教物理点 P1，静止相机拍摄特征点像素坐标 p1 创建基准。生产时机构携带需纠偏的物料运动到示教拍照位 P1，相机拍摄的特征点像素坐标为 p2；将 p1、p2 从图像系转换到机构物理系，再根据修正角度后的物理坐标计算差值（相对偏移量）；**相对偏移量与示教物理位之和即绝对纠偏坐标**。

**输入**：**与单点抓取模块的参数（除示教拍照物理点相关参数）基本一致**。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 基准点（基准点X/Y）/ 基准点R | point / float | 图像提取到的特征点坐标与角度 |
| 相对坐标X / Y / R | float | 相对基准位置变化的偏移量与角度偏移量 |
| 绝对坐标X / Y / R | float | 机构抓取的绝对物理位置与角度 |

**使用步骤**：同单点抓取，省去示教拍照物理点；基准=示教物理点 P1 创建，生产时拍 p2 算偏移。

**单点对位 vs 单点抓取 vs 单点纠偏（小结）**：

| 模块 | 场景 | 输入 | 关键输出 | 特殊要求 |
| --- | --- | --- | --- | --- |
| 单点对位 | 对象点对位到目标点 | 目标点+对象点的**物理坐标** | x/y/theta 偏移 | **需先标定转换**；Δθ 归一化 -π~π；无绝对抓取概念 |
| 单点抓取 | 单相机抓料 | 像素点+示教物理点(+示教拍照物理点)+标定文件 | 相对偏移 + 绝对抓取坐标(X/Y/R) | 不共轴时标定类型选平移旋转标定且**必须填示教拍照物理点** |
| 单点纠偏 | 单相机纠偏 | 像素点+示教物理点+标定文件 | 相对偏移 + 绝对纠偏坐标(X/Y/R) | 参数同抓取但**无示教拍照物理点** |

### 标定转换

**功能**：将同一组坐标系下的特征点信息通过加载标定文件转换为另一组坐标系下的特征点，常用于图像坐标系的像素点和物理坐标系的物理点之间转换。

**原理**：`Pw=HPI`（PI 图像坐标、Pw 物理坐标、H 转换关系），反向 `PI=H⁻¹Pw`。输出参数中的**单像素精度即 H 中的尺度**，**平移X/Y、旋转、尺度、斜切、宽高比即 H⁻¹ 中的参数分量**。

**输入**：图像输入（输入源）；坐标点输入（输入方式[按点/按坐标]、坐标点 / 坐标X/Y、角度、**坐标类型**[图像坐标 / 物理坐标]）；标定文件（与单点抓取模块对应参数基本一致）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 输出点（转换坐标X/Y） | point | 输入坐标经标定转换/逆转换后的点 |
| 转换角度 | float | 输入角度经标定转换/逆转换后的角度 |
| 单像素精度 | float | H 中的尺度；单个像素对应物理坐标系下的尺寸 |
| 平移X / 平移Y | float | H⁻¹ 分量；世界坐标系原点映射到图像坐标系的坐标 X/Y |
| 旋转 | float | H⁻¹ 分量；机构物理系相对图像系的旋转角（弧度） |
| 尺度 | float | H⁻¹ 分量；世界坐标系中单位长度对应图像系中的像素数 |
| 斜切 | float | H⁻¹ 分量；世界坐标系 Y 轴旋转角与 X 轴旋转角之差（弧度） |
| 宽高比 | float | H⁻¹ 分量；世界坐标系 Y 轴缩放量与 X 轴缩放量的比例 |

**前提约束**：**坐标类型须明确输入点是图像坐标还是物理坐标**（决定做正转换还是逆转换）。

**使用步骤**：1) 图像源获取图像；2) 定位类模块获取图像特征点；3) 标定转换根据输入的图像特征点和标定文件获得转换后的物理坐标点。

### 点集对位

**功能**：与单点对位功能相似（均得到对象点到目标点的偏移量），差别在于单点对位通过**一对点**的坐标和角度得到，本模块通过**多个点坐标形成的点集**得到。原理与单点对位大同小异。

**输入**：输入方式（按点 / 按坐标）；**示教点-运行点**——设置多个运行点对位至示教点的点坐标（点 / 点X/Y），可自定义或订阅；点击"+"可继续添加，**至少 2 个以上，最多不超过 8 个**。

**输出**：耗时、模块状态（通用）；x偏移、y偏移、theta偏移（示教点到运行点的角度偏移量，**顺时针为正**）。

**前提约束**：**必须配合图像源模块、定位类模块和标定转换模块使用**（定位类获取图像系多组特征点，标定转换转为物理坐标点）。

### 旋转计算

**功能**：将点或线绕旋转中心点按照旋转角度旋转，计算得到旋转之后该点或线的相关信息。

**原理**：`Out X/Y = 旋转(中心X0/Y0, θ)·In X/Y`（Out 为输出点、In 为输入点、X0/Y0 为旋转中心、θ 为**图像坐标系下**旋转角度，**顺时针为正、逆时针为负**）。

**输入**：图像输入（输入源）；**输入类型**（按点 / 按线）——点输入时设置旋转的点、线输入时设置旋转的线；旋转中心坐标；旋转角度（正=顺时针，负=逆时针）。

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 输出点（输出点X / 输出点Y） | point | 输入点旋转后得到的点（**采用左手图像坐标系**） |
| 输出线（线起点X/Y、线终点X/Y） | line | 输入的线旋转后得到的起点、终点 |

**使用步骤**：图像源获取图像；定位类模块获取图像系特征点或直线；旋转计算将角平分线绕其交点旋转指定角度得到旋转后的直线。

### 线对位

**功能**：原理和功能与点集对位类似，差别仅在于点集对位针对的是**点**，本模块针对的是**线**。

**输入**：基本参数与点集对位大同小异（参见点集对位）。**运行参数**：**对位形状**（开 / 闭）——选"闭"时特征线**必须形成闭合形状**方能检测（例：存在 4 条特征线，必须按顺序形成一个封闭矩形才能检测）；选"开"时特征线**无需形成闭合形状**也能检测。

**输出**：耗时、模块状态（通用）；x偏移、y偏移、theta偏移（**顺时针为正**）。

**前提约束**：**必须配合图像源模块、直线查找模块和标定转换模块使用**（直线查找获取图像系多组特征线；标定转换把直线起点与终点坐标都转换为物理坐标；几何创建模块把物理坐标起点、终点连线构成示教线和运行线）。

### 单位转换

**功能**：将图像中的间距、宽度等距离，通过标定文件由像素距离转换为物理坐标系下的物理距离。

> **说明**：该模块**仅为近似运算，存在一定误差**。若需精确数值，推荐通过对特征点使用标定转换模块转换后，再通过点点测量模块计算得到。

**输入**：图像输入（输入源）；单位转换（**像素间距**：订阅前序模块输出的距离）；标定文件（**加载标定文件**[支持 **iwcal、txt、xml**]、**刷新信号**[必填，默认 **0**]、**像素当量修正**[必填，默认 **1**]）。

**参数规则**：
- 刷新信号=0 或空值：仅第一次运行加载标定文件，后续不更新，且**像素当量修正参数设置不生效**。
- 刷新信号=非 0 非空：每次运行重新加载标定文件，且**像素当量修正参数设置生效**。

**输出**：耗时、模块状态（通用）；单像素精度、转换结果、像素距离、平移X/Y、旋转、尺度、斜切、宽高比。

**公式**：**输出的物理距离 = 像素间距 × 单像素精度 × 像素当量修正**。

**使用步骤**：1) 图像源获取图像；2) 定位类模块获取图像系特征点之间的距离；3) 单位转换将订阅的像素距离转换为物理距离（示例中其结果与点点测量模块得到的距离结果一致）。

### 变量计算

**功能**：通过设计表达式，完成变量之间的算术或逻辑运算。变量可以是自定义参数，也可以从前序模块订阅输出的模块结果。本质是一个"计算器"，在计算器基础上还可订阅前序模块输出（解析时先把订阅字符串替换成具体数字再计算）。例：`1+<1 圆查找1.圆心X>[0]+<1 圆查找1.圆心Y>[0]*3`，其中 `<1 圆查找1.圆心X>[0]` 就是一个订阅数据。

**输入 / 参数**：点击"+"添加变量的计算表达式（默认已添加 1 个，支持添加多个）；通过"重置"按钮将所有变量重置为初始值。每个表达式由以下参数组成：

**表达式窗口**：窗口上方为公式显示和编辑区域（右侧可订阅前序模块）；中间区域标记公式需使用的常数、运算符号和函数；初始值和初始化与基本参数窗口为同一参数；"校验公式"可校验设置的公式是否合理。

| round(x) | 将 x 的小数位四舍五入后返回整数 | trunc(x) | 将 x 的小数位取 0 后返回整数 |
| ceil(x) | 返回大于等于 x 的最小整数值 | floor(x) | 返回小于等于 x 的最大整数 |
| log(x) | 返回指定数字的自然对数（底为 e） | exp(x) | 返回 e 的 x 次幂 |

### 坐标转换

**功能**：将图像上某个点的坐标通过计算转换为其他坐标点信息。一般配合**划片拆分模块**使用，将划片中的某点坐标转到原图中（即划片前的图像），可获取各个划片区域点在原图中的坐标信息。

**原理**：通过获取到的划片区域在原图中的**划片中心点坐标、宽、高**，计算出划片区域**左上角**在原图中的坐标 P，再将需要转换点的坐标加上坐标 P，即得到转换点在原图中的坐标信息。

**输入 / 参数**：

| 分类 | 参数项 | 取值范围 / 选项 | 说明 |
| --- | --- | --- | --- |
| 划片信息 | 坐标转换使能 | 开 / 关 | **默认开启**；若关闭，则输入点和输出点的数据完全一致 |
| 划片信息 | 输入方式 | 按点 / 按坐标 | 设置划片中心点的输入方式 |
| 划片信息 | 划片中心点 / 划片中心点X/Y | 订阅 | 一般从前序划片拆分模块订阅 |
| 划片信息 | 划片宽 / 划片高 | 订阅 | 一般从前序划片拆分模块订阅划片区域的宽/高 |
| 输入点 | 输入方式 | 按点 / 按坐标 | — |
| 输入点 | 点 / 点X/Y | 自定义 / 订阅 | 输入点坐标的信息来源 |

**输出**：耗时、模块状态（通用）；输出点（输出点X / 输出点Y）——输入点旋转后得到的点（**采用左手图像坐标系**）。

**前提约束**：**必须配合图像源模块、划片拆分模块、拷贝填充模块、定位类模块使用**（示例：图像源获取图像，划片拆分拆为 2×2 四个区域，拷贝填充获取第三个划分区域即原图左下角区域，边缘交点提取划片区域的边缘交点作为特征点，坐标转换根据划片信息把特征点坐标转换回原图坐标；输出点与"边缘点交点2"模块直接在原图上提取的结果相同）。

### 颜色抽取

**输出**：

### 颜色转换

**功能**：对输入的 RGB 图像中指定彩色区域的颜色信息进行测量，并将图像转换到指定颜色空间（**灰度、HSV、HSI、YUV**），输出指定颜色通道的灰度图像。用于需把彩色图像转换成其他颜色空间再计算处理的场景。前序需输入彩色图像（如图像源设为输出 RGB），后序一般为需要使用的检测模块。

**参数**：

| 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 转换类型 | RGB转灰度 / RGB转HSV / RGB转HSI / RGB转YUV | — | 不同转换类型需设置的参数不同 |
| 转换比例（选 RGB转灰度时） | 见下表（9 种） | — | 小写 r、g、b 分别代表图像中实际的 R、G、B 通道分量；自设/无约束含 R/G/B 转换比例 |
| 显示通道（选 RGB转HSV/HSI/YUV 时） | 第一通道 / 第二通道 / 第三通道 | — | 按对应通道转换 |

**转换比例选项**：

| 选项 | 公式 |
| --- | --- |
| 通用转换比例 | 0.299r + 0.587g + 0.114b |
| 平均转换比例 | (r + g + b) / 3 |
| 通道最小值 | min(r, g, b) |
| 通道最大值 | max(r, g, b) |
| 自设转换比例 | (R·r + G·g + B·b) / (R + G + B)（大写 R/G/B 为 R/G/B 转换比例） |

| G通道 | 0·r + g + 0·b，即 G 通道灰度值 |
| B通道 | 0·r + 0·g + b，即 B 通道灰度值 |
| 无约束转换比例 | R·r + G·g + B·b（大写 R/G/B 为对应转换比例） |

**输出**：耗时、模块状态（通用）；输出图像（binary：输出图像数据、宽度、高度、像素格式，**17301505=Mono8，35127316=RGB24**）。

### 颜色识别

**功能**：通过对图像样本建立颜色模型，识别并计算目标与模型的相似程度，主要用于通过颜色对目标图像分类。包含**建模**和**识别**两部分。适用于目标物体颜色变化较为明显的场景，常用在"有无检测"；对体积变化、形状变化等不适用。前序需输入彩色图像（如图像源设为输出 RGB），后序一般为逻辑模块。

**原理**：
- 建模：输入一张或多张图像，选择 ROI 作为样本，设置样本标签，建立颜色模型。
- 识别：输入待识别图像的 ROI 区域，根据模型样本与待识别区域的相似程度识别出最接近的标签类名称。

**颜色模型（建模步骤）**：
1. 在颜色模型面板点"+"进入模板配置界面创建模型：
   1. 加载图像（点图片列表处"+"添加当前图像源模块导入的图片，也可添加本地图片）；
   2. 添加标签（点标签类列表右侧"+"创建标签，可编辑标签名称）；
   3. 框选掩膜（用绘制工具对标注区域绘制掩膜 ROI）；
   4. 添加至标签（点"添加至标签"将掩膜样本加入对应标签类别，标签名称右侧同步显示样本数量；样本打标错误时可移动到正确标签列表）；
   5. 配置参数（敏感度、特征类型、亮度，见下表）；
   6. 点"保存模型"生成 **.bin** 格式模型文件，点"确定"返回颜色模型面板。
2. 颜色模型面板右上角"编辑模型"可编辑已有模型。
3. 面板中可导入/导出模型文件（**导入模型时会清空已有的颜色模型**）。

**建模参数**：

| 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 敏感度 | 高 / 中 / 低 | — | 对图像颜色变化的敏感程度；图像对颜色变化敏感程度高时建议选高敏感 |
| 特征类型 | 直方图特征 / 色谱特征 | — | 直方图特征分布更细、对图像变化更敏感；**建议选直方图特征高敏感模式**，不满足再调 |
| 亮度 | 高 / 中 / 低 | — | 反映光照对图像的影响程度；**需在光照变化下保持识别结果更稳定时可关闭亮度特征**；直方图特征可选启用/关闭，**色谱特征推荐始终启用** |

**运行参数**：

| 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| K值 | int | — | 选取前 K 个颜色样本中所占数量最多的类作为最佳识别结果，**K 值需小于所有标签类中的最小样本数** |
| KNN距离 | 欧式距离 / 曼哈顿距离 / 相交距离 / 偏移距离 | — | 欧氏=多维空间两点真实距离；曼哈顿=二维坐标中两点横纵坐标距离总和；相交=历史兼容性保留、效果不如偏移距离；**偏移距离推荐（运行效果最优）** |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 置信度 | float 数组 | 识别的置信度，数组长度等于字符个数 |
| 最佳匹配名称 | string | 识别得分最高的模型名称 |
| 最佳分数 | float | 识别得分最高的分数 |
| 类别名 | string | 创建颜色模型所需输入的标签类名称 |
| 分数 | float | 匹配到图像的得分，**1 表示与模板图像完全相同** |
| 模型H/S/I通道数据 | float | 模型通道数据（色调/饱和度/亮度） |
| 样本H/S/I通道数据 | float | 样本通道数据（色调/饱和度/亮度） |
| 检测区域 | box | 中心点X/Y、宽度、高度、角度 |
| 屏蔽区多边形 | polygo | 图像中需屏蔽的 ROI 区域（不检测）；含**多边形点数**(int)与**多边形点集**(point：多边形点X/Y) |

### 颜色分割

**功能**：通过输入彩色图像，根据指定颜色空间设置的三通道阈值将目标区域进行分割。与颜色抽取不同：**输出的是灰度图**，每个像素的灰度值标记了该像素所属的目标区域，不同目标区域用不同灰度值表示，非目标区域灰度值为 **0**。

**与颜色抽取相比增加的功能**：
- **同时抽取多个不同颜色的目标区域**：每个颜色范围可设一个类别名称，相同类别的颜色范围视为同一类别（取并集）；不同类别之间可存在交集，模块自动处理交集范围内的像素。每个像素最终仅属于一种类别，用该类别灰度值表示，不属于任何类别则灰度值为 0（模块自动为每个类别赋予灰度值，可通过"类别信息"结果查看）。图像显示区域选"输出渲染图"可以伪彩色显示，便于观察。例：设深绿、浅绿、红色三个颜色范围，深绿与浅绿类别名均为"绿色"、红色为"红色"，则输出灰度图中灰度值 **15** 区域表示绿色（深绿+浅绿），灰度值 **31** 表示红色，**0** 表示其它颜色。
- **孔洞填充与杂斑筛除**：孔洞=被目标区域（灰度值非 0）完全包围的非目标区域（灰度值为 0 的 8 连通域），面积小于设置数值的孔洞被填充、与周边目标区域合并；杂斑=同一种颜色所组成的面积较小的目标区域（灰度值非 0 的 8 连通域），面积小于设置数值的杂斑被删除、变为非目标区域或与周边其它目标区域合并。
- **色品图和明度轴、自动设定开关**：在图像上通过颜色区域选择框选颜色后，色品图和明度轴中用红点表示所框选范围内的颜色，也可手动拖动游标调整范围；打开"自动设定"时，每次框选后游标自动调整为模块推荐的颜色范围，关闭时框选后游标位置不自动调整。

**参数**：

| 分类 | 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| 分割参数 | 颜色范围列表 | **1 ~ 16** 个 | — | 单击"+"新增 |
| 分割参数 | 颜色空间 | RGB / HSV / HSI | — | RGB 通过 R/G/B 通道设阈值；HSV/HSI 通过色调、饱和度、亮度设阈值（也可用左侧示意图滑块调整） |
| 分割参数 | 颜色区域选择 | 框选 | — | 在输入图像框选指定目标区域，快速生成对应的三通道范围阈值 |
| 分割参数 | 颜色反转 | 关 / 开 | — | 启用则选择当前设置颜色范围外的颜色空间作为实际颜色范围 |
| 分割参数 | 使用独立面积参数 | 关 / 开 | — | 未开启时当前颜色范围使用运行参数中的孔洞填充面积和杂斑筛除面积；开启时可单独设置 |
| 分割参数 | 孔洞填充面积 | px² | — | 面积小于设置数值的孔洞被填充并与周边目标区域合并 |
| 分割参数 | 杂斑筛除面积 | px² | — | 面积小于设置数值的杂斑被删除 |
| 分割参数 | 类别名称 | string | — | 自定义对应颜色范围的类别名称；**多个颜色范围的类别名称相同时，模块会将颜色范围合并后作为一个类别输出** |
| 分割参数 | 自动设定 | 关 / 开 | — | 启用时色品图和明度轴的游标每次根据颜色区域选择框选的区域自动调整为算法推荐的颜色范围；未启用时框选后游标位置不自动调整 |
| 运行参数（全局） | 孔洞填充面积 / 杂斑筛除面积 | px² | — | 针对该模块的**所有**颜色范围（前面分割参数针对**选中的**颜色范围） |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时 / 模块状态 | float / int | 通用 |
| 总面积 | float | 所有 Blob 加起来的总面积 |
| 类别信息 | image | 类别名称(string，保存在模型中，导入模型时从模型文件中获取)、灰度值(int，每个类别的灰度值) |
| 输出图像 | binary | 输出图像二进制数据、宽度、高度、像素格式（**17301505=Mono8，35127316=RGB24**） |
| 输出渲染图 | image | 完成渲染后输出的图像、宽度、高度、像素格式 |
| 检测区域 | box | 中心点X/Y、宽度、高度、角度 |
| ROI圆弧 | annull | 中心点X/Y、内径、外径、起始角度、角度范围 |

**使用步骤**：1) 设 1~16 个颜色范围并设类别名称；2) 框选或滑块设定阈值；3) 设孔洞/杂斑面积；4) 接 Blob 标签分析模块（自动订阅类别名称和灰度值，计算各分割区域属性并筛选排序）。一般用于分割目标区域和非目标区域色彩区分明显的场景，或分割多个颜色差异明显的目标。

### 彩图生成

**功能**：将三张灰度图分别作为 R、G、B 通道的图像，合成一张彩色图像。一般在**相机配合三色光源**分别拍摄红光、绿光和蓝光灰度图的情况下使用（将三色光源分别采集的图像作为对应各通道的输入图像）。

> **说明**：订阅的 3 张图片应确保**只是灰度值的差异，其他需完全一致**（例如相同的被测物、完全一致的摆放位置等）。

**输入**：前序模块一般为图像源等可输出灰度图的模块；**输入颜色R / 输入颜色G / 输入颜色B**（分别选择作为图像 R、G、B 通道分量的灰度图）。后序模块一般为颜色处理等相关模块。

**参数**：

| 参数名 | 取值范围 / 选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 输出图像格式 | RGB P3 / RGB C3 | — | 设置输出图像的格式 |

**输出**：耗时、模块状态（通用）；输出图像（binary：输出图像二进制数据、宽度、高度、像素格式，**17301505=Mono8，35127316=RGB24**）。

## 五、横向对比与选型

### 5.1 测量模块对比

| 模块 | 输入几何对象 | 核心输出 | 是否需标定得物理距离 | 典型用途 |
| --- | --- | --- | --- | --- |
| 线圆测量 | 直线 + 圆（线输入：按线/按点/按坐标；圆输入：按圆/按参数） | 垂足点、距离、交点1-2、角度、测量直线、测量圆环 | 是（选特定坐标系+标定矩阵） | 圆孔到边间距 |
| 圆圆测量 | 圆 + 圆 | 圆心距、位置关系（Inside/Inscribe/Intersect/Circumscribe/Outside）、交点、测量圆环1-2 | 是 | 两孔间距 |
| 点圆测量 | 点 + 圆 | 中心距离、最近/最远距离、角度、测量圆环 | 是 | 齿到轮芯、柱钢内外径 |
| 点线测量 | 点 + 线 | 垂直距离、垂足点、垂线角度、最近/最远距离 | 是 | 角点到边、孔点到边 |
| 线线测量 | 线 + 线 | 绝对距离、夹角（锐角）、交点、角度标识点1-5 | 是 | 两边间距/夹角 |
| 点点测量 | 点 + 点 | 距离、中点、角度 | 是 | 圆心间距、两点间距 |
| 亮度测量 | 灰度图 ROI（图形/图像） | 最小/最大/均值/标准差/直方图(256)/对比度、输出掩膜 | 否 | 光源/环境光评估、区域对比 |

| 直方图工具 | 灰度图 ROI | 直方图/累积直方图(256)、中值/峰值/对比度 | 否 | 对比度筛选与增强 |

### 5.2 运算模块对比

| 模块 | 输入 | 输出 | 是否依赖标定 | 典型场景 |
| --- | --- | --- | --- | --- |
| 单点对位 | 示教点+运行点的**物理坐标**（点X/Y+角度） | x/y/theta 偏移（顺正，Δθ 归一化 -π~π） | 是（上游标定转换） | 对象点对位到目标点 |
| 单点抓取 | 像素点（基准+运行）+示教物理点+示教拍照物理点+标定文件 | 相对坐标X/Y/R + 绝对坐标X/Y/R | 是（平移旋转标定） | 单相机抓料 |
| 单点映射对位 | 对象像素点+目标像素点+目标像素直线起终点+示教物理点+双标定文件 | 相对坐标X/Y/R + 绝对坐标X/Y/R | 是（平移旋转标定 + 映射标定） | 上下相机贴合对位 |
| 单点纠偏 | 像素点（基准+运行）+示教物理点+标定文件（无示教拍照物理点） | 相对坐标X/Y/R + 绝对坐标X/Y/R | 是（平移旋转标定） | 单相机纠正物料姿态 |
| 标定转换 | 坐标点（图像/物理）+角度+坐标类型+标定文件 | 转换坐标X/Y、转换角度、单像素精度、平移X/Y、旋转、尺度、斜切、宽高比 | 是（自身即转换） | 图像↔物理坐标互转 |
| 点集对位 | 示教点-运行点多组（**2~8** 个） | x/y/theta 偏移 | 是（上游标定转换） | 多点稳健对位 |
| 线对位 | 多组特征线（按顺序连线）+对位形状（开/闭） | x/y/theta 偏移 | 是（上游标定转换） | 线特征对位（闭合矩形等） |
| 旋转计算 | 点/线 + 旋转中心坐标 + 旋转角度 | 输出点X/Y、输出线（起点/终点X/Y） | 否 | 绕中心旋转点/线 |
| 单位转换 | 像素间距 + 标定文件（iwcal/txt/xml）+像素当量修正 | 单像素精度、转换结果、像素距离（近似）、平移X/Y、旋转、尺度、斜切、宽高比 | 是 | 像素距→物理距（近似） |
| 变量计算 | 表达式（名称/注释/表达式/初始值/输出类型/初始化）+订阅变量 | var0（默认0）、结果显示 | 否 | 算术/逻辑运算 |
| 坐标转换 | 划片信息（划片中心点X/Y、划片宽/高）+ 输入点 | 输出点X/Y（左手图像系） | 否 | 划片内特征点转回原图坐标 |

### 5.3 标定选型速查（补充）

- 要"机构走位 + 像素↔物理" → **N点标定**（有海康板且想更准 → **N图像标定**）。
- 只测距离 / 多相机统一物理系 → **标定板标定**。
- 上下/两相机图像系对位 → **相机映射**（订阅前序点集）或 **映射标定**（海康板图像/文件）。
- 镜头畸变 → **畸变标定** + 畸变校正模块。
- 小视野大角度旋转中心 → **平移旋转标定**（可开组合标定）；纯旋转中心 / 需纯旋转标定文件 → **旋转标定**。
- 自定义坐标系或复用标定矩阵 → **坐标系** / **标定加载**。
- 引导动作选型：抓料→单点抓取；纠偏→单点纠偏；上下相机贴合→单点映射对位；点对位→单点/点集对位；线对位→线对位。
