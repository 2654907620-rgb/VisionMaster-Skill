# VM 模块参考：边缘学习

边缘学习属于深度学习的一种。与深度学习类模块一样，边缘学习类模块也分为 C 和 G 两种类型，两种模块的原理与参数基本一致，仅运行环境不同：

| 类型 | 运行环境 | 要求 |
| --- | --- | --- |
| 模块名称后缀为"C" | 基于CPU运行 | 推荐使用i7-8代及以上的CPU |
| 模块名称后缀为"G" | 基于显卡GPU运行 | 确保使用显存6 GB及以上的独立显卡 |

## 速览

- **注册分类**：依据已注册图像类别对图像分类；多类别（最多100类）、多目标；要求类间差异明显、类内一致性好；适用于每类样本量少且有新增类别的场景。分为注册/分类两流程，无追加注册。
- **异常分类**：仅 OK/NG 两类；两类关键特征存在可辨识差异；学习10张以内样本即可有效分类；准确率和分类效率高于注册分类；明确不存在第三种类别时使用。支持追加注册。
- **多类别分类**：多类别（至少2类、最多32类）；类间差异较明显；学习10张以内样本即可有效分类；效率高于注册分类；适用于有新增类别的场景。支持追加注册。
- **注册检测**：单类别、多目标；形态变化小、无重叠和背景干扰；注册模板即可满足简单场景检测，无需大规模训练；适用于产线换型频繁、要求模型迭代快的定位检测。不支持简单分类（需全监督检测）。
- **全监督检测**：多类别、多目标；形态变化小、无严重重叠；检出率和准确率高于注册检测；需标注全部目标；适用于简单定位分类场景。支持追加注册。
- **有无检测**：单类别、单目标；形态存在变化的柔性物体；学习10张以内样本即可满足简单场景的存在性检测；需注册图像+背景图像。支持追加注册。
- **学习计数**：单类别、多目标；形态存在变化的柔性物体；目标间无重叠；学习10张以内样本即可满足简单场景计数。支持追加注册。
- **注册分割**：单类别、多目标；形态简单、相互无遮挡；与DL实例分割类似但无需大规模训练；通过注册模板分割简单场景中的对应类别目标。

通用说明：各检测类模块均需前序有图像源模块；注册图可勾选"图像保存至模型"保存到方案/模型中；类别名称保存在模型中，导入模型时从模型文件获取。

### 学习计数

**功能**：对单一类别的目标进行计数和定位，适用于形态存在变化的柔性物体（如挤压变形的零食袋、褶皱的快递标签等）。所需训练数据量较少，注册图像应标注全部待计数目标。

**原理**：通过从注册图像中提取目标的特征数据，并在检测图像中搜索并定位具有同类特征的目标。仅支持对图像中单个类别的目标进行检测与计数。算法分为注册和检测两个步骤，并支持对效果不佳的异常样本追加学习：（1）注册步骤：获取包含目标标注的待注册图像，通过深度学习提取目标特征数据；（2）检测步骤：将特征数据与待检测图像输入计数模型，搜索并定位同类目标；（3）追加注册与检测步骤：出现新样本或异常样本时，修正检测结果作为追加注册数据，学习新样本特征并更新检测流程。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 输入图像 | image | 前序图像源模块采集的待检测图像 |

**输出**：

| 输出项 | 类型 | 说明 |
| --- | --- | --- |
| 耗时（ms） | float | 该模块运行时耗费的时间 |
| 模块状态 | int | 0代表NG（红色），1代表OK（绿色） |
| 结果类别总数 | int | 检出目标类别的总数量 |
| 结果类别名称 | string[] | 检出目标的类别名称 |
| 目标分类计数 | int[] | 各个类别下的目标数量 |
| 目标总数 | int | 检测区域内检测到的定位框个数 |
| 目标类别 | int | 检测到的目标实例的种类序号（需预先训练好模型并标记序号） |
| 目标置信度 | float | 每个定位框的置信度 |
| 目标状态 | int | 1代表定位框正常，0代表定位框异常 |
| 类别名称 | string | 类别名称，保存在模型中，导入模型时从模型文件获取 |
| 标签颜色 | String | 不同类别标签对应的RGB颜色值，可在注册图像操作中自定义 |
| 目标信息矩形 | box | 定位框所在矩形（含中心X/Y、宽度、高度、角度[-90,90]） |
| 目标面积 | int | 每个检测目标的面积大小 |
| 检测区域 | box | 检测ROI区域（含中心X/Y、宽度、高度、角度） |

**参数**（原文未给出取值范围和默认值）：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 最大查找个数 | 原文未给出 | 原文未给出 | 模块能查找到的最大目标数量，超出则舍弃，仅输出该数量的目标；不确定目标数量时建议调大 |
| 最小置信度 | 原文未给出 | 原文未给出 | 预测结果的最小置信度，低于该值的预测结果被舍弃；漏检时调低、错检时调高 |
| 最大重叠率 | 原文未给出 | 原文未给出 | 两预测框的最大重叠比例（重叠面积与较小预测框的比值），超过则舍弃较小置信度的结果 |
| 目标排序 | 按中心点X/Y坐标升序；按置信度降序 | 原文未给出 | 高级参数，设置输出预测结果的顺序 |
| 边缘筛选使能 | 开/关 | 原文未给出 | 高级参数，开启后筛选超出ROI边界的预测结果 |
| 最小边缘分数 | 原文未给出 | 原文未给出 | 预测框在ROI内的面积与整体面积的比值，低于该值则舍弃 |
| 面积使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置面积范围，超出则舍弃 |
| 宽度使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置宽度范围，超出则舍弃 |
| 高度使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置高度范围，超出则舍弃 |
| 角度使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置角度范围；顺时针旋转角度大于0，逆时针小于0 |

**模型/训练相关**：训练入口为模块"注册类别"页签 → 单击"+注册图像"进入注册图像窗口。样本要求：注册图像应标注全部待计数目标（单类别多目标场景）；可设一张不含目标物的图像为背景图以保证注册精度；支持自动追加/自动打标辅助标注。注册参数：旋转增强（启用后学习的特征对目标角度变化进行适应和增强，检测目标存在旋转时建议开启）。模型保存/复用：勾选"图像保存至模型"可将注册图保存到方案并在导出模型时保存在模型中；类别名称保存在模型中，导入模型时从模型文件获取。

**使用步骤**：
1. 在流程中添加图像源和学习计数，并将学习计数模块连接至图像源模块。
2. 双击学习计数配置相应参数。
3. 在注册类别页签完成注册（添加注册图：获取流程图像/获取当前图像/导入图像[缓存图像、本地图像、文件夹]；逐图标注全部目标；单击注册→配置旋转增强→开始注册）。
4. 执行流程进行检测。
5. 当出现新样本或未检出目标的异常样本时，在注册类别页签单击追加注册，将新特征数据或修正后的特征数据更新至检测流程中。
6. 执行流程再次进行检测。

**注意事项**：
- 该模块适用于单一类别下的多目标检测场景，标注时需将每张图像上的所有目标均标注出，以确保注册模型精度。
- 连续执行流程抓图时，达到图像上限后流程自动停止执行。
- 若已存在模型，获取流程图像时支持同步导入注册图的推理结果。
- 若已设置全局触发，返回注册图像界面时满足触发条件则流程图像自动同步至图像列表。
- 进行自动追加或自动打标时，推理结果自动显示标签，需手动调整目标区域或标签类别后才能加入训练样本。

### 有无检测

**功能**：判断场景中是否存在特定目标，对其进行定位并输出坐标位置，适用于形态存在变化的柔性物体。所需训练数据量较少，通过学习少量注册图像和背景图像实现目标检测。

**原理**：通过从注册图像中提取目标的特征数据，并在检测图像中进行特征匹配并定位目标。仅支持对图像中的单个目标进行有无判断。算法分为注册和检测两个步骤，并支持追加学习（注册：包含带目标标注的图像和背景图像；检测：特征匹配并定位；追加注册：修正结果更新检测流程）。

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 输入图像 | image | 前序图像源模块采集的待检测图像 |

**输出**：与"学习计数"模块结果一致——耗时（ms）、模块状态、结果类别总数、结果类别名称、目标分类计数、目标总数、目标类别、目标置信度、目标状态、类别名称、标签颜色、目标信息矩形（box，含中心/宽/高/角度[-90,90]）、目标面积、检测区域（box，含中心/宽/高/角度）。

**参数**（原文未给出取值范围和默认值）：

| 参数名 | 取值范围/选项 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 最小置信度 | 原文未给出 | 原文未给出 | 预测结果的最小置信度，低于该值的预测结果被舍弃；漏检时调低、错检时调高 |
| 边缘筛选使能 | 开/关 | 原文未给出 | 高级参数，开启后筛选超出ROI边界的预测结果，需配置最小边缘分数 |
| 最小边缘分数 | 原文未给出 | 原文未给出 | 预测框在ROI内的面积与整体面积的比值，低于该值则舍弃 |
| 面积使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置面积范围，超出则舍弃 |
| 宽度使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置宽度范围，超出则舍弃 |
| 高度使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置高度范围，超出则舍弃 |
| 角度使能 | 开/关 | 原文未给出 | 过滤参数，开启后需设置角度范围；顺时针为正、逆时针为负 |

**模型/训练相关**：训练入口为"注册类别"页签 → "+注册图像"。样本要求：注册图像包含带目标标注的图像和背景图像；可将一张不含目标物的图像设为背景图以保证注册精度；支持自动打标。注册参数：旋转增强（目标存在旋转时建议开启）。模型保存/复用：勾选"图像保存至模型"；类别名称保存在模型中，导入模型时从模型文件获取。

**使用步骤**：
1. 在流程中添加图像源和有无检测，并将有无检测模块连接至图像源模块。
2. 双击有无检测配置相应参数。
3. 在注册类别页签完成注册。
4. 执行流程进行检测。
5. 出现新样本或异常样本时，单击追加注册更新特征数据。
6. 执行流程再次进行检测。

**注意事项**：与学习计数相同——连续抓图达上限自动停止；已存在模型时获取流程图像支持同步导入推理结果；自动打标结果需手动确认后加入训练样本。

### 全监督检测

**功能**：基于少量标注样本实现简单场景的多类别目标检测定位，相比注册检测模块有更高的检出率和准确率。适用于物体和区域形态变化小、遮挡较少的简单场景。注册时应标注图像中全部待检测目标。

**原理**：基于深度学习目标检测算法，分注册和检测两步（注册：基于标注学习场景特征；检测：特征数据与待检测图像输入检测模型得出结果；另支持追加注册与检测）。与注册检测、DL目标检测的选型对比：

| 模块 | 分类能力 | 检测目标特点 | 使用场景 | 操作要求 |
| --- | --- | --- | --- | --- |
| 注册检测 | 单个类别 | 物体，形态变化小 | 目标间无严重重叠，且背景简单 | 注册若干图像，仅需标注典型目标 |
| 全监督检测 | 简单分类 | 物体或区域，形态变化小 | 目标间无严重重叠 | 注册若干图像，需标注全部目标 |
| DL目标检测 | 复杂分类 | 物体或区域，形态变化大 | 目标间有严重重叠 | 大规模训练数据，需标注全部目标 |

**输入**：

| 输入项 | 类型 | 说明 |
| --- | --- | --- |
| 输入图像 | image | 前序图像源模块采集的待检测图像 |

**输出**：与"学习计数"模块结果一致——耗时（ms）、模块状态、结果类别总数、结果类别名称、目标分类计数、目标总数、目标类别、目标置信度、目标状态、类别名称、标签颜色、目标信息矩形（box，含中心/宽/高/角度[-90,90]）、目标面积、检测区域（box，含中心/宽/高/角度）。

**参数**（原文未给出取值范围和默认值）：

| 最小置信度 | 原文未给出 | 原文未给出 | 最小置信度，低于舍弃；漏检调低、错检调高 |
| 最大重叠率 | 原文未给出 | 原文未给出 | 两预测框最大重叠比例，超过则舍弃较小置信度结果 |
| 目标排序 | 按中心点X/Y坐标升序；按置信度降序 | 原文未给出 | 高级参数，输出预测结果的顺序 |
| 边缘筛选使能 | 开/关 | 原文未给出 | 高级参数，筛选超出ROI边界的预测结果，需配置最小边缘分数 |

**模型/训练相关**：训练入口为"注册类别"面板 → "+注册图像"。注册配置参数（原文未给出默认值）：

- **手动设置分辨率**：一般无需设置；自动检测效果不好时可开启。分辨率：图像较长一边的分辨率按设置的数值缩放，另一边等比例缩放。模块会自动推荐一个数值，不满足时可基于推荐数值上下微调。
