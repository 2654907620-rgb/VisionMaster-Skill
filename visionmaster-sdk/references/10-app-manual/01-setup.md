# VM 应用手册：概览与方案搭建

> 本文档是「海康机器人 VisionMaster（VM）机器视觉软件」应用侧（GUI 使用手册）知识的蒸馏稿。
> 与 `visionmaster-sdk` skill（.NET SDK 二次开发）的关系：SDK 文档告诉你 API 怎么调；本文档告诉你**界面上各参数是什么含义、该怎么配**。
> 原文为 HTML 帮助文档抽取文本，图片已删除（仅保留图注文字，如「图 1 版本信息窗口」便于定位），导航噪声已去除。

## 速览

- VM（VisionMaster）是海康机器人视觉算法开发平台，由近千个算子 + 150+ 交互式视觉功能模块组成，支持 GUI 搭方案、SDK 二次开发、算子级二次开发三种模式。
- 软件为收费软件，需授权：本机加密狗 / 软加密（授权码）/ 远程加密狗（局域网共享）三种方式。
- 概念层级：**方案 → 流程 → 模块 → Group**。流程一般与相机一一对应；方案必需元素是「模块 + 流程」，相机并非必需（可用本地图）。
- 运行环境：Windows7/10/11（64 位），推荐 i7-6700 / 8GB 内存 / 显存 1GB；深度学习需 6GB 显存，支持 NVIDIA RTX 20/30/40/50 系列及 Tesla L2、AI 推理终端。
- 与 MVS（相机调试软件）版本需兼容：VM 主界面 帮助 > 版本信息 可查兼容的最低 MVS 版本；建议先装 VM 再装对应 MVS。
- 加密狗型号能力集以 `iMVS-VM-xxxx` 表示；带 6210/7120/7210 的型号支持导出算子代码、编辑运行界面、脚本等高级功能。
- 相机管理支持：全局相机、HKR 采集卡、Dalsa 采集卡、Matrox 采集卡四类；采集卡连接的相机本质是全局相机。
- 通信管理 = 设备管理 + 接收事件 + 发送事件 + 触发配置（全局触发）+ 响应配置 + 心跳管理；协议分**基本通信协议**（TCP/UDP/串口）与 **PLC 通信协议**（三菱/欧姆龙/西门子/ModBus 等）。
- 流程编辑：模块对齐自动连线，右键可禁用/复制/粘贴参数/注释/搜索；硬触发时一个流程对应一个相机，否则无法控制多流程触发顺序。
- 全局逻辑（全局相机、全局/局部变量、全局脚本、全局触发、数据队列）解决多流程联动、外部数据传递、流程控制。
- 运行界面可自定义，由画布、固定栏、控件构成；布局分割样式等功能仅 6210/7120 加密狗支持。
- 所有方案的模块结果新增「耗时（ms）」输出；单方案模块数量上限已扩充至 **4096** 个。
- 方案可加密保存（方案密码 + 加密狗密码双重加密）；保存路径默认本地，首次保存需选路径。
- 软件兼容 GigE Vision / USB3 Vision / Camera Link / CoaXPress 相机，及 TCP/IP、串口、UDP、ModBus、Ethernet/IP 等工业协议。
- 升级到 V5.0.0 起支持在线推送补丁包（启动 VM 弹窗提示，亦可 帮助 > 在线补丁升级 获取）。

### 1.4 术语介绍

| 术语 | 含义 |
| --- | --- |
| 方案 | 视觉方案/配方，视觉处理方法的总和（含图像采集、流程、通信、脚本等） |
| 流程 | 视觉处理方法，由模块按逻辑顺序组成，一般与相机相关，一个相机对应一个流程 |
| 模块 | 视觉处理最小单元，做特定图像算法或逻辑运算 |
| 模型 | 由图像/特征注册或训练得到的数据块，告知算法目标特征 |
| Group | 组合模块，多个模块的组合 |
| 脚本 | 特定描述性语言编写的可执行文件 |
| 位姿 | 目标相对参考坐标系的位置和姿态 |
| 基准点 | 设定为基准的点，用于测目标位置偏移 |
| 图像坐标系 | 以图像左上角为原点、X 向右、Y 向下、顺时针为正角度 |
| 物理坐标系 | 真实世界坐标系，距离对应真实距离 |
| 左手/右手坐标系 | 左手：X 右 Y 上 Z 背向自己；右手：Z 指向自己 |
| 手性一致性 | 两坐标系同为左/右手系记为 1 |
| 单像素精度 | 图像一个像素在真实世界的实际尺寸，越小精度越高 |
| 掩膜 | 告知算法计算哪些区域（灰度 255 计算，0 不计算） |
| BOX | 矩形框，由中心(X,Y)、宽、高、角度组成 |
| 卡尺 | 测量灰度值的矩形区域 |
| 检测区域 / ROI 区域 | 算法处理区域 / 感兴趣区域 |
| 质心 | 区域所有点算术平均 |
| Blob | 相似颜色/纹理组成的连通区域 |
| 概率图 | 反映检出得分强弱的图，像素值越大得分越高 |
| RGB/HSV/HSI/YUV | 颜色空间；YUV 含 YUV444/YUV422/YUV420，默认转 YUV444 |

## 2. 快速入门

### 2.1 准备工作

- 软件已集成加密狗及驱动，无需额外驱动；建议杀软加白名单（360 建议关闭）。
- **图像采集设备**：面阵/线阵相机（千兆网口、USB3.0、万兆网口、Camera Link、CoaXPress，兼容 GigE Vision/USB3 Vision/Camera Link/CoaXPress，推荐海康相机）；X86 开放平台（不支持深度学习模块）。
- **授权方式**：本机加密狗（USB 插入即插即用）、软加密（授权码激活，离线/在线，相对路径 `.\Applications\Tools\AuthActiveTool\SoftEncryptActive.exe`）、远程加密狗（Virbox 工具服务端配置，需同网段 ping 通）。不同授权规格见第 1.3 节。

### 2.2 方案构成

方案 = 「数据与逻辑配置」集合（图像采集、视觉处理流程、通信、脚本等）。

**必需元素**

| 元素 | 描述 |
| --- | --- |
| 视觉功能模块（模块） | 处理图像数据最小功能单元 |
| 视觉处理流程（流程） | 由模块构成，定义图像处理逻辑（采集 + 检测）；方案至少含一条流程 |

**可选元素**

| 元素 | 描述 |
| --- | --- |
| 运行界面 | 自定义 GUI，终端用户操控/监控方案 |
| 方案相关设备 | 相机、视觉控制器、PLC 等，绑定后数据交互 |
| 多流程运行逻辑 | 多流程联动 |
| 方案全局与局部逻辑 | 全局相机、全局脚本、全局触发、全局变量、数据队列；局部变量（单流程或单 Group） |

常见问题：相机并非必需——图像源模块可用本地图（工控机或局域网共享路径图像文件）调试。

### 2.3 搭建入门级方案（以「电池片检测」为例）

需求：计算电池片宽高并格式化；算中心点（中线交点+角平分线交点均值）；生成定位框并输出带框图像。

**方案思路（模块 → 作用）**

| 模块 | 作用 |
| --- | --- |
| 图像源 | 输入电池片图像 |
| 快速匹配 | 粗定位 |
| 位置修正 | 精定位（修正来料偏移） |
| 直线查找 | 定位四条边 |
| 中线查找 | 定位两组平行边的中线 |
| 角平分线查找 | 定位两组相交边的角平分线 |
| 线线测量 | 算宽高、中线交点、角平分线交点 |
| 变量计算 | 算中心点（两交点 X/Y 均值） |
| 几何创建 | 由旋转角度+宽高+中心生成定位框 |
| 格式化 | 整合并格式化输出字符串 |
| 输出图像 | 输出带框图像 |

**步骤一：创建方案** — 欢迎页单击「通用方案」进入主界面（或 文件 > 新建方案）。

**步骤二：搭建流程**

- 编排：从模块箱拖入流程编辑区，对齐自动连线；否则手动连接。
- 输入图像：双击图像源 → 基本参数「图像源」选本地图像（或相机/SDK）；图像显示区单击图标添加单张/文件夹图像。
- 定位电池片：流程栏单击执行一次出图；快速匹配 → 基本参数「输入源」选「图像源1.图像」，特征模板页签创建特征模板；位置修正 → 选择方式「按点」，原点订阅「快速匹配1.匹配点」，角度订阅「快速匹配1.角度」。
- 定位边：直线查找 → 输入源「图像源1.图像」，ROI 绘制直线卡尺，打开位置修正并订阅「位置修正1.位置修正信息」；共 4 个直线查找定位四条边。
- 算宽高与中心：线线测量 3/4 测宽高（线订阅对应直线查找输出直线）；中线查找/角平分线查找各 2 个；线线测量 1/2 算中线交点/角平分线交点；变量计算添加 var0/var1，表达式 `(<16 线线测量1.交点X>[0]+<17 线线测量2.交点X>[0])/2` 等。
- 生成定位框：几何创建订阅快速匹配旋转角度、线线测量宽高与中心。
- 格式化与输出：格式化添加数据行整合信息；输出图像「前项存储设置」选几何创建。

**步骤三：设计运行界面**（详见第 7 节）— 快捷工具条运行界面设计图标；分页布局 2 画面；拖入多图像（画面数量 1X2、数据源配置图像源/输出图像）、运行控制、文本框（显示「检测结果：」与格式化结果）；预览 → 保存。

### 2.4 运行与保存方案

- 运行：快捷工具条单次/连续运行（注意与流程页签上的单次/连续运行区分）；或运行界面运行。
- 保存：快捷工具条保存图标 / 文件 > 保存方案（首次选路径，可加密）/ 方案另存为。加密方案载入需方案密码，双重加密还需加密狗密码匹配。

## 3. 方案搭建 - 硬件设备配置

### 3.1 相机管理

VM 可添加：全局相机、HKR 采集卡相机、Dalsa 采集卡（Camera Link）相机、Matrox 采集卡（Camera Link）相机。采集卡相机本质同属全局相机，可作流程图像输入源。硬触发时对应流程自动执行，且仅首个绑定全局相机的图像源所在流程被触发——建议一个流程对应一个相机。

**添加相机**：快捷工具条相机管理图标 → 相机类型选择对话框（全局相机 / HKR采集卡 / Dalsa采集卡 / Matrox采集卡）→ 设备列表右键可重命名/删除 → 配置参数 → 确定。也可通过图像源模块「关联相机」或编排时添加。

**配置自定义参数相机**：常用参数含相机连接（选择相机、相机参数、实时取流）；自定义参数可在相机参数界面右键「添加至收藏夹」，自定义编辑界面支持新增分组、删除分组/参数、调整参数分组（勾选参数移动至目标分组）。自定义参数属全局相机，换相机不变。

**配置全局相机**（参数大类：常用参数、设备控制、自定义参数）

- 相机连接：GenTL 相机（选 Cti 文件 + 选相机）；类型选择（枚举 / 跨网段IP：本机IP、相机IP、连接相机、自动重连）；加载用户集1；实时取流；相机参数；保存用户集1。
- 触发设置：
  - 开始采集：触发模式出图开关（软触发时自动开；默认开，选相机后 1~2 秒生效）。
  - 触发模式：是否开启触发。
  - 触发源：SOFTWARE（每次执行流程软触发）/ 其他 IO 信号源。
  - 触发延迟（μs）：收到触发后延迟出图。
  - 条件触发数：收到多少张图才触发流程（硬触发有效，如 5 则连跑 5 次）。
  - 条件触发超时（ms）：等待超时仍触发（硬触发有效）。
- 图像参数：图像宽度 / 图像高度 / 像素格式 / **插值算法类型**（Quick 快 / Balance 均衡默认 / Optimal 最优 / OptimalPlus 最优+）/ 帧率 / 实际帧率 / 曝光模式（OFF 手动 / ONCE 单次自动 / CONTINUOUS 连续自动）/ 曝光时间（μs）。
- 增益：增益 / 增益模式（OFF/ONCE/CONTINUOUS）/ 最小增益 / 最大增益（CONTINUOUS 时设范围）。
- Gamma：Gamma 使能 / Gamma（0~1 暗处提亮，1~4 暗处变暗）/ 选择器（用户 / sRGB）。
- 线阵相机参数：行频 / 实际行频（线阵时）。
- 软件参数：相机类型（标准面阵/智能相机/线阵）；有效电平（高电平有效/低电平有效）；断线重连时间（秒）；软触发超时（秒）；图像缓存数量（硬触发）；等待连接时间（ms）；**分时频闪拆图**（单台采多图）。
- 设备控制：
  - IO 控制：IO 选择项 / IO 模式（input/strobe）/ IO 输出选择器 / IO 输出源（OFF / SOFTWARETRIGGER：反相输出、电平触发）。
  - 光源控制（智能相机）：光源使能 / 光源模式（strobe 频闪：光源延迟时间；constant 常亮）/ 光源持续时间 / 光源提前时间。

**配置 HKR 采集卡连接的相机**：先选采集卡再选相机；配置文件（.hcf，由采集卡客户端导出属性生成）；图像宽度/高度；脉冲数；触发源；触发选择器（FrameBurstStart 帧触发 / LineStart 行触发，面阵仅帧触发）；触发模式。

**配置 Dalsa 采集卡连接的相机**：先加载 .ccf 配置文件（否则报错），再选相机（仅硬触发，不支持软触发）；缓存张数调图像缓存空间。

**配置 Matrox 采集卡连接的相机**：先加载 .dcf 配置文件，选相机（仅硬触发）；可能需设波特率 115200；图像参数与增益同全局相机。

**接收事件**（解析外部设备发来的数据；外部设备可为通信设备或有 IO 的视觉控制器，不支持纯光源控制器）。方式：文本-协议解析、文本-协议比对、字节匹配-协议比对、脚本。

- 文本-协议解析：绑定设备（PLC 需绑定地址）、分隔符、字符长度比较（默认 0 会失败）、输出列表（名称/类型 int·float·string/数据结果/状态）。
- 文本-协议比对：输入配置（同上 + 比较规则配置 不比较/!=/=）+ 组装配置（回复给设备、分隔符、组装列表）。
- 字节匹配-协议比对：解析配置（字节长度比较 默认0 最大512、ASCII数据、规则匹配逻辑 与/或、规则列表：名称/字节起止位置/类型 int·float·string·byte/顺序 ABCD·BADC·DCBA·CDAB/比较规则 不比较·!=·=·上升沿·下降沿·更改为、数据结果、状态）+ 组装配置（支持 byte）。
- 脚本：python 脚本（路径 `.\Applications\ModuleProxy\x64`，示例 RecvEventTest.py）；绑定设备、回复给设备、分隔符、载入路径、组装列表（getOutputParam() 定义，支持 string/int/float/byte；handleMessage(info) 默认分隔符 #）。

**发送事件**（将 VM 固定格式数据发外部通信设备，需搭配发送数据模块）：文本-直接输出、文本-组装输出、脚本（SendEventTest.py，getInputParam() 定义，handleMessage(list) 默认分隔符 #）。

**心跳管理**：添加设备（PLC 需选具体地址）→ 心跳类型（单数据/多数据）→ 发送内容 → 时间间隔（默认 1000ms）→ 启用。支持多设备同时心跳。

**响应配置**（指定动作时发信息给通信设备）：

- 方案加载：通信设备（PLC 需选寄存器地址+数据类型 int/float/string，string 可设结束符）、通信超时时间(s)、结束符（\r/\n/\r\n/自定义）、触发字符。
- 流程控制：通信设备、结束符、分隔符、空闲时触发/忙碌时触发；发送规则 {配置内容}{分隔符}{流程ID}（流程ID = 界面数值 - 9999）。
- 相机响应配置：通信设备、分隔符、连接时触发/掉线时触发；发送规则 {配置内容}{分隔符}{相机ID}。

**通信示例**

- 文本-协议解析示例：TCP 客户端接收 `{字符串,整型}`，解析后赋直线查找模块「边缘阈值」并触发流程1（分隔符 `,`，out2 订阅到运行参数，触发命令 执行流程→流程1）。
- 字节匹配-协议比对示例：ModBus（TcpClient）接收 4 字节，前2解析 int、后2 解析 string，触发所有流程（寄存器地址协议类型 RTU、Int 16bit、个数 2；规则 in1 字节0~1 int ABCD、in2 字节2~3 string；启用轮询使能；示例 `00 5C 41 44` → out1=92, out2=AD）。
- 控制器示例（字节匹配-协议比对）：VC2000 串口号 COM2，IO 4 上升沿触发流程1（规则 字节3~3 int ABCD 上升沿；开启 IO 输入轮询开关）。

## 4. 方案搭建 - 流程配置

**单流程运行逻辑**：新建/导入方案默认一条空流程。

1. 添加模块：右键流程编辑区选模块，或从模块箱拖入。
2. 排序连接：对齐自动连线；可删连接线、删模块、禁用/启用、复制粘贴模块、复制粘贴参数、搜索模块、添加注释。
3. 配置模块（详见第 5 节）。
4. 试运行：流程页签单次/连续运行；效果不符调试运行参数。

**多流程运行逻辑**：复杂场景引入流程 + 全局相机 + 数据队列 三类逻辑实体（最多 64 条流程）。

- 步骤一：流程栏 `+` 添加流程，配置并试运行。
- 步骤二：流程栏图标进入多流程编辑区，添加流程/数据队列/全局相机（拖入或右键 工具 > …），建立连接。
- 步骤三：定义输入输出：流程配置窗口 输入设置（类型多选/int/float/string/byte/pointset/IMAGE/PIXELIMAGE/BOX/POINT/LINE/FIXTURE/ANNULUS/CONTOURPOINT/RECT/CLASSINFO/POLYGON/POSTURE/ELLIPSE 等；IMAGE/PIXELIMAGE 可勾选显示）、输出设置（同理，部分类型可勾选显示）。
- 步骤四（可选）：自定义运行参数（运行参数页签，最多 32 分组，默认分组0）、渲染效果与通信（显示设置 + 通信配置：定时发送/流程结束时发送，含 时间间隔ms、发送对象、条件判断 OK/NG、OK发送/NG发送/超时发送）。
- 步骤五：试运行（快捷工具条单次/连续运行方案）与调试。

**其他操作与配置**（流程栏右键）：流程导出（.Prc）、流程拷贝、删除、导出算子代码、设置运行间隔（ms，流程耗时>间隔则不生效；与软件设置「流程延时」有生效优先级）、流程执行NG时停止、重命名、设置流程超时时间（默认 0 不限制）。

## 5. 方案搭建 - 模块配置

**模块使用基础规则**：模块前后序连接由「模块结果数据」与「可输入数据」是否匹配决定；每个模块有「前后序模块」「模块结果」「基本参数」说明（见各模块章节）。

**模块配置窗口**：基本参数（输入数据）、运行参数（算法参数）、结果显示（渲染）；含特征模型的另有 特征模板 页签。左上角图标可看对应模块帮助文档。

**基本参数**（通用：图像输入 + ROI 区域）

- 图像输入：订阅输入源图像。
- ROI 区域：
  - 输出掩膜：是否输出 ROI 掩膜图像。
  - ROI 区域类型：图形类型（自定义 ROI，可设屏蔽区与位置修正）/ 图像类型（掩膜图像订阅）。
  - 图形类型 - ROI 创建：绘制 / 继承（按区域 / 按参数：X/Y、宽、高、角度等）。
  - 屏蔽区创建：绘制 / 继承（屏蔽 ROI 内部分区域）。
  - 位置修正：选择方式 按信息/按点/按坐标（需前序位置修正模块）。

**运行参数**（通用设置方法）：下拉选择类、启用类、设置数值类（自定义；或切换订阅前序模块结果）。左下角图标重置默认。订阅窗口可勾选默认方式。

**结果显示**：结果判断（多条件均满足则 OK，否则 NG）、图像显示（开关显示 + OK/NG 颜色/透明度/粗细）、文本显示（内容、OK颜色/NG颜色、字号、透明度、位置X/位置Y）。

**绘制 ROI 区域**（支持形状与操作，表 1）

| ROI 形状 | 操作 |
| --- | --- |
| 全屏 | 检测区=整幅图像（默认） |
| 矩形 | 拖拽绘制；可调位置/角度/大小，或改中心点X/Y、宽/高、角度 |
| 多边形 | 逐点单击，末点双击；可调交点 |
| 圆 | 圆心+圆周点；内径/外径 |
| 扇形 | 圆心+圆周点；起始角度/角度范围 |
| 阵列圆 | 拖拽；横向圆个数M/纵向圆个数N 仅此处调 |
| 直线卡尺 | 默认绘制；卡尺数量仅此处调，卡尺宽/高 |
| 圆卡尺 | 圆心+圆周点；卡尺数量仅此处调 |
| 圆弧卡尺 | 起点+终点；半径/方向/卡尺数量 |
| 双矩形 | 自动绘制；宽/高/角度 |
| 四矩形 | 默认；中心点X/Y、宽/高、角度 |
| 点 | 单击；点X/Y |
| 线 | 起点+终点；起点/终点X/Y |
| 坐标系 | 原点+XY；中心点X/Y、角度 |

ROI 屏蔽区域：图形类型下绘制屏蔽（多边形类）。模型配置掩膜区域：形状含扇形/扇圆形/矩形/多边形/轨迹；可锁定/解锁掩膜与屏蔽区。

## 6. 方案搭建 - 全局与局部逻辑配置

**全局相机**：对应相机管理中的全局相机（添加见 3.1，参数配置见 3.1 配置全局相机）。

**全局/局部变量**：方案范围外定义的变量，可被运行界面、模块输入/输出/算法参数、发送数据模块订阅。全局变量针对整个方案；局部变量分单流程、单 Group 两种（Group 局部变量不供嵌套 Group 用；流程局部变量不供流程内 Group 用；全局供整方案）。可分组、自定义名称/类型/当前值，覆盖更新机制。

- 类型：int/float/string/byte/pointset/IMAGE/BOX/POINT/LINE/FIXTURE/ANNULUS/RECT/POLYGON/ELLIPSE。
- 配置：名称、注释、类型、当前值、输入来源（模块结果订阅）、目标输出（赋值模块目标参数）、初始化（全局变量可收 `SetGlobalValue:var0=0` 或 `SetGlobalValue:var0=123,var1=12.25`，局部变量无此参数）。
- 操作：导入/导出（.gvar，输入来源/目标输出不导出）、搜索、置顶/上移/下移、保存变量（仅全局变量，实时生效）。

**全局触发**（快捷工具条图标，可事件触发/字符串触发；导入导出经通信管理）

- 事件触发：新建触发 → 选触发事件（参考通信示例）→ 绑定参数（目标输出绑运行参数、设置输入绑输入参数）→ 触发命令类型（切换方案/执行流程/执行模块/执行模块动作，如 N 点标定清空标定点）→ 完成触发配置。
- 字符串触发：外部 TCP/UDP/串口设备发触发字符时执行动作（需开数据上传）。匹配模式：完全匹配/部分匹配/不匹配；触发命令类型同上（切换方案需路径+密码；执行流程需流程ID+触发字符；执行模块动作如重置变量计算变量、清空 N 点标定点）。

**全局脚本**（快捷工具条图标；方案全局资源，控流程/通信/模块参数）

- 控制栏：导入(.CS)/导出/示例程序/工程目录(VS调试)/引用程序集/保存/加密（密码验证）。
- 按钮：预编译（调 Init）、执行（调 Process）、确定。
- 使用限制：仅标准 C#（Windows）；无法控硬触发/通信触发/全局触发；单流程执行按钮不触发全局脚本。
- 核心接口：Init（加载方案/预编译时执行，初始化）、Process（多流程执行时执行，定义批量执行逻辑），另含 SetScriptContinuousExecuteInterval / GetScriptContinuousExecuteInterval / Dispose / InitAfterLoadSol / Get·SetGlobalVariableInt·Float·StringValue / StartGlobalCommunicate / Regesiter·UnRegesiterReceiveCommunicateDataEvent / OnReceiveCommunicateDataEvent / SendCommDeviceData / ConsoleWrite。
- 与脚本模块区别：全局脚本可定义多流程执行逻辑且支持 SDK；脚本模块仅作流程内模块、不支持 SDK。
- VS 调试：关 vServerApp.exe，附加主进程 exe，设断点后单次执行流程查看。
- 程序集添加：默认已加基础类库；可加 C# 程序集（`.\Development\V4.x\ComControls\Assembly`），仅支持 C#；非托管库用 DllImport 调用。
- 应用示例：流程控制（流程1+2 各执行1次后触发流程3）、设置模块参数（Process 中设快速匹配 MaxMatchNum=10 并获取结果）。

**数据队列**（流程间传数据，配发送数据/接收数据模块；最多 16 普通队列 + 4 图像队列；IN 类型 int/float/string/IMAGE；普通队列行数 [1,256]，IMAGE [1,10]，先进先出）

- 队列设置：添加队列、选数据类型、填列名称（不重复）、设队列行数。
- 触发流程：添加待触发流程（最多 16），开/关异步触发（同步：数据入队满足即触发，失败等下次；异步：子线程轮询判断，失败也间隔判断）。一次触发最多一个流程成功；失败是否保留数据由 `.\Applications\Module(sp)\x64\Global\DataQueueConfig.xml` 的 value（0 删/1 留）控制。
- 使用示例：流程1（图像源+发送数据→数据队列），流程2/3（接收数据+直线查找）按触发顺序运行，解决图像采集速率>处理速率问题。

## 7. 方案搭建 - 运行界面设计

运行界面用于终端用户操控/监控方案。设计窗口（工具条图标进入）含工具条、控件区、预览及编辑区、属性设置区。

**设计窗口概览**：工具条含加载/保存/模板设置/图层/对齐/分布/撤销/重做/删除/自适应/缩放/固定栏开关/预览/导出（模板、布局分割、导出等功能仅 6210/7120 加密狗支持）。

**通用设计思路**：选模板 → 设固定栏（上/下/左/右）→ 设画布布局 → 加控件并设数据源。控件可拖入，支持图层/对齐/分布/复制粘贴(Ctrl+C/V)。

**界面元素参考**

- 画布及固定栏：画布可增删、布局分割样式（基础布局 1~10 行/列；分割模板）、显示网格/网格颜色/背景；顶/左/右固定栏同画布（左/右可设宽度）；底部固定栏最多实时查 20 个设备连接状态（边距、选择列表：相机管理/通信管理中设备）。
- 控件配置参考（控件分类）：
  - 基础：图像、多图像、运行控制、运行状态、OK/NG、文本框、按钮、开关控制、参数设置、设置变量、字符设置、信号灯、条件信号灯
  - 布局：组合框、子界面、Tab 页
  - 图表：表格、线图阵列、多数据线图、生产统计、饼图、参数组合、文本框组合
  - 其他：图片、世界时钟、界面日志
- 图像控件（常用）参数：数据源、图形配置（叠加模块图形）、叠加图层1/2/3、保留上一次结果；布局（自动填充、自适应、尺寸、边距 T/B/L/R、对齐方式）；外观（显示状态栏、显示工具栏、显示辅助线）。
