## 13.13.1 圆拟合
*手册 PDF 1090–1093 页*

> 圆拟合可基于三个及以上的已知点拟合成圆。

**参数（7）**

| 参数名 | 说明 | 默认值 | 取值范围/枚举 |
|---|---|---|---|
| **输入源** | 可选择前序模块的图像数据 | — | 可选择前序模块的图像数据 |
| **拟合点** | 选择流程中采集到的点集作为拟合来源。可通过输入方式参数选择按点或按坐标方式订阅点的数据 | — | — |
| **剔除点数** | 误差过大而被排除不参与拟合的最小点数量。一般情况下，离群点越多，该值应设置越大，为获取更佳查找效果，建议与剔除距离结合使用 | — | — |
| **剔除距离** | 允许离群点到拟合直线的最大像素距离，值越小，排除点越多 | — | — |
| **初始化类型** | 包括全局法和局部最优两种。用局部最优，否则采用全局最优 | — | 包括全局法和局部最优两种 |
| **权重函数** | 包括最小二乘、huber 和tukey 三种。三种拟合方式只是权重的计算方式有些差异。随着离群点数量增多以及离群距离增大，可逐次使用最小二乘、huber、tukey | — | 包括最小二乘、huber 和tukey 三种 |
| **最大迭代次数** | 拟合算法的最大执行次数 | — | — |

**输出结果（8）**

| 结果名 | 类型 | 说明 |
|---|---|---|
| **模块状态** | `int` | int 型，0 代表NG，此时模块呈现红色；1 代表OK，此时模块呈现绿色 |
| **输出圆环** | `annull` | annull 型，表示模块查找到的圆，记录了圆的圆心、内径和角度等信息 |
| **圆心** | `point` | point 型，表示查找到的圆的圆心坐标 |
| **圆心X** | `float` | float 型，代表圆心的X 坐标 |
| **圆心Y** | `float` | float 型，代表圆心的Y 坐标 |
| **内径** | `float` | float 型，代表圆的内径 |
| **圆半径** | `float` | float 型，代表圆的半径 |
| **圆起始角度** | `float` | float 型，代表圆起始边与水平方向的夹角 |

## 13.13.2 椭圆拟合
*手册 PDF 1094–1096 页*

> 椭圆拟合可基于五个及以上的已知点拟合成椭圆。

**参数（2）**

| 参数名 | 说明 | 默认值 | 取值范围/枚举 |
|---|---|---|---|
| **拟合点** | 选择流程中采集到的点集作为拟合来源。可通过输入方式参数选择按点或按坐标方式订阅点的数据 | — | — |
| **误差容忍度** | 在进行椭圆拟合时会计算每个参与拟合的边缘点的拟合误差，该参数值越小时，拟合时删除掉的边缘点越多，拟合结果更加准确，但该值设置的过于小时，有可能造成过拟合 | — | — |

**输出结果（5）**

| 结果名 | 类型 | 说明 |
|---|---|---|
| **模块状态** | `int` | int 型，0 代表NG，此时模块呈现红色；1 代表OK，此时模块呈现绿色 |
| **输出椭圆** | `—` |  |
| **圆心点** | `point` | point 型，表示查找到的椭圆的圆心点 |
| **中心X** | `float` | float 型，代表圆心点的X 坐标 |
| **中心Y** | `—` |  |

**参数（8）**

| 参数名 | 说明 | 默认值 | 取值范围/枚举 |
|---|---|---|---|
| **输入源** | 可选择前序模块的图像数据 | — | 可选择前序模块的图像数据 |

| **剔除点数** | 误差过大而被排除不参与拟合的最小点数量。一般情况下，离群点越多，该值应设置越大，为获取更佳查找效果，建议与剔除距离结合使用 | — | — |
| **剔除距离** | 允许离群点到拟合直线的最大像素距离，值越小，排除点越多 | — | — |
| **初始化类型** | 包括全局法和局部最优两种。则采用局部最优，否则采用全局最优 | — | 包括全局法和局部最优两种 |

| **最大迭代次数** | 拟合算法的最大执行次数 | — | — |
| **角度拟合约束** | 开启后，根据期望直线角度和直线角度容忍范围设置的数值判断直线的角度是否符合要求。假设期望直线角度设为10，直线角度容忍范围设为20，则直线角度在-10° ~ 30°之间为符合要求 | — | — |
