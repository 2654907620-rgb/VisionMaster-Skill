## 13.12.1 划片拆分
*手册 PDF 1072–1074 页*

> 划片可将输入的图像根据设置的运行参数划分为多张图像输出。

**参数（2）**

| 参数名 | 说明 | 默认值 | 取值范围/枚举 |
|---|---|---|---|
| **X/Y 方向划片数** | 即水平/垂直方向需要划分的划片数量 | — | — |
| **X/Y 方向重叠率** | 即水平/垂直方向的相邻划片之间的重叠率；当重叠率设置为0 时，则表示相邻划片之间无重叠部分 | — | — |

**输出结果（8）**

| 结果名 | 类型 | 说明 |
|---|---|---|
| **模块状态** | `int` | int 型，0 代表NG，此时模块呈现红色；1 代表OK，此时模块呈现绿色 |
| **检测区域** | `box` | box 型，代表图像中需进行检测的ROI 区域 |
| **检测区域中心点** | `point` | point 型，代表检测区域的中心点 |
| **检测区域中心点X** | `float` | float 型，代表检测区域中心点的X 坐标 |
| **检测区域中心点Y** | `float` | float 型，代表检测区域中心点的Y 坐标 |
| **检测区域宽度** | `float` | float 型，代表检测区域的宽度 |
| **检测区域高度** | `float` | float 型，代表检测区域的高度 |
| **检测区域角度** | `—` |  |

## 13.12.4 Box融合
*手册 PDF 1082–1085 页*

> Box融合可将多个Box按照设置的重叠率进行融合。

**参数（14）**

| 参数名 | 说明 | 默认值 | 取值范围/枚举 |
|---|---|---|---|
| **按区域/按参数** | 订阅需进行Box 融合的区域。可选按区域或按参数 | — | 可选按区域或按参数 |
| **按区域** | 通过区域参数订阅Box 区域 | — | — |
| **按参数** | 通过ROI 中心点X/Y、ROI 宽度/高度、ROI 角度参数订阅Box 区域 | — | — |
| **Box 标签** | 订阅box 的标签信息 | — | — |
| **融合依据** | 可设置多个Box 的融合依据，可选重叠率或Box 中心之间的距离 | — | 可选重叠率或Box 中心之间的距离 |
| **重叠率** | 通过重叠率参数设置Box 重合时的最小重叠率 | — | — |
| **Box 中心之间的距离** | 根据设置的Box 中心点之间X 方向和Y 方向的距离判断是否融合。通过X/Y 方向的距离设置最大距离 | — | — |
| **Box 融合类型** | 可选三种融合类型 | — | 可选三种融合类型 |
| **无条件融合并按缺陷优先级输出标签** | 对支持的标签且满足融合依据的Box 区域进行合并，合并后输出优先级较高的Box标签。此时需设置以下参数 | — | 支持的标签且满足融合依据的Box |
| **标签优先级** | 订阅标签的优先级，一般通过脚本、格式化或全局变量的方式订阅实现 | — | — |
| **标签分割符** | 设置各个标签之间的分割符，下拉选择即可 | — | — |
| **优先级排序** | 调整标签的优先级，可选升序、降序 | — | 可选升序、降序 |
| **按标签类别融合并输出标签** | 对具有相同标签且满足融合依据的Box 区域进行合并，合并后输出共同的标签。需订阅Box 标签 | — | — |
| **无条件融合并随机输出标签** | 对满足融合依据的Box 区域进行合并，合并后随机输出一个标签 | — | — |

**输出结果（8）**

| 结果名 | 类型 | 说明 |
|---|---|---|
| **模块状态** | `int` | int 型，0 代表NG，此时模块呈现红色；1 代表OK，此时模块呈现绿色 |
| **重合Box 个数** | `int` | int 型，代表经过融合后得到的Box 的数量，其余Box 由于重叠率未达到阈值所以两两之间不能被融合 |
| **Box 标签** | `string` | string 型，代表经过融合后得到的Box 的标签，数组，其长度等于重合Box 个数 |
| **Box 融合** | `—` |  |
| **融合中心点** | `—` |  |
| **中心点X** | `float` | float 型，代表经过融合之后剩下Box 的中心点X，数组，其长度等于“重合Box 个数” |
| **中心点Y** | `float` | float 型，代表经过融合之后剩下Box 的中心点Y，数组，其长度等于“重合Box 个数” |
| **宽度** | `—` |  |
