# VisionMaster 产品概览 · 开发模式 · 部署与许可

## 0. 一句话定位

海康机器人 **VisionMaster（简称 VM）** 是一套通用机器视觉软件平台：图形化搭建"方案 → 流程 → 模块"完成视觉检测，同时提供 **.NET SDK（VM SDK）**、**算子SDK**、**算法模块开发** 三种二次开发通道，把 VM 嵌进自己的软件或给 VM 补充自定义算法模块。

---

## 1. 四种使用/开发模式（必读，决定技术路线）

> 摘自 FAQ 手册《VM 开发模式必读》。**先判断用户属于哪一种，再决定用哪个开发通道** —— 这是所有回答的起点。

VM 的开发模式分为 **VM SDK 开发、算子SDK 开发、算子模块开发**（外加无需开发的 **VM 应用**）。

**依赖关系**：VM SDK 开发依赖于 VM；算子模块开发给 VM 补充算法模块；算子SDK 开发依赖于算子安装包。由于 VM 安装包含算子安装包，**统一建议安装 VM**。

| 模式 | 适用场景 | 代码量 / 周期 | 平台提供 | 官方评价 |
|---|---|---|---|---|
| **1. VM 应用**（无开发） | 简单应用场景，VM 能实现业务逻辑；无定制界面需求；无外围（数据库、图表统计）需求 | 无需开发 | 完整 VM 界面与全部算法模块 | 轻松上手，调参方便 |
| **2. VM SDK 开发**（= VM 二次开发） | 用户希望**部分**业务逻辑自己实现（如定位计算）；有定制界面和外围功能需求；或要把 VM 嵌入自己开发的软件 | 代码量**少**、周期**短** | VM 提供各类流程与参数编辑控件 | **最为推荐的开发模式**，能满足绝大多数应用需求 |
| **3. 算子SDK 开发** | 用户希望**全部**业务逻辑自己实现 | 代码量**大**、周期**长** | 海康只提供**算子库和少量界面控件** | 能满足部分应用需求 |
| **4. 算法模块开发**（**只支持 C++**） | 用户希望把自己开发的算法**封装成模块**并能在 VM 中使用（拖拽、订阅等），补充项目所需算法功能 | 需要一定算法开发经验和编程功底 | VM 模块框架 + 模块开发框架 | — |

**快速选型口诀**

- 只想调参跑检测 → **VM 应用**
- 要定制界面 / 把 VM 嵌进自己的 C#/WinForm/WPF 程序 → **VM SDK 开发**（本知识库主线）
- 要用海康算法库自己做全部界面和业务 → **算子SDK 开发**
- 要写自己的算法并当成 VM 模块用 → **算法模块开发（C++）**

## 4. 版本激活与升级

### 4.1 激活

- **激活工具**：`ActivationTool.exe`，相对路径 `..\Applications\Tools\ActivationTool`，启动后自动激活当前版本。
- **前提**：关闭 VisionMaster 与 Visual Studio 所有进程。
- **试用版限制（VM4.0）**：最多只支持 **2 个流程**；最多只支持建 **2 个全局相机**；通信管理移除 Modbus 和 PLC 功能；去除图像组合模块、四边形查找模块、多直线查找模块；不支持深度学习功能。
- **试用版激活报错"更新失败：应用程序与本地 LM 通讯出错"**：在 `VisionMaster4.0.0\Applications\EncRuntime` 中运行 `haspdinst_33582.exe`，安装完成后点 OK，再运行 `VM_6600_S_V400_Unlock30d.exe` 即可成功激活。

### 4.2 升级二次开发程序

- **4.0 / 4.1 → 4.2+**：先用 `DevelopProcedureUpgradeTool.exe` 备份项目 debug（路径 `..\Applications\Tools\4.0二次开发程序升级4.2版本工具`），再用 `ImportRef.exe` 添加引用（路径 `..\Development\V4.x\ComControls\Tool`）。
- **4.2+ → 4.2+ / 4.3+**：直接打开即可。
- **方案/流程升级**：用新版本 VM 打开老版本方案/流程并另存为。
- **注意事项**：
  - VM4.x 启动前需 VM4.x 能正常打开并运行方案。
  - 4.3 部分接口名变化但基本兼容 4.2。
  - 同机装多版本会备份先装版本的算子。
  - 卸载某版本**勿勾选**卸载加密狗驱动 / 相机SDK / 算子SDK。

## 5. 软件许可

**三种授权方式**

| 方式 | 说明 |
|---|---|
| **本机加密狗** | 精锐 5.0 加密狗，即插即用，**仅对本机工控机有效** |
| **软加密** | 授权码激活，支持在线/离线；换机或重装需**先迁出再迁入** |
| **远程加密狗** | 局域网服务端插狗，客户端免狗 |

- 未授权时 Demo 可打开但**不能实际使用**。
- 加密狗异常：检查是否插狗或重装驱动，驱动路径 `..\VisionMaster+版本号\Drivers\SenseShield\install.bat`。
- **加密狗型号功能差异**：相机路数 —— 无后缀 **4 路**、`SE` 后缀 **2 路**、`PRO` 不限制（6210/7210 不限制）。软加密型号 `iMVS-VMS-*`、远程加密狗 `iMVS-VMNET-*` 功能类别类似。

## 9. 常见选型/环境类问题速查

| 症状 | 结论 | 详见 |

| 提示未注册 ActiveX 控件 | 注册表/引用问题 | FAQ 2.1.8 |
