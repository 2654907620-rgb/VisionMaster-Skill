3. **外观检测（PCB）方案**：图像源 → 高精度匹配 → 位置修正 → 亮度检测 → Blob 分析 → 条件检测 → 直线查找/圆查找 → 格式化 → 发送数据（TCP 服务端）。
4. **图像检索原理**：表示学习 + 分类器注册；用 VMTrain 打标签、本地/云/本地服务器训练生成 `bin`，再用 DL 图像检索模块注册 Gallery（`gall` 文件）。与图像分类区别：检索训练一个表示模型，可为不同检索库注册不同分类器。

7. **轮廓查找示例**：`Cv2.Canny` + `Cv2.FindContours` + `Cv2.DrawContours`，输出像素格式 `RGB24`。
8. **定位引导核心三步**：标定 → 示教 → 生产（求偏差），必须依次进行。
9. **标定方式**：工具中心与旋转中心共轴用**九点标定**（平移标定）；不共轴用**十二点标定**（平移旋转标定）。
10. **标定精度要求**：平移像素平均误差一般 < 1 像素，旋转像素平均误差 < 0.5 像素；角度旋转一致性 1 表示一致、-1 表示相反。
11. **单点抓取 / 单点纠偏 / 单点映射对位**：分别依赖同名模块 + 格式化 + 发送数据，结果分相对坐标与绝对坐标。
12. **上下相机映射对位**：统一到机构坐标系需两次标定（下相机 12 点 + 上下相机映射标定），映射标定取 ≥ 4 个不共线特征点。
13. **汽车挡风玻璃多相机对位**：4 次 12 点标定（上/下相机各 2），共搭 6 个流程；总偏差 = 上相机车身偏差 + 下相机玻璃偏差，目标精度 ±0.2mm。

## 2.2.1 外观检测：利用 VM 实现缺陷检测及尺寸量测

- **场景 / 目标**
  - 环境：VM4.0.0。
  - 需求：对 PCB 板三处区域检测 —— 区域1 检测锡片**有无**、区域1 检测锡片**外观完整性**、区域2 测量装配件长度 d1（图像中上下端高度）、区域3 测量圆心到区域2 装配件上端的距离 d2。
  - 输出：每次拍照后，视觉软件将总检测状态（OK=1，NG=0）以及两个测量值（物理值）发给上位机。
- **方案思路**
  - 检测与测量分离：检测用「亮度检测 + Blob 分析 + 条件检测」判定有无与完整性；测量用「直线查找 + 圆查找 + 格式化」算距离。
  - 用高精度匹配 + 位置修正做基准定位，保证后续 ROI 稳定。
- **实施步骤**
  1. 增加**图像源模块**，配置图像源（本地图像 / 相机 / SDK；实际生产用相机，本地调试用本地图像，通过 SDK 接口给图选 SDK；用相机前需在快捷工具栏全局相机配置相机）。
  2. 增加**高精度匹配模块**，连线连接，设置图像源（通常为图像源输出图像）；点击特征模板→创建，用掩膜工具选特征区域，设定参数创建模板（默认自动模式，必要时切手动；速度尺度与特征尺度控制模板精细程度，影响速度；特征尺度越大精细度越低、匹配越快；对比度阈值影响可建立的模板）。
  3. 建立模板后设置运行参数：最小匹配分数、匹配个数、匹配极性、角度范围尺度范围等（最小匹配分数越高越严格；匹配个数允许多个时默认取分数最高项；匹配极性指模板与背景过渡亮暗是否一致；角度范围越大匹配越慢）。不满足时调高级参数：最大重叠率（多目标允许重叠）、延拓阈值（目标位于图像边缘匹配不全时用）。
  4. 增加**位置修正模块**，连线连接，参数默认，点击一次执行→创建基准。
  5. 增加**亮度检测模块**，连线连接，设置 ROI（检测区域1 亮度判有无）。
  6. 增加 **Blob 分析模块**，连线连接，设置 ROI（检测区域1 较亮区域面积判外观完整性），并按实际设运行参数。
  7. 增加**条件检测模块**，连线连接，订阅需判断的参数并设置有效值范围。
  8. 增加**直线查找模块**，连线连接，按待查直线设 ROI；设运行参数：边缘类型（想找的直线特征）、边缘极性（搜寻方向灰度变化）、边缘阈值（梯度阈值）、滤波尺寸（抗噪，越大抗噪越强但可能滤掉真边缘）、卡尺数量（找点数量）、剔除点数（拟合时排除的最少点数，结合剔除距离）。高级参数：剔除距离（离群点到直线最大像素距离）、投影宽度（扫描 ROI 宽度）、初始拟合（一般全局拟合）、拟合方式。
  9. 增加**直线查找模块与圆查找模块**，参照直线查找过程查圆。
  10. 增加**格式化模块**，配置输出内容（注意输出为像素距离，实际需乘以每像素代表的实际物理尺寸）。
  11. 增加**发送数据模块**，选通信方式（以 TCP 为例，默认视觉软件为服务端，选通信设备；TCP 服务端需在快捷栏通信管理中配置），将检测状态与测量值发上位机。
- **关键配置 / 参数**
  - 高精度匹配：最小匹配分数、匹配个数、匹配极性、角度范围尺度范围；高级：最大重叠率、延拓阈值。
  - 直线查找：边缘类型 / 边缘极性 / 边缘阈值 / 滤波尺寸 / 卡尺数量 / 剔除点数 / 剔除距离 / 投影宽度 / 初始拟合（全局拟合）/ 拟合方式。
  - 格式化：输出像素距离，需乘物理尺寸换算。
- **误差/精度要点 / 注意事项**
  - 问题根因：不熟悉 VM 做项目的流程。
  - 拍照位与标定工作距离须保持不变；特征点须稳定。

## 2.2.2 图像检索：使用 VM 深度学习功能实现模型训练与图像检索功能

- **场景 / 目标**
  - 环境：VM4.0.0 及以上。
  - 需求：用 VM 深度学习工具自己训练模型实现图像检索。
- **方案思路**
  - 图像检索 = 图像表示学习（网络提取特征向量）+ 分类器注册（特征向量入分类器）。
  - 与图像分类区别：分类是直接训固定类别数的分类器；检索是训一个表示模型，再针对不同检索库注册不同分类器（避免每库重训网络，提升泛化）。
- **实施步骤**
  1. **打标签**：用 VMTrain 1.4.0 打标签（添加图片单张打标 / 添加文件夹批量打标）。
  2. **模型训练**：三种环境可选 —— 本地训练（需支持深度学习加速的 NVIDIA 显卡 + CUDA）、云服务器训练、本地服务器训练。参数：训练迭代次数（按数据量调）、基础学习率（控收敛速度）、版本、剪枝比例（模型压缩，权衡性能与精度）、数据增强（扩数据集防过拟合）。训练完在指定文件夹生成 `bin` 文件（模型权重）。
  3. **注册图像**：在 VM 中用 **DL 图像检索模块** → Gallery 管理 → 注册图像（单张或按文件夹注册；不同检索库可注册不同 Gallery，执行时加载 `gall` 文件）。
  4. **图像检索**：主要用 DL 图像检索模块；参数需加载训练好的模型文件（`bin`）和注册好的 Gallery 文件（`gall`）。
  5. 查看**检索结果**。
- **关键配置 / 参数**
  - 训练参数：训练迭代次数、基础学习率、版本、剪枝比例、数据增强。
  - 检索参数：模型 `bin` 文件 + Gallery `gall` 文件。
- **误差/精度要点 / 注意事项**
  - 问题根因：不熟悉 VM 深度学习训练工具的使用。

## 2.2.3 字符识别：使用 VM 进行字符识别

- **场景 / 目标**
  - 环境：VM4.0.0。
  - 需求：对铭牌上的字符进行识别，并将识别出的字符发送给上位机。
- **方案思路**
  - 先用高精度匹配 + 位置修正粗定位，再二值化 + 形态学去干扰，最后用字符识别模块训练字符库并识别；输出用 TCP 发送数据。
- **实施步骤**
  1. 增加**图像源模块**（本地图像）。
  2. **高精度匹配 + 位置修正**粗定位：高精度匹配设图像源→特征模板创建（掩膜选区域）；位置修正参数默认，一次执行→创建基准。本例运行参数：最小匹配分数 **0.5**、最大匹配个数 **1**、匹配极性 **考虑极性**、角度范围 **-20 到 20**、尺度范围 **0.98 到 1.02**、高级默认。
  3. 增加**图像二值化模块**（图像源输入，绘 ROI，运行参数自动二值化）便于字符分割。
  4. 增加**形态学处理模块**（图像源输入，绘 ROI）：开运算/腐蚀断开边界粘连，闭运算/膨胀闭合间隙；形态学形状即结构元素形状，结果轮廓相近。
  5. 增加**字符识别模块**（形态学输出为输入，绘 ROI），运行参数点击**字符训练**：框选字符区域，设距离阈值（字符片段到文本基线距离，超则不被提取）、字符间隙（两字符最小横向间距）；点提取字符→被红框分割；点训练字符→填字符→添加至字符库。
  6. 开启**字符过滤**（以开启为例）：识别字符个数、字符类型。
  7. 设运行参数：白底黑字 / 黑底白字；字符宽度范围与高度范围 **[1,512]**（按实际设）；宽度类型（等宽 / 可变）；片段面积（单字符允许像素面积范围）；合格阈值（可识别最小得分）。
  8. 高级参数（必要时）：距离阈值（到基线距离，超则删除）、忽略边框（是否忽略与 ROI 粘连字符）、主方向范围（文本行倾斜搜索范围）、倾斜角范围（允许字符最大倾斜）、最大宽高比（单字符外接矩形最大宽高比）、字符滤波使能、笔画宽度范围（开宽度滤波后生效）。
  9. 增加**发送数据模块**（TCP，视觉软件服务端，通信设备；服务端在通信管理配置），发送识别字符。
- **关键配置 / 参数**
  - 高精度匹配：最小匹配分数 0.5、最大匹配个数 1、匹配极性 考虑极性、角度 -20~20、尺度 0.98~1.02。
  - 字符识别：距离阈值、字符间隙、识别字符个数、字符类型、白底黑字/黑底白字、字符宽高范围 [1,512]、宽度类型（等宽/可变）、片段面积、合格阈值、高级（主方向范围、倾斜角范围、最大宽高比、笔画宽度范围等）。
- **误差/精度要点 / 注意事项**
  - 问题根因：不熟悉 VM 字符识别模块的使用。

## 2.2.4 联合开发：VM 脚本联合 OpenCV 开发

- **场景 / 目标**
  - 环境：VM4.0.0 + VS2015 及以上。
  - 需求：在 VM 脚本模块中调用 OpenCV（OpenCvSharp）进行图像处理。
- **方案思路**
  - 先配置 OpenCV 三方库引用并修复 `OpenCvSharpExtern.dll` 引用失败；再在脚本中实现 VM `ImageData` 与 OpenCV `Mat` 的互转，即可调用 OpenCV 函数。
- **实施步骤**
  1. 双击打开**脚本模块**。
  2. 点击「**编辑程序集**」按钮。
  3. 点击添加，将 VM 安装路径下三方库中的 OpenCV 动态库全部选中并加入引用。
  4. 因 `OpenCvSharpExtern.dll` 引用失败，需将其**手动拷贝到 VM 脚本模块依赖目录**。
  5. 在脚本中添加 OpenCV 的命名空间。
  6. 实现 `ImageData` ↔ `Mat` 转换：设置输入/输出变量（类型均为 IMAGE）；引用 `System.Runtime.InteropServices`；将输入 `ImageData` 转 `Mat`、设 ROI 调 OpenCV 接口、再转回 `ImageData` 输出。
- **关键代码**（C#，逐字保留）

```csharp
//实例化ImageData 类型图像
ImageData img = new ImageData();
GetImageValue("in0", ref img);
ImageData imgOut = new ImageData();
Mat srcImage = Mat.Zeros(img.Heigth, img.Width, MatType.CV_8UC1);

Rect rect = new Rect(0, 0, 300, 300);

if (img.PixelFormat == ImagePixelFormate.MONO8)
{
     //开辟内存空间
     IntPtr grayPtr = Marshal.AllocHGlobal(img.Width * img.Heigth);
     //向内存空间中写入数据
     Marshal.Copy(img.Buffer, 0, grayPtr, img.Buffer.Length);

     //imagedata 转Mat
     srcImage = new Mat(img.Heigth, img.Width, MatType.CV_8UC1, grayPtr);
     //设置ROI
     Mat imageROI = new Mat(srcImage, rect);
     Mat dstImage = Mat.Zeros(imageROI.Height, imageROI.Width, MatType.CV_8UC1);
     //调用OpenCV 中的接口进行图像处理
     Cv2.Threshold(imageROI,dstImage,10,120,ThresholdTypes.Otsu);
     //将处理后的图像拷贝到原图ROI 区域
     dstImage.CopyTo(imageROI);

     byte[] datab = new Byte[srcImage.Width * srcImage.Heigth];

     //mat 转ImageData
     srcImage.GetArray(0, 0, datab);
     imgOut.Buffer = datab;
     imgOut.Width = srcImage.Width;
     imgOut.Heigth = srcImage.Height;
     imgOut.PixelFormat = ImagePixelFormate.MONO8;

     //用完记得释放指针
     Marshal.FreeHGlobal(grayPtr);
}
SetImageValue("imageOut", imgOut);
```

- **误差/精度要点 / 注意事项**
  - 问题根因：不熟悉 VM 脚本联合 OpenCV 开发的方法。
  - 提示：鼠标选中脚本模块，按 **Ctrl+M** 快捷键可直接跳转到脚本模块目录。

## 2.2.5 联合开发：VM 脚本联合 OpenCV 实现轮廓查找

- **场景 / 目标**
  - 环境：VM4.0.0 + VS2015 及以上。
  - 需求：利用 VM 脚本联合 OpenCV 实现轮廓查找与绘制。
- **方案思路**
  - 采集灰度图 → 脚本获取海康 `ImageData` → 转 `Mat` → `Canny` 边缘检测 + `FindContours` 轮廓查找 → `DrawContours` 绘制（彩色需先 `CvtColor` 转 RGB）→ 转回 `ImageData` 输出（`MONO8` 或 `RGB24`）→ 释放内存防泄漏。
- **实施步骤**
  1. 采集灰度图。
  2. 脚本获取海康图像内存对象：`ImageData img = new ImageData(); GetImageValue("in0", ref img);`
  3. `ImageData` 转 `Mat`（MONO8 分支开辟内存、拷贝、`new Mat(...)`）。
  4. 依次 `Cv2.Canny(srcImage, dstImage, 90, 230)` 与 `Cv2.FindContours(dstImage, out contours, out hierarchy, RetrievalModes.Tree, ContourApproximationModes.ApproxSimple, new Point(0, 0))`。
  5. 绘制轮廓（灰度图绘制时先 `CvtColor` 到 RGB，再 `Cv2.DrawContours(dstImageRGB, contours, i, color, 2, LineTypes.Link8, hierarchy)`）。
  6. `Mat` 转 `ImageData` 输出；彩色时数据数组大小为 宽*高*3，像素格式 `RGB24`。
  7. `Marshal.FreeHGlobal(grayPtr)` 释放内存。
  8. `SetImageValue("imageOut", imgOut)` 输出。
- **关键代码**（C#，完整脚本，逐字保留）

# 三、定位引导专题（输入2：PDF 996–1070）

## 2.2.1 常规定位引导项目入门必看

- **场景 / 目标**
  - 适用场景：单相机拍物料的抓取场景。
  - 标定方式：**工具中心与旋转中心（一般为法兰中心）共轴** → 九点标定（单相机与机构做平移标定，9 点标定）；**不共轴** → 十二点标定。
  - 限制条件：不支持多相机联立坐标系、相机拍照位姿变化等场景。
- **机构及成像质量调整**
  - 硬件安装：机构安装稳固不松动；镜头平面与物料平面平行；网线用海康网线安装稳固；电源线用高柔电缆；镜头光圈先拧到底再反拧半圈（兼顾景深与锐利度）。
  - 系统要求：Win10 64bit；处理器 I5 以上 CPU。
  - 成像质量：调焦距保证清晰（图像边缘过渡带不超过两个像素）；特征处于图像正中心（边缘易径向畸变）。
  - 机构精度：
    - 静态测试：拍照位与物料静止连续拍照，特征点提取稳定在 **1 像素以内**，否则换更稳定特征点。
    - 动态测试：平移精度——物料不动，机械手沿 X/Y 正负等步长移动 4 次得三组像素差，保证 **1 像素以内**；每次回原位看平移复位精度（特征点坐标须 1 像素以内）。旋转精度——正反旋转一定角度（与标定角度相当），图像特征角度等角度变化（一般 **0.1 度以内**），回原位看复位精度（1 像素以内）。
    - 点位移动测试：VM 通讯发送绝对坐标给机械手，确保能移动到指定点位。
- **搭建定位引导视觉方案**
  - **3.1 标定方案**：含图像特征点提取、通讯触发及协议解析（触发流程+解析机械手物理坐标）、平移旋转标定模块、发送数据（回复标定状态）。
    - 3.1.2 **高精度模板匹配**：提取特征点，同一位置定位精度保持 1 像素以内，角度稳定 0.1 度以内。
    - 3.1.3 **平移旋转标定模块**：平移次数默认 9；旋转次数一般设 3。
  - **平移旋转标定参数表**：
    - 标定类型：平移标定（旋转中心在工具中心）/ 平移旋转标定（不共轴，增加旋转中心标定）。
    - 标定点获取：触发获取（通常）/ 手动输入（支持模块单独运行生成矩阵）。
    - 相机模式：相机静止 / 相机运动。
    - 自由度：透视变换（缩放、旋转、纵横比、倾斜、平移及透射）、仿射变换（缩放、旋转、纵横比、倾斜及平移）、相似性变换（缩放、旋转及平移）。
    - 标定点输入：按点 / 按坐标。
    - 图像点：可订阅其他模块的点。
    - 物理点：机械臂坐标点，可订阅通讯输入。
    - 图像角度 / 物理角度：可订阅/计算；旋转一致性、左右手坐标系（平移旋转标定时显示）。
    - 平移次数：一般 9 点；旋转次数：不共轴设 3，且旋转在第 5 个点位置进行。
    - 组合标定：开启后支持平移后旋转并平移回视野（小视野场景旋转中心拟合不准时用，对平移精度要求较高）。
    - 更新文件 / 标定文件路径 / 示教 / 外部输入字符 / 外部触发字符：见原文参数表。
    - 标定输出结果：标定状态（1 成功 / 0 失败）、平移估计真实误差、旋转真实平均误差。
  - **3.2 创建通讯设备及全局触发**：通信管理添加设备，全局触发建触发事件，实现机械手通信触发视觉流程。
  - **3.3 标定**：
    - 3.3.1 机械臂带动相机按设定方向/步长移动，每次移动触发标定流程；九点移动 9 次，十二点先按九点移动、最后 3 点在第五点基础上按设定角度旋转 3 次。
    - 3.3.2 结果查看：标定轨迹（X/Y 轴垂直、三点共线、无波动）；标定状态（1/0）；像素精度——平移像素精度一般 **1 像素以内**，旋转像素精度 **0.5 像素以内**；旋转一致性（1 一致 / -1 相反，判断错需重标）。
  - **3.4 示教**（可与生产流程共用）：放物料→调机构对准（记录示教物理点）→移拍照位（示教拍照物理点）拍照得像素坐标→在**单点抓取模块**创建基准（填示教抓取物理点、绑定基准图像像素点，可绑定为运行图像点）。
  - **3.5 生产**：
    - 3.5.1 生产拍照位最好与标定第五点拍照位一致，可 X/Y 偏移，但拍照姿态（相机旋转角度）必须不变；工作距离必须不变。
    - 3.5.2 生产方案同示教，特征点须一致。
    - 3.5.3 **单点抓取模块**：输入方式（平移标定↔九点、平移旋转标定↔十二点；按点/按坐标，可订阅或手输）；像素点需基准点+运行点（基准点示教已填，生产绑运行图像点）；示教抓取物理坐标、示教拍照物理坐标须正确，加载正确标定文件。
    - 3.5.4 运行取偏差：结果分相对/绝对坐标（绝对坐标=抓取位置）；用格式化模块订阅偏差值，发送数据模块发给机械手。

## 2.2.2 单点抓取：单相机常规抓取场景

- **方案思路**
  - 整个应用分**标定、示教、生产（求偏差）**三部分，依次进行。标定建立图像坐标系↔物理坐标系转换矩阵。

  - **2.3 生产**

## 2.2.4 单点映射对位：上下相机映射对位场景

- **实施步骤**
  - **2.1 标定（步骤一）**
    - 标定方式：下相机——共轴九点 / 不共轴十二点；上下相机——有标定板用标定板映射，无标定板用物料做相机映射。

    - 2.1.2 创建通信触发：通信管理添加设备，全局触发建事件，PLC 触发视觉。
    - 2.1.3 下相机平移旋转标定流程：[7] 机械手吸取标定片/物料移下相机视野；[8] Z 字形等间距平移 9 次（角度固定），每次发物理坐标（如 `C1,5,5,0`）触发拍照；[9] 回第五点顺/逆时针旋转 3 次（XY 固定）。结果：标定状态、平移/旋转像素平均误差（一般 1 像素以内）、角度旋转一致性（1/-1，错则重标）；正常生成标定文件。
    - 2.1.4 上下相机映射标定流程：1) 放标定物料于上相机视野（上下相机拍不同面须同时拍到 ≥ 4 个不共线特征点）；2) 上相机拍照位拍照；3) 移动机械手抓物料，记录物理坐标（示教物理点）；4) 抓物料平移到下相机视野，下相机拍照；5) 搭建映射标定流程（左右为上下相机一一对应特征点，用**相机映射模块**得两相机映射矩阵）；6) 生成映射标定文件。
  - **2.2 示教（步骤二）**：记录映射标定时吸取物料的物理坐标（示教物理点），填入**单点映射对位模块**。
  - **2.3 生产（步骤三）**
    - 2.3.1 下相机拍照流程：提取对象特征点和直线角度传给**全局变量**供上相机使用。
    - 2.3.2 上相机拍照流程：上相机拍照位最好与标定第五点一致（可 X/Y 偏移，拍照姿态不变，工作距离不变）；生产时上相机提取的对象特征点与下相机目标特征点一致、直线查找方向一致。
    - 2.3.3 单点映射对位模块配置：对象像素点订阅下相机传全局变量的特征点；目标像素点订阅上相机提取的特征点；目标直线起点终点订阅上相机提取的直线起点终点；加载上下相机映射标定文件。
    - 2.3.4 实际生产：机械手抓物料移下相机拍照位触发下相机流程；移上相机拍照位触发上相机流程；单点映射对位模块结果分相对/绝对坐标（绝对坐标=抓取位置）；格式化订阅坐标值，发送数据给机械手按绝对坐标引导定位。

## 2.2.6 定位引导：汽车挡风玻璃多相机对位组装案例

- **场景 / 目标**
  - 环境：VM4.0.0。
  - 需求：汽车挡风玻璃对位组装。玻璃放工装（定位精度 ±2mm），车身放夹具（±2mm）；玻璃用两个下相机定位，车身用两个上相机定位。机械手抓玻璃移到固定下相机上方，两下相机拍玻璃两处特征（轮廓、定位销等），算出玻璃与基准偏差 A；机械手带玻璃移到车身附近，两上相机拍车身两处特征，算出车身偏差 B；最终装配点坐标/位置偏差目标精度 **±0.2mm**。
- **方案思路**
  - 场景拆为下相机玻璃纠偏 + 上相机车身放置；总偏差 = 玻璃偏差 + 车身偏差。
  - 两下相机拍玻璃两位置边缘角点，算运行位置与基准位置偏差；两上相机拍车身两位置圆形特征点，算车身偏差；各自取两特征点中点与连线角度作为偏差计算的特征点与特征角度。
  - 法兰盘中心与抓取中心不共轴 → 全部用**平移旋转（12 点）标定**；共需 4 次 12 点标定（上相机 2 + 下相机 2）。
- **实施步骤**
  1. **标定**：4 次平移旋转（12 点）标定（上相机两次 + 下相机两次）。
  2. **通信协议设计**（TCP）：
     - 标定协议：开始标定 `SC`（清空 N 点标定模块数据、确认通信正常）、标定 `C`（上位机每发一次信号机械手走一次并返回拍照状态）、结束标定 `EC`。
     - 生产协议：基准拍照 `B`（获取基准位置特征点坐标）、运行拍照 `R`（获取运行位置特征点坐标，上相机车身处算总偏差返回上位机）。
  3. **对位算法原理**（基准与运行时拍照位不变）：
     - 总偏差 `Offset = UpOffset + DownOffset`
     - 下相机玻璃偏差（绕旋转中心旋转 DR 后坐标偏差）：
       `RotateX = (DownrunWorldX – RotateCenterX)*Cos(DR) – (DownrunWorldY – RotateCenterY)*Sin(DR) + RotateCenterX`
       `RotateY = (DownrunWorldX – RotateCenterX)*Sin(DR) + (DownrunWorldY – RotateCenterY)*Cos(DR) + RotateCenterY`
       `DownOffset = DownmarkWorld – Rotate`
     - 上相机车身偏差 = 平移偏差 + 旋转偏差：`UpOffset = UpTransOffset + UpRotateOffset`
       `UpTransOffset = UprunWorld – UpmarkWorld`
       上相机基准坐标 = 基准图像转物理坐标 + 第五点拍照位：`UpBaseWorld = UpmarkWorld + Snap`
       旋转偏差量 `UpRotateOffset`（示教位 `TeachWorld`）：
       `RotateX = (TeachWorldX – UpBaseWorldX)*Cos(DR) – (TeachWorldY – UpBaseWorldY)*Sin(DR)`
       `RotateY = (TeachWorldX – UpBaseWorldX)*Sin(DR) + (TeachWorldY – UpBaseWorldY)*Cos(DR)`
       `UpRotateOffset = Rotate – TeachWorld`
  4. **方案搭建**：共搭 **6 个流程** —— 前 4 个为四个相机标定流程（CalibDown1、CalibDown2、CalibUp1、CalibUp2），后 2 个为运行流程（DownRun、UpRun）。
     - DownRun 计算运行时下相机玻璃与基准位置偏差；UpRun 计算运行时上相机车身与基准位置偏差，并与 DownRun 的下相机偏差相加得最终偏差量与定位坐标。
     - CalibDown1 作用：对下相机1 标定，每步实时返回标定状态；发送数据模块 73 返回 N 点标定模块状态，56/57 返回标定开始与结束标志位。
     - 高精度匹配模块参数参考 FAQ 1.5.2，N 点标定模块参数参考 FAQ 1.5.1。
     - 全局触发配置参考 FAQ 1.3.2。
- **误差/精度要点 / 注意事项**
  - 问题根因：对定位原理以及 VM 做定位项目的流程不熟悉。
  - 提示：平移旋转（12 点）标定原理与标定方式选取标准参考 FAQ 1.5.1。
