# 设计窗口概览

运行界面设计窗口用于自定义配置运行界面，本文为您介绍设计窗口各区域功能及说明。

单击主界面工具条中的![](GUID-434D257F-C302-48B3-9F61-79C1EC2198DD-high.png)可进入运行界面设计窗口。

![](GUID-96558FEA-21F5-4A9C-B051-32B7FFAACE3E-high.png)

图 1 运行界面设计

该界面各区域的说明参见下表：

表 1 运行界面设计窗口介绍

| 名称 | 描述 |
| --- | --- |
| 工具条 | 提供运行界面保存、模板设置、图层设置、删除、固定栏设置、导出等功能，详情参见工具条介绍。 |
| 控件区 | 呈现可在运行界面上使用的控件，详情参见控件配置参考。 |
| 预览及编辑区 | 呈现当前设计中的运行界面。可绘制新的控件，或编辑当前已添加的控件，具体如何操作参见控件通用操作。 |
| 属性设置区 | 展示预览及编辑区选中画布、固定栏及控件的属性（例如布局、数据源、颜色、字体等），并进行设置。 |

## 工具条介绍

工具条可设置如下功能：

* ![](GUID-9BDB4E9B-7084-41D8-B3F2-8132035121EF-high.png)：加载已保存的运行界面。
* ![](GUID-B3A5B501-9CEC-4748-BC4C-3CEE33DE9AB8-high.png)：保存当前设计的运行界面。若为首次保存，需选择保存路径。
* ![](GUID-3983D673-6E69-4E4C-B1AD-7F55BFE78EC4-high.png)：可选择已保存的运行界面模板进行应用或删除。
* ![](GUID-21463D14-0B1B-496E-8D31-2FB1B543C083-high.png)：可将当前设计的运行界面作为模板保存。保存时，需填写名称、创建人、推荐使用场景和描述，并点击确定。
* ![](GUID-BB0A0DEA-561B-4A09-8827-47D0EE4A6A7F-high.png)：可对预览及编辑区中选中的控件设置图层位置，分别对应顶层、上一层、底层、下一层。
* ![](GUID-CDC41464-7FFA-4C7E-9F85-881CAAE4DB3B-high.png)：预览及编辑区域选中多个控件时，以选中控件组成的区域为基准对选中控件的对齐方式进行调整。可选左对齐、水平居中、右对齐、顶部对齐、垂直居中、底部对齐。
* ![](GUID-86503A63-DAA6-45F4-BA12-466E93BC3B2D-high.png)：预览及编辑区域选中多个控件时，以选中控件组成的区域为基准对选中控件的分布方式进行调整。可选水平分布和垂直分布。

  说明

  水平/垂直分布需选择3个以上的控件，才起作用。对应的效果分别为水平/垂直方向控件等间隔分布。其余选项选择2个以上控件即可。
* ![](GUID-E0EC584A-9BE4-469A-B01A-A79927DD3818-high.png)：撤销最近一次操作。
* ![](GUID-D2F4DCA5-5AD6-4E93-9B83-A4ADB059EDCF-high.png)：取消撤销操作，恢复至撤销前的状态。
* ![](GUID-99DAFFEA-D680-4E08-98EE-E00C8FF25BBC-high.png)：删除预览及编辑区域选中的控件。
* ![](GUID-12A8086D-E091-40B0-B0D2-31FB75FF06D5-high.png)：可将预览及编辑区中的运行界面窗口相对于预览及编辑区按照合适比例进行大小调整。

  说明

  打开运行界面设计窗口时，默认调用一次该功能。后续可在调整窗体宽/高后，使用该功能。
* ![](GUID-ECF58E6D-6E60-434D-8448-22C973048388-high.png)：可通过拖动滑块调整预览及编辑区域中运行界面的大小。
* ![](GUID-F615E1C4-21B8-4CFE-92F1-B848C14F14C0-high.png)：可设置是否在运行界面增加顶部、底部、左侧和右侧固定栏。点击勾选即可，可同时选择多个位置的固定栏。
* 预览：可预览当前设计的运行界面。
* 导出：可将VM当前编辑的方案以及设计的运行界面以工程包的形式导出。详情参见导出运行界面并运行。

说明

* 其中删除、撤销、重做、图层位置功能也支持在选中控件后通过鼠标右键实现；
* 复制粘贴功能仅支持在选中控件后通过Ctrl+C和Ctrl+V实现。
* ![](GUID-3983D673-6E69-4E4C-B1AD-7F55BFE78EC4-high.png)、![](GUID-21463D14-0B1B-496E-8D31-2FB1B543C083-high.png)和![](GUID-F615E1C4-21B8-4CFE-92F1-B848C14F14C0-high.png)功能仅型号中带6210或7120的加密狗支持使用。
