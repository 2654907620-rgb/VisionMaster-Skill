# 点集

点集工具可以将其他模块输出的相关数据组合为点的集合，便于后续模块获取及传输。

本节内容包含：

* 使用方法
* 参数配置
* 模块结果

## 使用方法

点集模块支持点或者坐标输入，可开启循环使能放入循环模块使用，搭配Group模块做点的汇集。后续模块可搭配图形拟合工具，通过点集输出一组特征点，图形拟合根据其拟合直线、圆、椭圆等形状。

该示例通过输入两个圆查找模块的圆心点，再通过点集模块输出两个圆心点的集合。

## 参数配置

点输入
:   选择按点或者按坐标输入其他模块的点数据，比如圆心点、顶点。最多仅支持添加16项点数据。

循环使能
:   开启后，会将每次循环得到的点集添加到输出点集中。

## 模块结果

点集模块的模块结果具体如下：

耗时（ms）
:   float型，代表该模块运行时耗费的时间。

点集
:   点X
    :   float型，代表点集X坐标。

    点Y
    :   float型，代表点集Y坐标。

模块状态
:   int型，0代表NG，此时模块呈现红色；1代表OK，此时模块呈现绿色。
