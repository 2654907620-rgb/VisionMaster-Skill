# 运行入门级方案

完成“电池片检测”入门级方案搭建之后，即可运行该方案，并查看该方案运行效果。

1. 在主界面的快捷工具条上单击![](GUID-9EF5906E-6C4E-4560-B533-2588A90347EE-high.png)/![](GUID-4A738645-CD93-4392-A1A7-CF6C3E367B5C-high.png)单次试运行或连续试运行方案。

   若运行效果欠理想，继续调整流程和模块配置，直至方案运行效果达到预期。

   注意

   快捷工具条上的![](GUID-9EF5906E-6C4E-4560-B533-2588A90347EE-high.png)/![](GUID-4A738645-CD93-4392-A1A7-CF6C3E367B5C-high.png)与流程页签上![](GUID-0AF5B488-0721-40F5-A830-3105A0A26CFA-high.png)/![](GUID-ED1B370F-63FB-41D1-A2F1-0DD6717814BA-high.png)分别用于运行方案和流程，请勿混淆。
2. 在菜单栏选择文件 > 保存方案或文件 > 方案另存为保存方案。
3. 单击主界面右上角的运行模式，切换至已在步骤三：设计运行界面中设计完成的运行界面。
4. 在运行界面单击![](GUID-9EF5906E-6C4E-4560-B533-2588A90347EE-high.png)/![](GUID-4A738645-CD93-4392-A1A7-CF6C3E367B5C-high.png)运行方案。

   ![](GUID-B791BE3D-C6C7-46CA-B81B-DC5B060BE88E-high.png)

   图 1 运行界面

   至此，您已完成入门级方案——“电池片检测”的运行。若需了解方案运行更为高阶的功能，请参见方案调试与运行及其子章节。
