# 程序集添加

全局脚本默认已添加VM二次开发需要的基础类库。如需调用其他类库的程序集，可自行添加。如果程序集无需再调用，可自行删除。

说明

仅支持添加C#程序集。如需调用非托管库（如C++库），请参见第三方库调用方法。

1. 在全局脚本窗口单击![](GUID-F550A20B-B694-4C29-BAB3-78D5862F45C7-high.png)打开引用程序集窗口。

   ![](GUID-89B7761A-FDF1-4CF6-A0FF-FDAF26EF5660-high.png)

   图 1 引用程序集窗口

   说明

   VM二次开发基础类库（如上图所示）的调用方法，请参见算法开发平台SDK开发指南。
2. 单击添加，选择本地路径添加所需的程序集。

   如需添加4.x版本新增模块的类库的程序集，可从VM安装路径下的Assembly文件夹添加，该文件夹的相对路径：.\Development\V4.x\ComControls\Assembly。

   ![](GUID-B9AEF262-20DA-4090-8B29-14BE0EE9D27E-high.png)

   图 2 4.x版本模块类库的程序集
3. **可选操作：**
   单击![](GUID-FD4135BE-9FCB-425C-94B8-0700AECE365F-high.png)将对应的程序集从全局脚本中删除。
4. 单击确定。
