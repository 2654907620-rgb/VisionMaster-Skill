# 查看模块结果

图像显示区域的模块结果页签显示所选模块或所选流程的输出数据。

* 在模块结果页签选中该模块某个输出参数后，下方将显示SDK中与该输出参数对应的信息，如下图所示。其中`VmSolution.Instance`表示方案实例，`BlobNum`即blob个数。可单击![](GUID-72D1B3A1-6192-4C03-B926-9711B2C5A840-high.png)复制该信息，用于二次开发的结果获取。

  ![](GUID-2586F676-E514-4BAD-9142-13C477731CC5-high.png)

  图 1 SDK中的对应等信息
* 可单击变量管理列的![](GUID-DA244A4F-8CC1-4012-B3E0-4FDABE1BAAFA-high.png)选择全局/局部变量，将其与对应的结果数据绑定。
