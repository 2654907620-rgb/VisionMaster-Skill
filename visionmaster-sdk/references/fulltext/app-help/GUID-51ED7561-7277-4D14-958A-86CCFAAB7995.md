# 缓存图像

缓存图像模块可用于方案功能调试，特别是在某些样本图像出现误判时，通过缓存图像功能，可将图像临时存储，以便在后续调试过程中快速绑定和重新处理，而不需要每次都重新加载原始图像。

## 模块原理

该功能使能时流程运行一次可缓存一张图像，最多缓存15张。按照时间顺序，缓存区存满后，最新缓存图像从下方进入缓存区，并将缓存区内最早保存的图像覆盖掉，其余图像位置上升一位。以缓存5张图为例，覆盖逻辑如下图所示。后续处理模块的数据源可以绑定15张缓存图像的任意一张，便于追溯方案调试过程。

## 参数配置

输入源
:   需要订阅前序模块输出的图像数据。

缓存使能
:   0代表不使能，1代表使能。数据订阅仅限int型数据，当没有数据绑定时默认使能。

缓存数量
:   缓存图片的数量，可直接自定义输入也可绑定，仅限int型数据。

## 模块结果

缓存图像模块的模块结果具体如下：

耗时（ms）
:   float型，代表该模块运行时耗费的时间。

模块状态
:   int型，0代表NG，此时模块呈现红色；1代表OK，此时模块呈现绿色。

输出图像\*（\*代表0~14）
:   输出图像\*数据
    :   image型，代表每张输出图像的图像数据。

    输出图像\*宽度
    :   int型，代表每张输出图像的图像宽度。

    输出图像\*高度
    :   int型，代表每张输出图像的图像高度。

    输出图像\*格式
    :   int型，代表每张输出图像的像素格式。其中17301505对应Mono8格式，35127316对应RGB24格式。
