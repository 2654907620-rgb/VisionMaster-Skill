# 配置HKR采集卡连接的相机

先选择采集卡再选择相机即可连接相机。

连接相机后，可设置相关参数。

配置文件
:   可将相机的参数以hcf文件形式导入，从而修改相机相关参数。

    说明

    hcf文件通过采集卡客户端导出属性的方式生成。

图像宽度

图像高度
:   可分别查看并设置相机采集图像的宽度/高度。

脉冲数
:   可读取相机设置的脉冲数情况。

触发源
:   按需选择相机出图的触发源。

触发选择器
:   可选FrameBurstStart（帧触发）或LineStart（行触发）。

    说明

    面阵相机只有帧触发选项。

触发模式
:   设置是否开启触发模式。
