# 边缘学习

边缘学习是深度学习方法延伸出来的一种应用，基于大模型思想解决深度学习中的小样本问题，从而大幅降低常规深度学习任务对数据的需求量。边缘学习一般只需注册少量下游任务数据，即可完成深度学习任务，实现简单的图像分类、目标检测及图像分割等功能。
