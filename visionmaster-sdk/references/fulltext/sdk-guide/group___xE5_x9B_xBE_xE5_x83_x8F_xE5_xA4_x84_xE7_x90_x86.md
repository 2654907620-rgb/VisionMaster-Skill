# 图像处理

图像处理可对目标图像进行图像预处理，使特征更明显。
更多...

|  |  |
| --- | --- |
| 模块 | |
|  | 图像二值化 |
|  | 图像二值化可将图像上点的灰度置为0或255，使整个图像呈现出明显的黑白效果。 |
|  | |
|  | 图像滤波 |
|  | 图像滤波可通过滤波预处理消除图像中混入的噪声，为图像识别抽取出图像特征。 |
|  | |
|  | 掩膜工具 |
|  | 掩膜工具可用于对图像进行形态学操作。该模块支持配置自定义ROI区域和屏蔽区，且可对原图进行基础位运算，包括计算其与其他掩模图片的交集、并集、差集和补集。 |
|  | |
|  | 形态学处理 |
|  | 形态学处理可从图像中提取出对表达和描绘区域形状有意义的图像分量，使后续的识别工作能够抓住目标对象最为本质的形状特征。主要针对图像中的白色像素点进行处理。 |
|  | |
|  | 图像增强 |
|  | 图像增强包括锐化、对比度调节、Gamma调节和亮度校正。增强图像中的有用信息，可改善图像的视觉效果。 |
|  | |
|  | 阴影校正 |
|  | 阴影校正可对输入的图像进行均值滤波，并与原图像对比得到图像残差，依据某种规律进行像素重置。主要用于对输入的光照不均匀图像进行光照校正。 |
|  | |
|  | 图像组合 |
|  | 图像组合可将形态学处理、图像二值化、图像滤波、图像增强和阴影校正这五种图像处理任意组合，对图像进行预处理后输出。 |
|  | |
|  | 图像归一化 |
|  | 图像归一化可对输入的图像进行灰度变换处理，使输入图像达到设定的灰度水平。 |
|  | |
|  | 图像运算 |
|  | 图像运算可对两张图像相同坐标像素的灰度值进行运算，得到新的图像。需配置两张大小一致的图像，且仅支持全图运算。 |
|  | |
|  | 图像修正 |
|  | 图像修正可通过预先设置基准点初始信息以及运行时检测到的基准点变动情况（位置和角度），对补正对象进行图像偏移修补，使修正后的图像和参考图像位姿一致。 |
|  | |
|  | 仿射变换 |
|  | 仿射变换具有“抠图”和缩放图像的作用。 |
|  | |
|  | 逆仿射变换 |
|  | 逆仿射变换需配合仿射变换使用，把仿射变换模块处理后的图像设置到指定图像中。 |
|  | |
|  | 图像缩放 |
|  | 图像缩放可对原图中的ROI区域根据设置的参数进行缩放并输出图像。 |
|  | |
|  | 几何变换 |
|  | 几何变换可用于图像的水平、垂直、水平垂直变换，配合一定角度可在镜像变换后再按照一定角度旋转整张图像。 |
|  | |
|  | 圆环展开 |
|  | 圆环展开可在指定的矩形区域内，进行圆弧展开操作。 |
|  | |
|  | 拷贝填充 |
|  | 拷贝填充可对ROI以及ROI最小外接矩形进行处理。拷贝可把ROI内的图像复制下来对ROI外且在最小外接矩形内的区域进行填充，填充只对ROI内以及ROI外且在最小外接矩形内进行填充。 |
|  | |
|  | 畸变校正 |
|  | 畸变校正通过加载畸变标定文件对图像进行校正，输出校正过的图像。 |
|  | |
|  | 图像矫正 |
|  | 图像矫正可对光学透镜造成的桶形畸变和枕形畸变进行矫正。 |
|  | |
|  | 图像拼接 |
|  | 图像拼接可将多张图像拼接成一整张图像。 |
|  | |
|  | 清晰度评估 |
|  | 清晰度评估可对指定图像进行清晰度的量化评价，可评判相机是否聚焦清晰。 |
|  | |
|  | 帧平均 |
|  | 帧平均可对多帧图像设置的相同大小ROI区域的像素进行均值计算处理，并输出该区域的均值图像。 |
|  | |
|  | 多图融合 |
|  | 多图融合可将多个方向打光生成的图片合成成一张图像，需配合多图采集使用。 |
|  | |

## 详细描述

图像处理可对目标图像进行图像预处理，使特征更明显。
