# 颜色处理

颜色处理可对方案中彩色图像进行颜色相关的检测。
更多...

|  |  |
| --- | --- |
| 模块 | |
|  | 颜色抽取 |
|  | 颜色抽取可将目标区域从彩色图像中分割出来，最终得到只包含目标物体的二值图。 |
|  | |
|  | 颜色测量 |
|  | 颜色测量可测量彩色图像指定区域的颜色信息，包括每个通道的最大值、最小值、均值、标准差和直方图信息。 |
|  | |
|  | 颜色转换 |
|  | 颜色转换可对彩色图像指定区域进行颜色空间转换，并输出该区域转换后图像的指定颜色通道灰度图像。 |
|  | |
|  | 颜色识别 |
|  | 颜色识别依靠颜色为模板进行分类识别，当不同类物体有着比较明显的颜色差异时颜色识别可实现精准的物体分类并输出相关的分类信息。 |
|  | |
|  | 颜色分割 |
|  | 颜色分割从图像中分割出配置的颜色范围，以灰度图和渲染图的方式输出。颜色范围可直接从图像中提取。 |
|  | |
|  | 彩图生成 |
|  | 彩图生成通过输入3通道Mono8的图，合成彩色图。 |
|  | |

## 详细描述

颜色处理可对方案中彩色图像进行颜色相关的检测。
