# 运算

运算可根据输入的目标点和对象点数据，得出对象点对位至目标点的移动量。部分模块输入的数据为物理坐标，需配合标定转换模块使用。

|  | 单点对位 |
|  | 单点对位可根据输入的目标点位置和方向、对象点位置和方向，计算出由对象点对位至目标点需要的移动量。 |

|  | 单点映射对位模块基于对象图像特征点与目标图像特征点坐标实现上下相机对位，输出相对坐标以及绝对坐标。 |
|  | |
|  | 单点纠偏 |
|  | 单点纠偏模块基于图像基准点与图像运行点坐标实现纠偏，输出相对坐标以及绝对坐标。 |

## 详细描述

运算可根据输入的目标点和对象点数据，得出对象点对位至目标点的移动量。部分模块输入的数据为物理坐标，需配合标定转换模块使用。
