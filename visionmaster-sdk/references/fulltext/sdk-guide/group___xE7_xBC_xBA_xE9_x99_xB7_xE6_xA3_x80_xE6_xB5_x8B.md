# 缺陷检测

缺陷检测可检测方案中图像的各类缺陷。
更多...

|  |  |
| --- | --- |
| 模块 | |
|  | 表面缺陷滤波 |
|  | 表面缺陷滤波用于检测图像中的缺陷信息，输出二值化图像。 |
|  | |
|  | 字符缺陷检测VA |
|  | 字符缺陷检测VA可将目标图像与标准图像进行验证对比，检测印刷字符、图案是否存在缺失、冗余等非一致性外观缺陷。主要应用于包装、印刷品、半导体等生产制造领域。 |
|  | |
|  | 异常检测 |
|  | 异常检测是可以训练出一个异常检测模型，利用该模型可以检测出目标图片是否OK或者NG。 |
|  | |
|  | 边缘模型缺陷检测 |
|  | 边缘模型缺陷检测可与标准的边缘模型进行对比，输出相关的缺陷信息。 |
|  | |
|  | 边缘对模型缺陷检测 |
|  | 边缘模型缺陷检测可与标准的边缘对模型进行对比，输出相关的缺陷信息。 |
|  | |
|  | 直线边缘缺陷检测 |
|  | 直线边缘缺陷检测可检测直线边缘有缺损或凹凸的情况，输出缺陷外接框的位置信息以及缺陷的大小信息。 |
|  | |
|  | 直线对缺陷检测 |
|  | 直线对缺陷检测可检测发生形变或断裂的一对直线之间的缺陷，输出相应的缺陷信息。 |
|  | |
|  | 圆弧对缺陷检测 |
|  | 圆弧对缺陷检测可检测圆弧的凹凸或断裂部分，查找两圆弧之间的缺陷区域，输出相关信息。 |
|  | |
|  | 圆弧边缘缺陷检测 |
|  | 圆弧边缘缺陷检测可检测圆弧边缘的凹点、凸点或断裂缺陷，可准确识别有缺陷的圆弧并输出缺陷信息。 |
|  | |
|  | 边缘组合缺陷检测 |
|  | 边缘组合缺陷检测可组合多个边缘缺陷检测工具，包括直线和圆弧边缘缺陷检测。 |
|  | |
|  | 边缘对组合缺陷检测 |
|  | 边缘对组合缺陷检测可组合多个边缘对缺陷检测工具，包括直线对和圆弧对边缘缺陷检测。 |
|  | |
|  | 边缘位置趋势分析 |
|  | 边缘位置趋势分析可检测图像中边缘的位置信息。 |
|  | |
|  | 边缘对位置趋势分析 |
|  | 边缘对位置趋势分析可分析图像中边缘对之间的信息，例如距离。 |
