# 深度学习

深度学习通过类似脑神经网络的深度学习模型，让计算机像人一样在真实世界中吸收、学习和理解复杂信息，完成高难度的识别任务。 深度学习需要一定的数据基础，因此在深度学习前需训练大量的数据集。

## 详细描述

深度学习通过类似脑神经网络的深度学习模型，让计算机像人一样在真实世界中吸收、学习和理解复杂信息，完成高难度的识别任务。 深度学习需要一定的数据基础，因此在深度学习前需训练大量的数据集。
