# 逻辑工具

逻辑工具可将方案中多个模块的数据通过各种逻辑整合后输出。
更多...

|  |  |
| --- | --- |
| 模块 | |
|  | 条件分支 |
|  | 条件分支结合条件检测和分支模块的功能，当订阅的条件符合要求时执行设定的模块。 |
|  | |
|  | 条件检测 |
|  | 条件检测可判断输入数据是否满足条件。若满足，显示OK字符；否则，显示NG字符。 |
|  | |
|  | 分支模块 |
|  | 分支可根据方案实际需求，配置不同的输入条件。当满足输入条件时，则执行该分支。 |
|  | |
|  | 分支字符 |
|  | 分支字符可检测string类型输入字符。若检测通过，则进行数据传输。 |
|  | |
|  | 文本保存 |
|  | 文件保存可根据编辑的文本格式组成字符串并保存至本地文件，输入变量只有string类型，最大长度为4095字节。 |
|  | |
|  | 逻辑 |
|  | 逻辑可将多个的输出结果进行综合判断，包含运算类型和运算数据。 |
|  | |
|  | 格式化 |
|  | 格式化工具可将数据整合并格式化成字符串输出，既可以链接前面的结果输出，也可以直接在框内输入字符格。在进行通信输出前通常用格式化工具整理数据。 |
|  | |
|  | 字符比较 |
|  | 字符比较可根据输入的字符和设置的字符进行比较。若一样，则输出对应的索引值；不一样，则不输出。该一般配合分支使用。 |
|  | |
|  | 脚本 |
|  | 脚本可保存和加载已编写的脚本内容，进行相对复杂的数据处理。 |
|  | |
|  | Group |
|  | 在复杂方案中，过多可能造成视觉混乱，可选择使用Group进行整合。 |
|  | |
|  | 点集 |
|  | 点集可将其他的相关数据组合为点的集合，最多16个点集，便于后续方案操作。 |
|  | |
|  | 耗时统计 |
|  | 耗时统计可统计流程中从进入开始到离开结束之间的工具耗时。 |
|  | |
|  | 数据集合 |
|  | 数据集合可将生成的多个结果数据整合输出。 |
|  | |
|  | 触发模块 |
|  | 触发可通过流程ID选择方案中除该模块所处流程以外的其他流程，使得触发模块执行时触发其他流程执行。 |
|  | |
|  | 图形收集 |
|  | 图形收集可根据实际需求收集不同类型的图形，并显示在图像上。 |
|  | |
|  | 数据筛选 |
|  | 数据筛选可以订阅某一模块的模块结果，对订阅的数据筛选后输出。 |
|  | |
|  | 数据分类 |
|  | 数据分类可以订阅某一模块的模块结果，将订阅的数据分成若干类别后输出。 |
|  | |
|  | 数据排序 |
|  | 数据排序可订阅单个前序模块的多种类型字段，并根据指定字段进行排序。 |
|  | |
|  | 数据记录 |
|  | 数据记录可以订阅int和float类型数据，并将订阅的数据存储在数据库中。 |
|  | |
|  | Python脚本 |
|  | Python脚本可自定义代码对输入输出变量做逻辑运算。 |
|  | |

## 详细描述

逻辑工具可将方案中多个模块的数据通过各种逻辑整合后输出。
