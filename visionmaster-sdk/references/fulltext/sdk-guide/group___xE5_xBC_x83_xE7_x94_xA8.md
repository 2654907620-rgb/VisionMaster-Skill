|  | 灰度匹配以图像各像素点的灰度为基础建立模板，匹配灰度相近的目标物体。（自4.2.0版本起弃用） |

|  | 像素统计可统计ROI区域内满足高低阈值灰度设置的像素点个数。（自4.3.0版本起弃用） |
|  | |
|  | 字符缺陷检测 |
|  | 字符缺陷检测可将目标图像与标准图像进行验证对比，检测印刷字符、图案是否存在缺失、冗余等非一致性外观缺陷。主要应用于包装、印刷品、半导体等生产制造领域。（自4.1.0版本起弃用） |
|  | |
|  | DL异常检测CPU |
|  | DL异常检测CPU是通过少数OK样本学习的方式，实现对异常图片的检测。该模块为CPU版本，不依赖于显卡。（自4.4.0版本起弃用） |
|  | |
|  | DL异常检测GPU |
