# VisionMaster-Skill

海康机器人 **VisionMaster（VM）** 机器视觉知识库 + 硬件选型资料合集 —— 基于官方文档与厂商公开资料结构化构建，可直接作为 WorkBuddy / Claude Code 类 Agent 的技能包与学习资料使用。

## 这是什么

仓库分两部分：

1. **`visionmaster-sdk/`** —— VM 软件侧知识库技能：把官方 SDK 指南、FAQ 手册、应用帮助三套文档全量拆解成可检索的结构化 Markdown，让 Agent 在回答 VM 相关问题时能直接命中官方原文与 API 签名，而不是靠记忆编。
2. **`hardware-selection/`** —— 机器视觉**硬件选型**学习资料：相机 / 镜头 / 光源的选型计算、打光方案、公式速查与学习路径。

# 二、hardware-selection（硬件选型资料）

## 覆盖范围

| 文件 | 内容 |
|---|---|
| `机器视觉硬件选型_精选学习资料.md` | 按「需求与流程 / 相机 / 镜头 / 光源」四章整理的资料清单，含官方课程、选型工具、书籍、视频，逐条标注推荐指数与链接核验状态 |
| `机器视觉硬件选型_核心知识点笔记.md` | 四章知识点全量消化版：选型总流程、相机八步法与分辨率/行频计算、焦距与定倍率公式及手推实例、7 类打光方式总表与颜色/红外/紫外/偏振应用、公式速查、2 周学习路径 |

## 核心内容摘录

- **相机**：最少像素 = 视野 ÷ 精度（每方向，留 1.5~2 倍裕量）；线阵行频 ≥ 速度 ÷ 每行精度；运动物体必选全局快门
- **镜头**：焦距 `f ≈ WD × 芯片尺寸 ÷ FOV`；定倍率 `FOV = 芯片尺寸 ÷ β`；平行背光必须配远心镜头
- **光源**：低角度=暗场（划伤/倒角），高角度=明场（平整区缺陷），平行背光（精密边缘）；颜色遵循「同色增强、互补色过滤」，蓝光可分金银铜铝
- **靶面速查**：1″=12.8×9.6mm、2/3″=8.8×6.6mm、1/1.8″=7.2×5.4mm、1/2″=6.4×4.8mm、1/3″=4.8×3.6mm

> 注：清单中「建荣科技《工业相机如何选型》」原链接已 404 失效，其 8 步选型法已消化进核心知识点笔记，清单中已标注。

# 使用方式

## 作为 Agent 技能（visionmaster-sdk）

把 `visionmaster-sdk/` 整个目录放进 Agent 的技能目录即可：

```bash
# 用户级技能目录
cp -r visionmaster-sdk ~/.workbuddy/skills/
# 或项目级
cp -r visionmaster-sdk <项目>/.workbuddy/skills/
```

之后提问诸如「VM 二次开发怎么取流程输出」「报 MVALG_STS_ERR 怎么排查」「DL 字符定位有哪些参数」时，Agent 会按 `SKILL.md` 描述自动加载本技能。

## 作为学习资料（hardware-selection）

直接阅读两份 Markdown 即可；建议先看「精选学习资料」按路径学，再对照「核心知识点笔记」做公式手算与考点自查。

# 注意事项

- 两部分内容分工明确：`visionmaster-sdk/` 是**软件侧**（SDK / API / 模块参数 / GUI 操作）；`hardware-selection/` 是**硬件侧**（相机 / 镜头 / 光源选型）。
- 各参数给出的是官方定义与取值范围，不代替现场工艺调优经验。
- 硬件选型资料为第三方公开资料的整理与消化，来源含 OPT、Edmund Optics、CSDN、海康机器人等；`visionmaster-sdk` 仅覆盖海康 VisionMaster，非海康平台（HALCON / VisionPro 等）仅在"联合开发"章节涉及互转。
- 文档版权归各原厂商所有，本仓库仅作结构化的学习检索用途。
