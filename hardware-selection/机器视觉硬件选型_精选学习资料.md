## 六、核心公式速查（对应考点 2.2 / 3.3 / 3.4）

```
相机分辨率：    最少像素数 = 视野FOV ÷ 精度要求（每方向；考虑裕量×1.5~2）
线阵行频：      行频 ≥ 运动速度 ÷ 行扫描精度（每行间距）
焦距：          f = WD × 芯片尺寸 ÷ 视野FOV
放大倍率：      β = 芯片尺寸 ÷ FOV   （定倍率镜头：FOV = 芯片尺寸 ÷ β）
光圈与景深：    f/# 越大 → 景深越大、通光越小（需更长曝光/更亮光源）
运动模糊：      曝光时间内物体位移 ≤ 1 像素（快门越快越好）
```

## 七、建议学习路径（2 周冲刺）

1. **第 1~3 天**：B站 VM 初级认证教程 1.x + 2.x（相机/光源章节）→ 建立海康官方知识框架。
2. **第 4~6 天**：逐章精读《机器视觉从入门到提高》第 2/3/4 章，配合海康镜头选型工具把每个公式手算一遍再用工具验证。
3. **第 7~9 天**：精读 OPT 打光文章 + Edmund 远心选型笔记（3.4 β 与 WD 的计算逻辑）。
4. **第 10~14 天**：刷测试各章节题（每节 3~4 题），错题回到对应资料补漏；用 Basler 帧率计算器熟悉 2.2 帧率/行频题。

> 注：本清单剔除了纯算法/CV 向资源（公众号、深度学习类），只保留与「硬件选型」直接相关的高质量内容。
