## 1. 第 1 章 · 需求与硬件选型流程（总纲）

标准流程链（顺序不可乱）：

```
明确需求（视野/精度/速度/工作距/安装空间/环境/打光条件）
   ↓
精度要求 → 倒推相机分辨率（先定"看得清"，再定"拍得动"）
   ↓
选相机（分辨率/靶面/帧率/快门/接口）
   ↓
选镜头（焦距或倍率 → 与相机靶面、接口匹配）
   ↓
选光源（打光方式 → 颜色 → 尺寸 → 打光测试）
   ↓
配套：采集卡/光源控制器/工控机 → 装机打光测试验证
```

核心思想：**硬件选型是从"精度需求"逐级向下分解的，不是四个硬件各自独立挑。** 前一步的输出（相机靶面、分辨率）是后一步的输入（镜头计算需要芯片尺寸；光源尺寸受镜头视野约束）。

## 2. 第 2 章 · 相机

### 2.1 八步选型法（通用口径）

分辨率 → 芯片靶面 → 像素深度 → 帧率/行频 → 快门方式 → 传感器类型 → 数据接口 → 触发方式。

### 2.2 分辨率计算（考点 2.2）

```
最少像素数 = 视野 FOV ÷ 精度要求     （X/Y 两个方向各算一次）
工程裕量：结果 × 1.5 ~ 2 再选档
```

**例**：视野 100mm，要求精度 0.1mm → 100/0.1 = 1000 像素 → 理论 130 万（1280px）够用，乘裕量后建议 500 万档更稳。

### 2.3 线阵相机行频

```
行频（Hz）≥ 运动速度（mm/s）÷ 行扫描精度（mm/行）
```
运动越快、每行间距要求越小，行频必须越高；行频不足 → 图像拉伸/漏扫。

### 2.4 常见靶面尺寸（镜头计算必背）

| 靶面 | 对角(约) | 水平×垂直(mm) |
|------|---------|---------------|
| 1″ | 16mm | 12.8 × 9.6 |
| 2/3″ | 11mm | 8.8 × 6.6 |
| 1/1.8″ | 9mm | 7.2 × 5.4 |
| 1/2″ | 8mm | 6.4 × 4.8 |
| 1/3″ | 6mm | 4.8 × 3.6 |

（Edmund 实例中 1/1.8″ 水平即取 7.2mm。）

### 2.5 其他选型要点

| 维度 | 结论 |
|------|------|
| 快门 | **运动物体必选全局快门**（卷帘有果冻效应）；静止/低速可用卷帘（便宜） |
| CCD vs CMOS | CMOS 为主流（帧率高、集成度高、成本低）；CCD 已边缘化 |
| 黑白 vs 彩色 | 尺寸测量/边缘检测/定位用**黑白**（无拜耳插值损失）；只有颜色识别才用彩色 |
| 接口带宽 | USB3.0 ≈ 350~400MB/s；GigE ≈ 100MB/s 但可远距离；10GigE / CXP / CameraLink 用于高分辨率高帧率 |
| 触发 | 硬触发（光电/PLC 信号）时延小精度高；软触发有系统延迟 |
| 像素深度 | 8bit 通用；高动态/渐变测量场景考虑 10/12bit |

## 3. 第 3 章 · 镜头

### 3.1 普通定焦镜头：焦距公式（考点 3.3）

薄透镜：`1/f = 1/z + 1/z'`（z 物距、z' 像距），倍率 `m = z'/z = H'/H`。
工程近似（Edmund 公式 3 去掉 −1 项）：

```
f ≈ WD × 芯片尺寸 ÷ FOV
```

**Edmund 实例**：IMX250 传感器（2/3″、5MP），WD = 500mm，FOV = 175mm
→ f = 500 × 8.8 ÷ 175 ≈ 25mm → **选 25mm 镜头**。

### 3.2 定倍率（远心）镜头：倍率公式（考点 3.4）

```
FOV = 芯片尺寸 ÷ β        （β = 镜头标称放大倍率，如 0.3X）
```

**Edmund 实例**：测量 Φ20mm 孔，零件位置浮动，需 FOV = 24mm；1/1.8″ 传感器（水平 7.2mm）
→ β = 7.2 ÷ 24 = 0.3X → **选 0.3X 远心镜头**。
要点：定倍率镜头放大倍率不随传感器变，**只有 FOV 变**；且只在其设计工作距附近工作。

### 3.3 Edmund 图线的三条规律

1. 焦距越长 → 最小工作距离越长；加间隔环可缩短最小 WD，但**画质下降**。
2. 同焦距同 WD 下，**传感器越大 FOV 越大**（例：WD=350mm、12mm 镜头：2/3″ → FOV≈370mm；1″ → FOV≈530mm，+43%）。
3. 焦距-WD 图线上的"空隙"= 市面无现成定焦可覆盖的组合，需换传感器或换远心/变焦方案。

### 3.4 远心镜头价值与搭配

- 平行光路：物距变化不改变倍率 → 测量精度稳定、无视差；**精密尺寸测量首选**。
- **平行背光源必须配远心镜头**（光轴同轴调校；对不准效果很差，对准后极佳，调好需固定防震）。

### 3.5 分辨率匹配与光圈（考点 3.2）

- 镜头 MTF 必须覆盖相机像素频率：像素越小，要求镜头分辨率越高。**500 万相机配百万像素镜头 = 浪费**。
- 光圈 f/#：**越大 → 景深越大、进光越少**（需更亮光源或更长曝光）；小光圈过小会受衍射限制。
- 接口/像面：传感器对角 ≤ 镜头最大像面圈，否则暗角；C 口法兰距 17.526mm（CS 更短，加 5mm 接圈转 C）。
- 运动模糊：曝光时间内物体位移 ≤ 1 像素（快门越快越好，与光源亮度联动权衡）。

## 4. 第 4 章 · 光源（OPT 全文消化）

### 4.1 打光方式总表

| 打光方式 | 成像原理 | 典型应用 | 优 / 缺点 | 常用光源 |
|----------|---------|---------|-----------|---------|
| **背光·漫射** | 轮廓剪影，图基本黑白两区 | 存在性检测、计数、薄片边缘、透明体异物、镂空打标 | 简单稳定便宜 / 在线项目不便、厚件圆角**边缘发虚** | 漫射背光源 |
| **背光·平行** | 平行光在边缘折射出镜头入瞳→边缘纯黑锐利 | 精确边缘检测、定位、尺寸测量 | 效果极佳精度高 / 贵、必须配远心+同轴调校 | 平行背光源 |
| **前光·低角度（暗场）** | 平整面反光不进镜头→背景黑；不平整处反光进镜头→亮 | 划伤、打标字符、表面异物、边缘/倒角（45~60°坡度）、冲压浇铸字符 | 安装方便效果稳 / 透明体差、现场高度受限 | 条形光、线形光、低角度环形光 |
| **前光·高角度（明场）** | 平整面反光进镜头→背景白；不平整处暗 | 细微划伤、字符、异物、平整区轮廓、粗糙度差异 | 细节清晰 / 均匀性难调 | 高角度环形、条形、面光、同轴光、点光 |
| **折射光** | 平整表面透射方向一致（亮/暗背景），不平整处折射偏移 | 透明体表面细微划伤、平整度、厚度均匀性 | 细节清晰稳定 / 安装不便 | 面光、点阵光、带透明图层面光（点阵/标定板/光栅图案） |
| **散射光** | 微观粗糙结构散射变亮、其余暗场 | 玻璃/塑料划伤、激光雕刻字符、透明薄膜边缘 | 细节清晰 / 有效距离远时亮度要求高，多需特制 | 线形、条形、点光 |
| **漫射无影** | 球积分/拱形二次漫反射，面+方向均匀 | 反光物体轮廓、弧面严重缺陷、雕刻印刷图案 | 均匀稳定 / 镜面倒影难处理 | 环积分、拱形、四边无影、环形无影、灯箱 |

**背光应用技巧**（OPT 原文）：光源面积够用即可（过大伤边缘）；光源离工件远一点边缘改善；最亮处灰度 **≤220** 不过曝；高精度测量配物方远心。

### 4.2 颜色选择（考点 4.x 高频）

| 原则 | 用法 | OPT 实例 |
|------|------|---------|
| 同色增强、互补色过滤 | 要看的目标用**同色光**提亮；要滤掉的用**同色光**压掉 | 红色"谢谢惠顾"字符干扰冲压检测 → 红光把字符整体滤白/滤平 |
| 过滤背景 | 光源颜色 = 背景色 → 背景被削弱 | 蓝色/绿色瓶盖上的喷码 → 用与盖同色光照，只留字符 |
| 金属分光特性 | 短波段银/铝反射率远高于金/铜 → **蓝光区分金属** | Die Bonding：蓝光同轴下镀银焊盘亮、金线黑；铜接触片/镀银弹片 → 蓝光下铜变黑 |
| 红外 850/940nm | 波长长，**穿透有机材质**强，可滤有机染料颜色干扰 | 透薄塑胶检测 |
| 紫外 365/385nm | 荧光效应 + 散射好；短波紫外致物质光化学变化，**食品行业部分工位禁用** | 荧光残留/防伪特征 |
| 偏振 | 光源端线偏振片 + 镜头端**圆偏振片**（防线偏振光入镜后异常）；旋转消反光、翻转材质对比 | 电池极片胶膜定位；技巧：**先对焦再转光源端偏振片** |

### 4.3 选型步骤（对应测试 4.1~4.3）

明确需求（要检什么特征）→ 初选打光方式（上表反查特征）→ 定颜色（4.2 原则）→ 确认尺寸（覆盖视野、安装空间）→ **打光实测**（现场多角度试打，软件看对比度与稳定性）→ 定控制器（通道数/亮度调节/频闪/触发）。

## 5. 公式速查（合并清单第六节 + 实例）

```
相机分辨率：  最少像素 = FOV ÷ 精度（每方向，裕量 ×1.5~2）
线阵行频：    行频 ≥ 速度 ÷ 每行精度
焦距：        f ≈ WD × 芯片尺寸 ÷ FOV        [例: 500×8.8/175 ≈ 25mm]
定倍率:       FOV = 芯片尺寸 ÷ β             [例: 7.2/24 = 0.3X 远心]
薄透镜:       1/f = 1/z + 1/z'， m = z'/z = H'/H
光圈景深:     f/# 越大 → 景深越大、通光越小
运动模糊:     曝光时间内位移 ≤ 1 像素
背光灰度:     最亮处 ≤ 220
```
